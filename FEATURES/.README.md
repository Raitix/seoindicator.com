# FEATURES Template

This folder contains feature definitions.

## Naming Convention
`FEAT-X.md` where X is a sequential number.

## Feature File Structure

```markdown
# FEAT-X: [Feature Name]

## STATUS
`New Feature` | `Cancelled`

## Description
_Brief description of the feature_

## User Story
As a [user type], I want [goal] so that [benefit].

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Related
- Specification: SPEC-X
- Tasks: SPEC-X-1, SPEC-X-2, ...

## Notes
_Additional context or decisions_
```

---

## Valid Status Values & Agent Actions

| Status | Who | Action |
|--------|-----|--------|
| `New Feature` | Innovator | **Creates** feature with this status |
| `New Feature` | Architect | **Picks up** for specification |
| `Cancelled` | Any agent | Sets with documented reason |

---

## Workflow

```
Innovator creates FEAT-X ("New Feature")
         ↓
Architect picks up ("New Feature")
         ↓
Architect creates SPEC-X
```
