## Notes for Developer

### Component Location
- **Component:** `components/guides/ToolEmbed.tsx`
- **Tests:** `__tests__/components/guides/ToolEmbed.test.tsx`

### Implementation Guidelines

1. **Use ToolWidget internally** — ToolEmbed wraps ToolWidget for actual tool rendering
2. **Support lazy loading** — Use Next.js `dynamic` import or React.lazy for code splitting
3. **Error boundary** — Wrap tool in error boundary for graceful degradation
4. **Mobile-first CSS** — Design for mobile, enhance for larger screens
5. **CTA styling** — Use Shadcn/UI Button component with consistent styling
