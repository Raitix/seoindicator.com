## Notes for Developer

1. **Page Route:** Create page at `frontend/app/dashboard/badges/page.tsx`

2. **Component Structure:**
   - `BadgeManagementPage` - Main page component
   - `BadgeManagementRow` - Table row component
   - `BadgePreview` - Reuse from TASK-33-13
   - `EmbedCodeModal` - Modal for embed code display

3. **Data Fetching:**
   - Fetch public audits from `/api/v1/audits/public`
   - Fetch analytics from `/api/v1/badge/analytics`
   - Handle loading and error states

4. **State Management:**
   - Sort field and direction state
   - Visibility toggle state
   - Embed modal state

5. **API Calls:**
   - GET `/api/v1/audits/public` - List public audits
   - GET `/api/v1/badge/analytics` - Badge analytics
   - PATCH `/api/v1/audits/{id}/visibility` - Toggle visibility

6. **Accessibility:**
   - Use semantic HTML (table, thead, tbody)
   - Add aria-labels to interactive elements
   - Implement keyboard navigation
   - Use aria-live for loading/error states

7. **Responsive:**
   - Use `overflow-x-auto` for table container
   - Summary cards in responsive grid
   - Touch-friendly buttons (min 44x44px)
