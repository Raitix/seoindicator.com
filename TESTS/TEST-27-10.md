## Notes for Developer

### Controller Implementation
Create `backend/app/Http/Controllers/Api/V1/Admin/CreditsController.php`:
- `overview()` method - aggregates credit stats
- `transactions()` method - paginated list with filters
- `revenue()` method - revenue calculations

### Service Dependencies
- CreditAggregationService (TASK-27-9) - inject for data
- AdminStatsService (TASK-27-3) - optional caching

### Routes to Add
```php
Route::middleware(['auth', 'admin'])->prefix('admin/credits')->group(function () {
    Route::get('/overview', [CreditsController::class, 'overview']);
    Route::get('/transactions', [CreditsController::class, 'transactions']);
    Route::get('/revenue', [CreditsController::class, 'revenue']);
});
```

### PII Masking
When returning transactions, ensure:
- No user email addresses
- No full user names (mask as "J*** D***")
- No payment method details
- Only necessary user_id for reference
