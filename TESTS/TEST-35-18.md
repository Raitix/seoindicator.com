1. **OAuth State Storage:**
   - Store state in `sessionStorage` for CSRF protection
   - State format: `{siteId}-{locationId}-{timestamp}`

2. **Popup Handling:**
   - Open OAuth in popup (600x700 dimensions)
   - Handle popup blocked error gracefully
   - Listen for `message` event for callback

3. **Google Branding:**
   - Use official Google logo SVG
   - Apply `google-branding` class
   - Follow Google's button styling guidelines

4. **Token Security:**
   - NEVER store access tokens in frontend state
   - NEVER expose tokens in DOM
   - All token handling done by backend

5. **Error Messages:**
   - Popup blocked: "Please allow popups for this site."
   - No accounts: "No Google Business Profile accounts found."
   - Already connected: "This location is already connected to another record."
   - Generic: "Connection failed. Please try again."
