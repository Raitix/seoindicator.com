## Test Data Setup

### Factories Used
- `UserFactory` - Creates test users
- `ProjectFactory` - Creates test projects
- `CrawlJobFactory` - Creates crawl jobs with states:
  - `queued()` - Job in queue
  - `running()` - Job currently processing
  - `completed()` - Job finished successfully
  - `failed()` - Job failed with error
  - `cancelled()` - Job cancelled by user
  - `expired()` - Job past retention period
- `CrawlPageFactory` - Creates crawl pages with:
  - `forJob($crawlJob)` - Associate with job
  - Custom depth, URL, content, links

### Mock Services
- `CrawlerService` - Mocked for worker tests
- `PlaywrightRendererService` - Mocked for browser tests
- `UrlValidatorService` - Mocked for SSRF tests
- `TimeoutHandlerService` - Mocked for timeout tests
- `CancellationService` - Mocked for cancellation tests
- `PartialResultsService` - Mocked for partial results tests

## Notes for Developer

1. **Test Isolation:**
   - All tests use `RefreshDatabase` trait
   - Each test is independent and can run in any order
   - Mock services ensure no external dependencies

2. **Browser Mocks:**
   - Tests mock Playwright browser operations
   - Real browser tests would require Playwright installed
   - Use `--exclude-group=browser` to skip real browser tests

3. **Coverage Targets:**
   - Integration tests: 80%+ coverage
   - Focus on critical paths: job lifecycle, depth control, SSRF protection

4. **CI/CD Integration:**
   - Tests designed for CI environment
   - No external services required
   - Fast execution (mocked operations)
