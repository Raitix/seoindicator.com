## Expected Implementation

```typescript
// frontend/components/indicators/icons.ts

import {
  TrendingUp,
  Eye,
  Users,
  Wrench,
  Link,
  FileText,
  Star,
  Zap,
} from 'lucide-react';

/**
 * Centralized icon registry mapping SEO indicator types to Lucide icons.
 * Supports tree-shaking via individual imports.
 */
export const INDICATOR_ICONS = {
  'keyword-rankings': TrendingUp,
  'visibility-score': Eye,
  'competitor-analysis': Users,
  'technical-health': Wrench,
  'backlink-profile': Link,
  'content-opportunities': FileText,
  'serp-features': Star,
  'page-speed': Zap,
} as const;

/**
 * Type for valid indicator icon names.
 * Derived from INDICATOR_ICONS keys for type safety.
 */
export type IndicatorIconName = keyof typeof INDICATOR_ICONS;

/**
 * Array of all valid indicator icon names.
 * Useful for validation and iteration.
 */
export const IndicatorIconName: readonly IndicatorIconName[] = Object.keys(INDICATOR_ICONS) as IndicatorIconName[];
```

## Notes for Developer

1. **File Location:** Create `frontend/components/indicators/icons.ts`
2. **Import Pattern:** Use named imports from `lucide-react` for tree-shaking
3. **Type Safety:** Use `as const` for compile-time type checking
4. **Immutability:** Consider `Object.freeze()` for runtime protection
5. **Backward Compatibility:** All existing exports in `index.ts` must remain
