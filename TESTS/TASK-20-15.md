## Content Guidelines

### Section Content Requirements
- Each section should have 150-400 words
- Use markdown formatting (bold, lists, links)
- Include practical tips and examples
- Reference free tools (Let's Encrypt, SSL Labs)

### Checklist Item Requirements
- Clear, actionable text
- Appropriate priority level
- Covers key HTTPS/security areas
- Practical for users to implement

### Code Example Requirements
- Syntactically valid Apache/Nginx configuration
- Clear description of purpose
- Appropriate language tag ('apache' or 'nginx')
- Modern best practices (HSTS, X-Frame-Options)

### Technical Notes to Include
- Let's Encrypt provides free DV certificates
- HSTS max-age should be at least 31536000 (1 year)
- X-Frame-Options: SAMEORIGIN prevents clickjacking
- X-Content-Type-Options: nosniff prevents MIME sniffing
- Mixed content breaks HTTPS security model
- Chrome shows "Not Secure" for HTTP sites
- Google uses HTTPS as a ranking signal since 2014

### Security Headers Reference
| Header | Recommended Value | Purpose |
|--------|-------------------|---------|
| Strict-Transport-Security | max-age=31536000; includeSubDomains; preload | Force HTTPS |
| X-Frame-Options | SAMEORIGIN | Prevent clickjacking |
| X-Content-Type-Options | nosniff | Prevent MIME sniffing |
| X-XSS-Protection | 1; mode=block | XSS protection (legacy browsers) |
| Referrer-Policy | strict-origin-when-cross-origin | Control referrer info |
| Content-Security-Policy | (site-specific) | XSS prevention |
