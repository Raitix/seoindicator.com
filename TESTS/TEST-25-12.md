## Notes for Developer

1. **Model File**: Create `app/Models/AnalysisHistory.php`

2. **Repository File**: Create `app/Repositories/AnalysisHistoryRepository.php`

3. **Fillable Fields**:
   - user_id (required)
   - site_id (nullable)
   - tool_name (required, VARCHAR 100)
   - input_url (required, VARCHAR 2083)
   - status (default 'completed', ENUM: pending/completed/failed)
   - results (nullable JSON)
   - error_message (nullable TEXT)
   - analysis_duration_ms (nullable INT UNSIGNED)
   - analyzed_at (TIMESTAMP)

4. **Key Scopes to Implement**:
   - `completed()`, `pending()`, `failed()`
   - `byTool($tool)`, `byUser($userId)`, `bySite($siteId)`
   - `analyzedBetween($from, $to)`, `recent()`
   - `withResults()`, `withoutSite()`

5. **Repository Methods**:
   - `create(array $data): AnalysisHistory`
   - `findById(int $id): ?AnalysisHistory`
   - `findByUser(int $userId, array $filters = []): LengthAwarePaginator`
   - `update(int $id, array $data): AnalysisHistory|bool`
   - `delete(int $id): bool`
   - `getByTool(int $userId, string $tool): Collection`
   - `getRecent(int $userId, int $limit = 10): Collection`
   - `getStats(int $userId): array`

6. **Stats Array Structure**:
   ```php
   [
       'total' => int,
       'by_status' => ['pending' => int, 'completed' => int, 'failed' => int],
       'by_tool' => ['tool-name' => int, ...],
       'avg_duration_ms' => float,
       'success_rate' => float, // percentage
   ]
   ```
