## Test Scenarios

### Lang Attribute Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| LA-01 | Valid lang attribute | `<html lang="en">` | hasLang: true, lang: 'en' |
| LA-02 | Valid with region | `<html lang="en-US">` | hasLang: true, lang: 'en-US' |
| LA-03 | Missing lang attribute | `<html>` | hasLang: false |
| LA-04 | Empty lang | `<html lang="">` | hasLang: true, isEmpty: true |
| LA-05 | Invalid lang code | `<html lang="xyz">` | hasLang: true, isValid: false |

### Valid Language Code Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| VL-01 | Two-letter code | `en`, `de`, `fr` | isValid: true |
| VL-02 | Language + country | `en-US`, `de-DE`, `fr-CA` | isValid: true |
| VL-03 | Language + script | `zh-Hans`, `zh-Hant` | isValid: true |
| VL-04 | Invalid format | `english`, `US`, `123` | isValid: false |
| VL-05 | Common typos | `eng`, `esp` | isValid: false |

### Content Language Match Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CL-01 | Content matches lang | English content + lang="en" | contentMatches: true |
| CL-02 | Content mismatch | English content + lang="de" | contentMatches: false |
| CL-03 | Cannot determine | Mixed language content | contentMatches: null |

### Scoring Tests

| ID | Scenario | Input | Expected Score |
|----|----------|-------|----------------|
| SC-01 | Perfect lang | Valid + matches content | 3 (Excellent) |
| SC-02 | Good lang | Valid but potential mismatch | 2 (Good) |
| SC-03 | Poor lang | Missing or invalid | 1 (Poor) |

### Interface Compliance Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| IC-01 | ID returns correct | id() | 'language' |
| IC-02 | Name returns correct | name() | 'Language' |
| IC-03 | Category returns correct | category() | 'technical' |
| IC-04 | Weight returns correct | weight() | 0.03 |

### Edge Case Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| EC-01 | Multiple html elements | Two html tags | Uses first |
| EC-02 | Lang on body | `<body lang="en">` | Notes proper placement |
| EC-03 | Meta Content-Language | `<meta http-equiv="content-language">` | Detected as fallback |
| EC-04 | RTL language | `<html lang="ar" dir="rtl">` | detected |

## Mock Data

### Valid Language
```html
<!DOCTYPE html>
<html lang="en-US">
<head><title>English Page</title></head>
<body><p>This is English content.</p></body>
</html>
```

### Missing Language
```html
<!DOCTYPE html>
<html>
<head><title>Page</title></head>

</html>
```

```html
<html lang="english">
```
