## User Flows Tested

### Flow 1: View Audit List
1. Navigate to `/sites/:siteId/audits`
2. Verify audit cards display
3. Verify status indicators
4. Verify pagination if applicable

### Flow 2: Start New Audit
1. Click "Start Audit" button
2. Modal opens
3. Enter max pages and max depth
4. Submit form
5. Modal closes
6. New audit appears in list

### Flow 3: View Audit Details
1. Click on audit card
2. Navigate to detail page
3. View summary cards
4. View issues list
5. Filter by severity

### Flow 4: Manage Issues
1. View issues list
2. Select issues via checkbox
3. Use bulk actions
4. Verify status updates

## Security Tests

### XSS Prevention
- Script tags in issue descriptions are escaped
- No script execution from user content
- Content is rendered as text, not HTML

### SQL Injection Prevention
- Search queries don't execute SQL
- API returns safe responses
- No database errors exposed

### Authorization
- 401 responses show login prompt
- 404 responses show not found state
- 403 responses show access denied
