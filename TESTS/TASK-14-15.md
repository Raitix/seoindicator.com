## API Endpoints (from TASK-14-13)

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/v1/sites/{siteId}/audits` | GET | List audits for site |
| `/api/v1/sites/{siteId}/audits` | POST | Trigger new audit |
| `/api/v1/audits/{auditId}` | GET | Get audit status |
| `/api/v1/audits/{auditId}` | DELETE | Cancel running audit |

## Notes for Developer

1. **Polling:** useAudits hook must implement conditional polling (5s interval when any audit is running)
2. **Status Colors:** Use shadcn/ui Badge variants (destructive, warning, secondary)
3. **Icons:** Use lucide-react icons (Clock, Loader, CheckCircle, XCircle)
4. **Progress Bar:** Use shadcn/ui Progress component
5. **Modal:** Use shadcn/ui Dialog component
6. **Animation:** Use Tailwind animate-pulse and animate-spin
