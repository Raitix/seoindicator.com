## Required Fixes

### 1. SQLite Compatibility (CreditTest, CreditTransactionTest)
Replace `SHOW INDEX` queries with Laravel Schema methods:
```php
// Instead of:
$indexes = \DB::select("SHOW INDEX FROM credits WHERE Column_name = 'user_id'");

// Use:
$this->assertTrue(Schema::hasIndex('credits', ['user_id'], 'unique'));
// Or skip on SQLite:
if (config('database.default') !== 'sqlite') {
    // MySQL-specific tests
}
```

### 2. Repository Signature Alignment (CreditRepositoryTest)
Update test method calls to match implementation:
```php
// Old:
$this->repository->addCredits($user, 50.00, 'purchase', 'Test purchase');

// New:
$this->repository->addCredits($user, 50.00, [
    'type' => 'purchase',
    'description' => 'Test purchase',
]);
```
