## Notes for Developer

1. **Component Structure:**
   - `CreditPackages` - Main section component with grid
   - `PackageCard` - Individual card with all details
   - `ModelPricingTable` - Full table with sorting/filtering
   - `PricingFAQ` - Accordion with expand/collapse

2. **API Integration:**
   - `GET /api/v1/packages` - Returns credit packages
   - `GET /api/v1/models` - Returns AI models
   - Handle loading and error states

3. **SEO Requirements:**
   - Use `generateMetadata()` for meta tags
   - Include Schema.org JSON-LD script
   - Server-side render for crawlers

4. **Accessibility:**
   - All interactive elements focusable
   - Proper ARIA attributes on accordion
   - Table has caption and scope attributes

5. **Security:**
   - Sanitize all user-facing text
   - XSS prevention tested
