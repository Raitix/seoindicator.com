## Overview
Test suite for Backlinks History and Sync REST API endpoints. These endpoints enable historical trend visualization and on-demand data refresh for backlink profiles.

### Endpoints
- `GET /api/v1/projects/{projectId}/backlinks/history` - Get historical backlink snapshots
- `POST /api/v1/projects/{projectId}/backlinks/sync` - Trigger manual backlink sync

### Authentication
- Bearer token (Sanctum session or API Key)
- Authorization via ProjectPolicy

### Rate Limiting
- Sync endpoint: Max 1 request per project per hour
- History endpoint: Standard API rate limits

## Notes for Developer

### Routes Required (routes/api.php)
```php
Route::prefix('v1')->middleware(['auth:sanctum'])->group(function () {
    Route::get('projects/{projectId}/backlinks/history', [BacklinkHistoryController::class, 'index'])
        ->middleware('can:view,project');
    
    Route::post('projects/{projectId}/backlinks/sync', [BacklinkSyncController::class, 'store'])
        ->middleware('can:update,project')
        ->middleware('throttle:sync-backlinks');
});
```

### Controllers Required
- `app/Http/Controllers/Api/V1/Backlinks/BacklinkHistoryController.php`
- `app/Http/Controllers/Api/V1/Backlinks/BacklinkSyncController.php`

### Service Required
- `app/Services/Backlinks/BacklinkSnapshotService.php`

### Key Implementation Details

1. **History Endpoint**:
   - URL: `/api/v1/projects/{projectId}/backlinks/history`
   - Method: GET
   - Auth: `view` permission on project
   - Query params: `from` (date), `to` (date)
   - Default range: Last 30 days
   - Response: Array of snapshots ordered by date ASC

2. **Sync Endpoint**:
   - URL: `/api/v1/projects/{projectId}/backlinks/sync`
   - Method: POST
   - Auth: `update` permission on project
   - Rate limit: 1 request per project per hour
   - Response: job_id, status, estimated_duration
   - Job: Dispatches `SyncBacklinksJob`

3. **Rate Limiting**:
   - Track last sync per project (database or cache)
   - Return 429 with `retry_after` timestamp
   - Prevent concurrent syncs (check for pending job)

4. **Error Responses**:
   - 401: Unauthorized (missing/invalid token)
   - 403: Forbidden (no permission)
   - 404: Not found (project doesn't exist)
   - 422: Validation error / Precondition failed
   - 429: Rate limit exceeded
   - 503: Service unavailable (queue full)
