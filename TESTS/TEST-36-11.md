## Notes for Developer

1. **API Integration:** Components receive data via props, not direct API calls. The parent page should handle data fetching.

2. **shadcn/ui:** Use existing shadcn/ui components (Card, Table, Badge, Button, Tooltip, Skeleton) as building blocks.

3. **Number Formatting:** Use a consistent formatter for large numbers (K, M suffixes).

4. **Sparkline Library:** Consider using a lightweight sparkline library (e.g., react-sparklines or custom SVG).

5. **TypeScript Interfaces:** All props should have TypeScript interfaces exported from `types.ts`.
