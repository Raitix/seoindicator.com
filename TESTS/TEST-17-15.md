### Metrics Response
```typescript
interface OnboardingMetrics {
  total_users: number;
  completion_rate: number;
  average_duration_seconds: number;
  skip_rate: number;
  funnel: FunnelStep[];
  date_range: {
    start: string;
    end: string;
  };
  generated_at: string;
}

interface FunnelStep {
  step: number;
  name: string;
  users: number;
  conversion_rate: number;
  drop_off_rate: number;
}
```

## Notes for Developer

1. **Component Location**: `frontend/components/admin/OnboardingMetricsDashboard.tsx`

2. **API Endpoint**: `GET /api/v1/admin/onboarding/metrics`

3. **Query Parameters**:
   - `period`: 7, 30, 90 (days)
   - `start_date`: ISO date
   - `end_date`: ISO date

4. **Funnel Calculation**:
   - Each step shows % of users who reached it
   - Drop-off = previous step % - current step %

5. **Alert Threshold**: >20% drop-off triggers warning
