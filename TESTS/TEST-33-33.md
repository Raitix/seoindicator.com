## Notes for Developer

1. **Database Transactions:** All tests use `RefreshDatabase` trait for isolation
2. **Rate Limiting:** Tests verify rate limiting is applied to public endpoints
3. **Privacy:** IP addresses are always hashed before storage
4. **Cleanup:** Deleting an audit cascades to all related records
5. **Score Calculation:** Based on issue severity (critical: -10, warning: -5, notice: -2)
6. **Partial Data:** Anonymous users only see top 5 issues
