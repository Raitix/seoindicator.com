# TEST-34-19: AlertDetectionService Tests

## Task Reference
- **Task:** TASK-34-19
- **Specification:** SPEC-034
- **Feature:** FEAT-034 - AI Visibility Tracking (Generative Engine Optimization)

---

## Overview

Comprehensive test suite for the `AlertDetectionService` that detects significant changes in AI visibility metrics and creates alerts for brand monitoring.

**Key Responsibilities:**
1. Detect mention spikes (+20% increase)
2. Detect mention drops (-20% decrease)
3. Detect competitor gains (+15% competitor advantage)
4. Detect sentiment shifts (±0.3 score change)
5. Alert deduplication within 24 hours
6. Notification dispatch via events
