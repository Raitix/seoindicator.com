## Task Reference

## Overview
Comprehensive tests for Stripe payment flow including:
- PaymentForm component with Stripe Elements
- PaymentMethodSelector for saved payment methods
- PaymentConfirmation for success/error states
- PaymentHistory for transaction records
- API hooks for payment operations
- Full integration flow testing

## Notes for Developer

### Stripe Elements Setup
```typescript
import { loadStripe } from '@stripe/stripe-js';
import { Elements, CardElement } from '@stripe/react-stripe-js';

const stripePromise = loadStripe(process.env.NEXT_PUBLIC_STRIPE_KEY);

// In component
<Elements stripe={stripePromise}>
  <CardElement options={cardElementOptions} />
</Elements>
```

### Payment Flow
1. User selects package → Display PaymentForm
2. PaymentForm collects card details via Stripe Elements
3. On submit, create payment intent via API
4. Confirm payment with Stripe.js
5. Handle success/error via PaymentConfirmation
6. Update balance via Balance API

### Error Handling Pattern
```typescript
try {
  const { error, paymentIntent } = await stripe.confirmCardPayment(clientSecret);
  
  if (error) {
    // Handle Stripe error (declined, insufficient funds, etc.)
    setError(error.message);
  } else if (paymentIntent.status === 'succeeded') {
    // Payment successful
    onSuccess(paymentIntent);
  }
} catch (err) {
  // Handle network/server errors
  setError('Network error. Please try again.');
}
```

### PCI Compliance
- Card data NEVER touches your server
- Stripe Elements handles sensitive data
- Only `payment_method_id` or `payment_intent_id` stored
- Always use HTTPS in production
