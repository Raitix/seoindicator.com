## Notes for Developer

1. **Tracking Utility Location**: `frontend/lib/analytics/onboardingTracking.ts`

2. **Event Names**:
   - `onboarding_started`
   - `onboarding_step_completed`
   - `onboarding_step_skipped`
   - `onboarding_skipped`
   - `onboarding_completed`
   - `onboarding_resumed`

3. **Implementation Approach**:
   - Create tracking utility with typed methods
   - Call from OnboardingContext or individual components
   - Send async, don't block UI
   - Queue events if offline

4. **Privacy Considerations**:
   - Respect user's analytics opt-out preference
   - Don't include PII in event properties
   - Use anonymous session IDs

5. **Performance**:
   - Batch events when possible
   - Use sendBeacon for reliability
   - Don't await tracking calls
