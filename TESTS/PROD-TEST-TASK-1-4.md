## Root Cause Analysis

### Issue
Routes `/api/v1/keywords/{id}` (GET, PUT, DELETE) use `api-key` middleware while routes `/api/v1/sites/{siteId}/keywords` use `auth:sanctum` middleware.

### Evidence
```
GET /api/v1/keywords/1 → 401 {"success":false,"error":{"code":"UNAUTHENTICATED","message":"Missing API key"}}
GET /api/v1/sites/1/keywords → 200 {"success":true,"data":[],"meta":{"total":0,"page":1,"perPage":20}}
```

### Recommended Fix
Update `backend/routes/api.php` to use consistent middleware:

```php
// Change from:
Route::middleware(['api-key'])->group(function () {
    Route::get('/keywords/{id}', [KeywordController::class, 'show']);
    // ...
});

// To:
Route::middleware(['auth:sanctum'])->group(function () {
    Route::get('/keywords/{id}', [KeywordController::class, 'show']);
    // ...
});
```
