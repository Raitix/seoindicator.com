## Test Cases

### POST /api/v1/competitors - Create Competitor

#### Test 1: Create competitor with valid data
- **Type:** Feature
- **Steps:**
  1. POST with domain, displayName, notes
  2. Assert 201 Created
  3. Assert response contains competitor data
- **Expected:**
  ```json
  {
    "success": true,
    "data": {
      "id": 1,
      "domain": "competitor.com",
      "displayName": "Main Competitor",
      "notes": "Primary rival"
    }
  }
  ```

#### Test 2: Create competitor - domain only (minimum required)
- **Type:** Feature
- **Steps:**
  1. POST with only domain
  2. Assert 201 Created
  3. displayName and notes should be null
- **Expected:** Success with nullable fields

#### Test 3: Create competitor - missing domain
- **Type:** Feature
- **Steps:**
  1. POST without domain field
  2. Assert 400 Bad Request
- **Expected:**
  ```json
  {
    "success": false,
    "error": {
      "code": "VALIDATION_ERROR",
      "message": "The domain field is required."
    }
  }
  ```

#### Test 4: Create competitor - invalid domain format

### HTTP Status Codes
- 200: Success (GET, PUT)
- 201: Created (POST)
- 204: No Content (DELETE)
- 400: Bad Request (validation error)
- 401: Unauthorized
- 403: Forbidden (limit reached)
- 404: Not Found
- 409: Conflict (duplicate)
