## Notes for Developer

1. **Migration File**: Create `database/migrations/2026_03_01_000002_create_analysis_costs_table.php`

2. **Model File**: Create `app/Models/AnalysisCost.php`

3. **Decimal Precision**:
   - `cost_units`: DECIMAL(10,4) - up to 999999.9999 units
   - `cost_amount`: DECIMAL(10,6) - up to $999,999.999999

4. **Cost Types** (not enforced by enum, documented values):
   - `api_call` - External API usage
   - `compute` - CPU/compute time
   - `storage` - Storage used
   - `variable` - Other variable costs

5. **Foreign Key**: CASCADE delete ensures costs are removed when analysis is deleted

6. **Indexes**:
   - `analysis_id` - Fast lookup by analysis
   - `cost_type` - Filter/aggregation by type
