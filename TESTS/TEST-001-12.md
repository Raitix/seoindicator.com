## Test Scenarios

### Scheduling Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| SCHED-001 | Run scheduler daily | Jobs queued for all active keywords |
| SCHED-002 | Run scheduler hourly | Jobs queued based on config |
| SCHED-003 | Disabled scheduler | No jobs queued |
| SCHED-004 | Configurable interval | Interval from config |

### Keyword Selection Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| SEL-001 | Only active keywords | status='active' keywords queued |
| SEL-002 | Skip paused keywords | status='paused' not queued |
| SEL-003 | Skip recently checked | Keywords with recent last_checked_at skipped |
| SEL-004 | Include never checked | last_checked_at=null always queued |

### Job Prioritization Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| PRI-001 | Recently viewed keywords | Higher priority |
| PRI-002 | Old keywords | Lower priority |
| PRI-003 | Default priority | 'normal' priority |

### Randomization Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| RAND-001 | Jobs spread over time | Not all queued at same time |
| RAND-002 | Avoid API bursts | Gradual job creation |

### Manual Trigger Tests
| ID | Method | Endpoint | Scenario | Expected Result |
|----|--------|----------|----------|-----------------|
| MAN-001 | POST | /api/v1/admin/scheduler/run | Trigger scheduler | Jobs queued immediately |
| MAN-002 | POST | /api/v1/admin/scheduler/run?siteId=1 | Trigger for site | Only site keywords queued |

### Logging Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| LOG-001 | Scheduler run logged | Run time, job count recorded |
| LOG-002 | Error during run | Error logged with details |
| LOG-003 | Scheduler history | Track last run times |

## Edge Cases
- No active keywords
- All keywords recently checked
- Very large site (1000+ keywords)
- Scheduler run overlaps (previous still running)
- Database connection lost during scheduling
- Config changes mid-schedule
