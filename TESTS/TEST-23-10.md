## Notes for Developer

### Route Registration
```php
// routes/api.php
Route::middleware(['auth:sanctum'])->group(function () {
    Route::get('/projects/{project}/backlinks/domains', [BacklinkDomainsController::class, 'domains']);
    Route::get('/projects/{project}/backlinks/anchors', [BacklinkAnchorsController::class, 'anchors']);
});
```

### Controller Structure
```php
class BacklinkDomainsController extends Controller
{
    public function __construct(
        private ReferringDomainRepository $domains
    ) {}
    
    public function domains(Request $request, Project $project): JsonResponse
    {
        $this->authorize('view', $project);
        
        $sort = $request->get('sort', 'backlinks_count');
        $perPage = min($request->get('perPage', 20), 100);
        
        $domains = $this->domains->paginate($project->id, $perPage, $sort);
        
        return response()->json([
            'data' => $domains->items(),
            'meta' => [
                'total' => $domains->total(),
                'page' => $domains->currentPage(),
                'perPage' => $domains->perPage(),
                'lastPage' => $domains->lastPage(),
            ],
        ]);
    }
}
```

### Model Requirements
Tests assume these models exist with these properties:
- `ReferringDomain`: project_id, domain, backlinks_count, domain_trust_score, first_seen_at, last_seen_at
- `AnchorText`: project_id, anchor_text, backlinks_count, is_branded, is_exact_match

### Percentage Calculation
```php
// In controller or service
$totalBacklinks = $project->backlinks()->count();
$anchors = AnchorText::where('project_id', $project->id)
    ->orderByDesc('backlinks_count')
    ->get()
    ->map(function ($anchor) use ($totalBacklinks) {
        $anchor->percentage = $totalBacklinks > 0 
            ? round(($anchor->backlinks_count / $totalBacklinks) * 100, 1)
            : 0;
        return $anchor;
    });
```
