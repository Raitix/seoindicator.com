# TEST-31-13: Update AnalysisRunnerService to Use Unified Prompt

## Task Reference
- **Task:** TASK-31-13
- **Specification:** SPEC-031
- **Feature:** FEAT-031

## Overview

Test suite for updating AnalysisRunnerService to use the unified AI prompt approach. The service transitions from 17+ individual AI calls to a single unified call that returns all indicator results plus an overall summary.

## Mock Interfaces

### AIAnalysisServiceInterface

```php
interface AIAnalysisServiceInterface
{
    /**
     * Execute unified AI analysis.
     *
     * @param string $url The URL being analyzed
     * @param string $html The HTML content to analyze
     * @param array $options Optional parameters
     * @return AnalysisResult The analysis result
     * @throws AIAnalysisException On analysis failure
     */
    public function analyze(string $url, string $html, array $options = []): AnalysisResult;
}
```

### AnalysisResult DTO

```php
class AnalysisResult
{
    public function __construct(
        public readonly int $overallScore,
        public readonly string $overallSummary,
        public readonly array $categoryScores,
        public readonly array $indicators,
        public readonly string $model,
        public readonly int $promptTokens,
        public readonly int $responseTokens,
        public readonly int $latencyMs,
        public readonly array $truncationStrategies = [],
        public readonly array $topPriorities = [],
    ) {}
    
    public static function fromArray(array $data): self;
    public function toArray(): array;
}
```
