# Test Documentation: SPEC-SEC-2026-02-21-5 — Purge Secrets from Git History

## Overview
Tests to verify git history is clean of secrets after BFG/git-filter-repo execution.

## Test Type
- **Primary:** Integration Tests (git operations)
- **Secondary:** Manual Verification

---

## ⚠️ WARNING: DESTRUCTIVE OPERATION

This task involves rewriting git history. All tests must pass BEFORE force-pushing to remote.

**Pre-execution checklist:**
- [ ] All collaborators notified
- [ ] Backup of repository created
- [ ] All other tasks (1-4) completed
- [ ] Secrets rotated (Task 2)

---

## Test Scenarios

### 1. No Secrets in Current History

**Test ID:** SEC-5.1  
**Type:** Integration  
**Priority:** Critical

**Description:** Verify no secrets exist in any commit in the repository.

**Preconditions:**
- Git history rewrite completed

**Test Steps:**
1. Run `git log --all --full-history -p | grep -E "APP_KEY=base64:"`
2. Run `git log --all --full-history -p | grep -E "DB_PASSWORD=[^your_]"`
3. Run `git log --all --full-history -p | grep -E "CLIENT_SECRET=[^your_]"`
4. Use `git secrets --scan-history` if available

**Expected Result:**
- No matches found in any commit
- All historical commits are clean

### 4. Git Reflog Cleaned

**Test ID:** SEC-5.4  
**Type:** Integration  
**Priority:** High

**Description:** Verify git reflog doesn't contain old commits with secrets.

**Preconditions:**
- History rewrite completed
- `git reflog expire --expire=now --all` executed
- `git gc --prune=now --aggressive` executed

**Test Steps:**
1. Run `git reflog`
2. Verify only post-rewrite commits visible
3. Run `git fsck --unreachable`
4. Verify no unreachable objects

**Expected Result:**
- Reflog shows only clean commits
- No unreachable objects with secrets

### Pre-Execution Requirements
1. **Backup:** Create full backup before starting
   ```bash
   git clone --mirror <repo-url> backup.git
   ```

2. Check forked repos (if any) - they retain old history
3. Verify GitHub Secret scanning alerts resolved

- Test with different BFG patterns
