## Notes for Developer

### Implementation Requirements

1. **Controller:**
   - `GET /api/v1/ai-visibility/export`
   - Query parameters: `format`, `project_id`, `project_ids[]`, `from`, `to`, `data_type`
   - Returns: StreamedResponse with file download

2. **Service:**
   - `ExportService` with `export()` method
   - Dependencies: `CsvExporter`, `XlsxExporter`
   - Permission checks before data retrieval

3. **CSV Exporter:**
   - Implements `ExporterInterface`
   - Uses `fputcsv()` with streaming
   - UTF-8 BOM for Excel compatibility

4. **XLSX Exporter:**
   - Implements `ExporterInterface`
   - Uses `maatwebsite/excel` package
   - Multiple sheets for multiple data types

### Rate Limiting

- Default: 10 exports per minute per user
- Configurable via `config/ai-visibility.php`

### File Naming Convention

```
ai-visibility-export-{YYYY-MM-DD-His}.{csv|xlsx}
```

### Large Dataset Handling

- Use chunking (1000 rows per chunk)
- Streaming for CSV (generator)
- Spreadsheet exporter for XLSX (chunked writes)
- Memory limit: 256MB
