### 7. Security Tests

| ID | Scenario | Attack Vector | Expected Behavior |
|----|----------|---------------|-------------------|
| SEC-001 | SQL injection in tool param | tool="'; DROP TABLE analyses;--" | 422 or stored as string |
| SEC-002 | SQL injection in ID | id="1 OR 1=1" | 404 Not Found |
| SEC-003 | XSS in input_url | url="<script>alert(1)</script>" | Sanitized/escaped |
| SEC-004 | XSS in results | results with script tags | Escaped in response |
| SEC-005 | Path traversal in ID | id="../1" | 404 Not Found |
| SEC-006 | Mass assignment | Extra fields in request | Ignored |
| SEC-007 | Rate limiting | 100+ requests/minute | 429 Too Many Requests |
| SEC-008 | IDOR with predictable IDs | Sequential ID enumeration | 403 for non-owned |
| SEC-009 | Session fixation | Reusing auth token | Token validated each request |
| SEC-010 | CSRF protection | Missing CSRF token | Blocked (Sanctum handles) |

```php
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/analyses', [AnalysisHistoryController::class, 'index']);
    Route::get('/analyses/{id}', [AnalysisHistoryController::class, 'show'])
        ->where('id', '[0-9]+');
    Route::delete('/analyses/{id}', [AnalysisHistoryController::class, 'destroy'])
        ->where('id', '[0-9]+');
    Route::get('/analyses/{id}/costs', [AnalysisHistoryController::class, 'costs'])
        ->where('id', '[0-9]+');
});
```
