## Notes for Developer

### Implementation Notes

1. **API Client Location:** Create `frontend/lib/api/ai-suggestions.ts` with `getAISuggestion()` and `getAISuggestionWithDebug()` functions.

2. **Types Location:** Create `frontend/lib/types/ai-suggestions.ts` with `SuggestionResult`, `Suggestion`, `DebugInfo`, and `DebugSuggestionResult` types.

3. **Component Location:**
   - `frontend/components/tools/AISuggestionButton.tsx`
   - `frontend/components/tools/AISuggestionPanel.tsx`

4. **Rate Limit Handling:** The button should disable itself when rate limited and show a countdown until the next request is allowed.

5. **Error States:**
   - Network error: Show retry button
   - Rate limit: Show countdown timer
   - Server error: Show generic error with retry option
   - Fallback: Show warning banner with reason

6. **Accessibility:**
   - All buttons must have aria-labels
   - Focus management after suggestion load
   - Screen reader announcements for new content
   - Keyboard navigation support

7. **Testing Approach:**
   - Mock `fetch` globally for API tests
   - Use `@testing-library/react` for component tests
   - Mock timers for rate limit countdown tests
   - Use `userEvent` for interaction tests
