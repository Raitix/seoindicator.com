## Overview
Comprehensive test suite for the frontend PayPal payment flow. Tests cover PayPal JS SDK integration, Smart Buttons (popup flow), redirect flow option, API integration with order/capture endpoints, error handling, loading states, and balance updates. ### PayPal Button Configuration
```typescript
// Standard Smart Button configuration
paypal.Buttons({
  // Called when user clicks PayPal button
  createOrder: async () => {
    const response = await fetch('/api/v1/payments/paypal/order', {
      method: 'POST',
      body: JSON.stringify({ package_id: selectedPackage.id })
    });
    const data = await response.json();
    return data.order_id; // PayPal expects order ID string
  },
  
  // Called when user approves payment in popup
  onApprove: async (data) => {
    const response = await fetch('/api/v1/payments/paypal/capture', {
      method: 'POST',
      body: JSON.stringify({ order_id: data.orderID })
    });
    const result = await response.json();
    if (result.success) {
      onSuccess(result);
    }
  },
  
  // Called when user cancels without approving
  onCancel: (data) => {
    onCancel(data);
  },
  
  // Called when an error occurs
  onError: (err) => {
    onError(err);
  }
}).render('#paypal-button-container');
```

### Redirect Flow Implementation
```typescript
// For redirect flow, store order info before redirect
const handleRedirectPayment = async () => {
  const response = await createPayPalOrder(package.id, successUrl, cancelUrl);
  
  // Store order ID for return validation
  sessionStorage.setItem('paypal_order_id', response.order_id);
  
  // Redirect to PayPal
  window.location.href = response.approval_url;
};

// On return page, capture the order
useEffect(() => {
  const params = new URLSearchParams(window.location.search);
  const token = params.get('token');
  const payerId = params.get('PayerID');
  
  if (token && payerId) {
    capturePayPalOrder(token);
  }
}, []);
```
