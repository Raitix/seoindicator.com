## Task Reference

- Stage: PreTester
- Status after test design: `To Develop`

## Overview
Production validation showed `GET /api/v1/sites/{siteId}/locations` returning a generic Laravel `500 Server Error` page instead of the expected protected-route JSON contract.

This test pack locks the failure down at two levels:
1. **Backend production-regression coverage** for guest, owner, non-owner, missing-site, empty-list, and schema/config drift scenarios.
2. **Frontend endpoint-state coverage** so `/sites/{siteId}/local` can render real empty/error UI when the endpoint returns valid JSON instead of crashing HTML.

## Coverage Intent
The endpoint has already shown multiple production-only failure modes during this incident chain:
- controller construction failing when real Google OAuth config is missing
- schema drift around `business_locations.deleted_at`
- wrong response shape/status for guest and authorization failures
- empty-state list rendering blocked because the page never received a normalized JSON payload

These tests keep all of those regression surfaces pinned down.
