## Notes for Developer

1. **Component Files to Create:**
   - `frontend/components/dashboard/BadgeAnalyticsDashboard.tsx`
   - `frontend/components/dashboard/BadgeStatsCard.tsx`

2. **Props Interface:**
   ```typescript
   interface BadgeAnalyticsDashboardProps {
     siteId?: string;
     stats?: BadgeStats;
     impressionsData?: TimeSeriesPoint[];
     clicksData?: TimeSeriesPoint[];
     topReferrers?: TopReferrer[];
     topAudits?: TopAudit[];
     dateRange?: PresetRange;
     customDateRange?: DateRange;
     onDateRangeChange?: (range: PresetRange, custom?: DateRange) => void;
     isLoading?: boolean;
     error?: string | null;
     className?: string;
   }
   ```

3. **Recharts Usage:**
   - Use `ResponsiveContainer` for chart responsiveness
   - `LineChart` with `Line`, `XAxis`, `YAxis`, `Tooltip`
   - Consider `CartesianGrid` for visual clarity

4. **Date Range Selector:**
   - Can reuse `DateRangeSelector` from admin components
   - Or create simplified version for badge analytics

5. **API Integration:**
   - Fetch data from analytics API (TASK-33-28)
   - Consider React Query or SWR for caching
   - Handle loading and error states
