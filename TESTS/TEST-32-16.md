## Notes for Developer

### TDD Pattern
Tests are designed to FAIL until implementation is complete. The mock components in integration tests demonstrate the expected interfaces.

### Implementation Order
1. **RelatedComparisons component** - Create `frontend/components/compare/RelatedComparisons.tsx`
2. **Footer modification** - Add "Compare SEO Tools" link to Resources column
3. **Homepage section** - Add "How We Compare" section before footer
4. **Pricing page section** - Add "Compare with Alternatives" section

### Key Implementation Points
1. Use Next.js `Link` component for client-side navigation
2. Ensure all links are crawlable (not JavaScript-only)
3. Use `COMPARISON_SLUGS` from registry for consistent data
4. Consider adding UTM parameters for tracking (optional)

### Accessibility Requirements
- All sections must have `aria-label` attributes
- Links must have accessible text (not just icons)
- Sections should have proper heading hierarchy (h2)
- Callouts should have `role="complementary"`
