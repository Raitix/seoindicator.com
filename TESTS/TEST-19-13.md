## Test Scenarios

### 1. Network Timeout Handling

#### 1.1 Timeout Detection
- [ ] Detects connection timeout (30s default)
- [ ] Detects read timeout
- [ ] Logs timeout with URL and duration

#### 1.2 Timeout Recovery
- [ ] Marks indicator as failed
- [ ] Continues with other indicators
- [ ] Job completes with partial results

### 2. Invalid URL Handling

#### 2.1 Format Validation
- [ ] Validates URL format before processing
- [ ] Rejects malformed URLs
- [ ] Returns clear error message

#### 2.2 DNS Failures
- [ ] Handles DNS resolution failure
- [ ] Marks indicator as failed
- [ ] Continues with others

### 3. Rate Limiting Detection

#### 3.1 429 Response Handling
- [ ] Detects 429 from target sites
- [ ] Extracts Retry-After header
- [ ] Implements exponential backoff

#### 3.2 Retry Logic
- [ ] Single retry after backoff
- [ ] Maximum backoff time (60s)
- [ ] Logs retry attempt

### 4. Memory Exhaustion Handling

#### 4.1 Memory Monitoring
- [ ] Monitors worker memory usage
- [ ] Detects approaching limit
- [ ] Logs memory warnings

#### 4.2 Recovery Actions
- [ ] Kills worker at 90% limit
- [ ] Marks indicator as failed
- [ ] Restarts worker

### 5. Partial Job Completion

#### 5.1 Mixed Results
- [ ] Job completes with some failed indicators
- [ ] Final status reflects partial success
- [ ] Users can see which failed and why

#### 5.2 Success Threshold
- [ ] Job marked as completed if > 50% success
- [ ] Job marked as failed if < 50% success
- [ ] All indicators visible regardless

### 6. User-Friendly Error Messages

#### 6.1 Message Format
- [ ] No technical jargon
- [ ] Clear action items
- [ ] Localizable

#### 6.2 Error Categories
- [ ] Network errors → "Unable to connect"
- [ ] Timeout → "Analysis took too long"
- [ ] Invalid URL → "Invalid website address"

### 7. Error Logging

#### 7.1 Log Structure
- [ ] Includes job ID
- [ ] Includes indicator slug
- [ ] Includes URL
- [ ] Includes error details
- [ ] Includes timestamp

#### 7.2 Log Channels
- [ ] Separate channel for analysis errors
- [ ] Not mixed with application errors
- [ ] Searchable

### 8. Integration Tests

#### 8.1 Error Scenarios
- [ ] All indicators fail → job failed
- [ ] Some indicators fail → job completed
- [ ] Network down → graceful failure

#### 8.2 Recovery Scenarios
- [ ] Temporary network issue → retry succeeds
- [ ] Rate limit → backoff succeeds
- [ ] Memory pressure → worker restarts
