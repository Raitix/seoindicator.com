## Test Scenarios

### Title Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| TE-01 | Title present | `<title>Page Title</title>` | exists: true |
| TE-02 | Title missing | No title tag | exists: false, score: 1 |
| TE-03 | Empty title | `<title></title>` | exists: true, empty: true |
| TE-04 | Whitespace title | `<title>   </title>` | exists: true, empty: true |
| TE-05 | Multiple titles | Two title tags | uses first, warning |

### Title Length Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| TL-01 | Too short (< 40 chars) | `<title>Short</title>` | length: 5, isOptimalLength: false |
| TL-02 | Sub-optimal (40-49 chars) | `<title>This is a forty character title here</title>` | length: 40, isOptimalLength: false |
| TL-03 | Optimal (50-60 chars) | `<title>This is the optimal title length for SEO purposes</title>` | length: 55, isOptimalLength: true |
| TL-04 | Acceptable (61-70 chars) | `<title>This is a slightly longer but still acceptable title for SEO</title>` | length: 67, isOptimalLength: false |
| TL-05 | Too long (> 70 chars) | `<title>This is a very long title that exceeds the recommended length for SEO best practices</title>` | length: 93, isOptimalLength: false |
| TL-06 | Exact 50 chars | `<title>This is exactly fifty characters title for SEO</title>` | length: 50, isOptimalLength: true |
| TL-07 | Exact 60 chars | `<title>This is exactly sixty characters title for SEO test</title>` | length: 60, isOptimalLength: true |

## Expected Result Structure

```php
new IndicatorResult(
    id: 'title_tag',
    name: 'Title Tag',
    category: 'content',
    score: 3,
    weight: 0.10,
    passed: true,
    details: [
        'exists' => true,
        'title' => 'SEO Services London | Best SEO Agency UK',
        'length' => 42,
        'isOptimalLength' => false,
        'hasKeywords' => true,
        'keywordCount' => 2,
        'isUnique' => null, // Cannot verify in single-page analysis
    ],
    suggestions: [
        [
            'type' => 'warning',
            'message' => 'Title length (42 chars) is below optimal (50-60 chars).',
            'action' => 'Add more descriptive text including target keywords.',
        ]
    ]
);
```
