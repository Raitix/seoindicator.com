## Test Scenarios

### Internal Links Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| IL-01 | Internal links present | Links to same domain | internalCount: N |
| IL-02 | No internal links | Only external links | internalCount: 0 |
| IL-03 | Relative internal links | `/page`, `page.html` | counted as internal |
| IL-04 | Anchor links | `#section` | counted separately |
| IL-05 | Subdomain links | `blog.example.com` | May count as external |

### External Links Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| EL-01 | External links present | Links to other domains | externalCount: N |
| EL-02 | No external links | Only internal links | externalCount: 0 |
| EL-03 | External with nofollow | `rel="nofollow"` | nofollowExternal: N |
| EL-04 | External with sponsored | `rel="sponsored"` | detected |

### Broken Links Tests (Sample Check)

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|

| BL-02 | Some broken links | Some return 404 | brokenCount: N |
| BL-03 | Timeout on check | Request timeout | Handled gracefully |
| BL-04 | Sample check limit | 100+ links | Sample first 20 |

### Nofollow Usage Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
