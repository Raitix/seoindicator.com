## Adversarial Test Cases

### Security: SSRF via DNS Rebinding
- **Description:** Attacker controls DNS that alternates between public/private IPs
- **Test:** Resolve at request time, not cache DNS result
- **Expected:** Block if resolved IP is private at request time

### Security: SSRF via Redirect
- **Description:** Valid domain redirects to internal IP
- **Test:** Follow redirect, validate final destination IP
- **Expected:** Block redirect to private IP

### Security: SSRF via IPv6 mapped IPv4
- **Description:** Use IPv6 mapped address to bypass filter
- **Test:** `::ffff:127.0.0.1` or `::ffff:192.168.0.1`
- **Expected:** Block mapped addresses

### Security: SSRF via URL Encoding
- **Description:** Encode domain characters to bypass filters
- **Test:** `%31%32%37%2e%30%2e%30%2e%31` (127.0.0.1 encoded)
- **Expected:** Decode and validate

### Security: Timing Attack on DNS
- **Description:** Measure DNS response time to infer internal network
- **Test:** Ensure constant time responses
- **Expected:** No timing leakage
