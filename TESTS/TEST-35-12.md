# TEST-35-12: Local SEO Alert Service Tests

## Overview

Test suite for `LocalSEOAlertService` - a coordinator service that generates alerts based on data from other services (LocalRankService, GBPReviewsService, GBPInsightsService). Tests cover all 7 alert types, deduplication, CRUD operations, and queue integration.

## Notes for Developer

### Interface Mocking
All three dependency services should be mocked via interfaces:
- `LocalRankServiceInterface`
- `GBPReviewsServiceInterface`  
- `GBPInsightsServiceInterface`

### Deduplication Implementation
Deduplication should check for existing alerts with:
- Same `alert_type`
- Same `business_location_id`
- Created within last 24 hours (`created_at >= NOW() - INTERVAL 24 HOUR`)

2. Event dispatch for notification system
