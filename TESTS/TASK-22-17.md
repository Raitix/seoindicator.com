## Notes for Developer

### Implementation Checklist

1. **Config Changes** (`config/crawler.php`):
   - Add `timeouts` array with job, page, browser, connection, grace_period
   - All values configurable via environment variables

2. **TimeoutHandlerService** (`app/Services/Crawler/TimeoutHandlerService.php`):
   - Tracks start time, elapsed time, remaining time
   - Methods: `startTracking()`, `stopTracking()`, `isApproachingTimeout()`, `shouldStartGracefulShutdown()`

3. **CancellationService** (`app/Services/Crawler/CancellationService.php`):
   - Uses cache for cancellation flags
   - Methods: `requestCancellation()`, `isCancellationRequested()`, `shouldCancel()`
   - Atomic cache operations for race condition safety

4. **PartialResultsService** (`app/Services/Crawler/PartialResultsService.php`):
   - Stores crawled pages with timeout/cancel reason
   - Generates partial content URLs

5. **CrawlWorker Updates**:
   - Check timeout before each page
   - Check cancellation flag before each page
   - Graceful shutdown when approaching timeout
   - Resource cleanup on timeout/cancel

6. **API Endpoint**:
   - `DELETE /api/v1/crawler/jobs/{jobId}` → 202 Accepted
   - Authorization via CrawlJobPolicy

7. **CrawlJob Model**:
   - Add `cancelled_at` column if missing
   - Add `canBeCancelled()` method (exists)
   - Add `reason` field for partial results
