## Notes for Developer

1. **TDD Approach:** Tests are written first. Run tests to see failures, then implement to pass.

2. **Mocking Strategy:**
   - Use Laravel's `Cache::fake()` for cache tests
   - Use `Http::fake()` for external API tests
   - Use Mockery for service mocking
   - Use factory states for different user types

3. **Test Data:**
   - UserFactory has `admin()` and `superAdmin()` states
   - CreditFactory and CreditTransactionFactory should be used
   - Use RefreshDatabase trait for database tests

4. **Performance Testing:**
   - Run on production-like dataset for accurate results
   - Use database transactions for isolation
   - Measure with Laravel Telescope or external profiling

5. **Security Testing:**
   - Test actual middleware, not just controller
   - Verify rate limiting at route level
   - Check PII exclusion in all endpoints
