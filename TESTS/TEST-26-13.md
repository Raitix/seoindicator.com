## Request/Response Schema

### Request Body
```json
{
  "package_id": 2,
  "return_url": "https://example.com/credits/success",
  "cancel_url": "https://example.com/credits/cancelled"
}
```

### Success Response (200)
```json
{
  "success": true,
  "data": {
    "order_id": "5O190127TN364715T",
    "approval_url": "https://www.paypal.com/checkoutnow?token=5O190127TN364715T",
    "amount": 10.00,
    "credits": 10.50,
    "package_name": "Basic"
  }
}
```

### Error Responses
| Status | Description |
|--------|-------------|
| 401 | Unauthorized (not authenticated) |
| 422 | Validation error (invalid input) |
| 400 | Bad Request (package inactive) |
| 500 | Internal Server Error (PayPal failure) |

## Notes for Developer

### Implementation Requirements
1. Controller: `app/Http/Controllers/Api/V1/Payments/PayPalOrderController.php`
2. Route: `Route::post('payments/paypal/order', [PayPalOrderController::class, 'create']);`
3. Request validation: Use FormRequest or inline validation
4. Service injection: `PayPalGatewayService` via constructor

### Key Implementation Points
- Price MUST be read from database (not request body)
- Credits calculated as: `base_credits * (1 + bonus_percent/100)`
- Create pending transaction record with order_id
- Return order_id and approval_url for frontend redirect
- Log all PayPal API calls for debugging

### PayPalGatewayService Interface
```php
interface PaymentGatewayInterface
{
    public function createPaymentIntent(User $user, float $amount, string $currency = 'USD', array $metadata = []): array;
    // Returns: ['order_id' => '...', 'approval_url' => '...']
}
```

### Transaction Table (if needed)
```sql
CREATE TABLE payment_transactions (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,
    package_id BIGINT UNSIGNED NOT NULL,
    order_id VARCHAR(255) NOT NULL,
    amount DECIMAL(10, 2) NOT NULL,
    credits DECIMAL(10, 2) NOT NULL,
    status ENUM('pending', 'completed', 'failed', 'refunded') DEFAULT 'pending',
    provider VARCHAR(20) DEFAULT 'paypal',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (package_id) REFERENCES credit_packages(id)
);
```
