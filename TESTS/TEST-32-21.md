## Running Tests

```bash
# Run all comparison tests
npx playwright test comparison.spec.ts

# Run with UI
npx playwright test comparison.spec.ts --ui

# Run specific test
npx playwright test comparison.spec.ts -g "E2E-CMP-001"

# Run mobile tests only
npx playwright test comparison.spec.ts --project=chromium --grep "Mobile"
```

## Test Data

Tests use:
- `PRIMARY_COMPARISON_SLUG`: `seoindicator-vs-ahrefs`
- `CROSS_COMPETITOR_SLUG`: `ahrefs-vs-moz` (valid cross-competitor from registry)
- Expected primary comparisons: 7 (seoindicator-vs-*)

## Notes

- Tests designed to work with existing Playwright configuration
- Mobile tests use 375x667 viewport (iPhone SE size)
- Tablet tests use 768x1024 viewport (iPad size)
- Performance thresholds: 5s for index, 3s for comparison pages (dev server tolerance)
- All tests use `data-testid` attributes for stable selectors
- Comparison table uses `role="table"` with div elements (not native `<table>`)
- Main content test targets `main[aria-label="Comparison page"]` to avoid layout wrapper conflicts

## Dependencies

- Playwright test runner
- Existing comparison page implementation
- Compare registry data
