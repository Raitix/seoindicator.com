## Notes for Developer

1. **Controller Location:** `app/Http/Controllers/Api/V1/ContentRetrievalController.php`
2. **Routes:** Extend existing `/api/v1/crawler/jobs/{jobId}/` routes
3. **Service:** Create `ContentRetrievalService` for complex logic
4. **Cache:** Use Laravel Cache with 1-hour TTL
5. **Streaming:** Use `StreamedResponse` for large jobs
6. **Field Whitelist:** Validate include/exclude against: `url`, `depth`, `title`, `renderedHtml`, `structuredText`, `meta`, `links`, `size`, `crawledAt`
7. **IDOR Protection:** Always verify user owns the job via `user_id` check
8. **Pagination:** Default 50, max 100 per page
