## Response Format

### GET Success (existing branding)
```json
{
  "success": true,
  "data": {
    "siteId": 1,
    "logoUrl": null,
    "primaryColor": "#2563eb",
    "secondaryColor": "#64748b",
    "fontFamily": "Inter",
    "companyName": "ACME Corp",
    "companyWebsite": "https://acme.com",
    "createdAt": "2026-03-12T19:00:00.000000Z",
    "updatedAt": "2026-03-12T19:00:00.000000Z"
  }
}
```

### GET Success (defaults, no record)
```json
{
  "success": true,
  "data": {
    "siteId": 1,
    "primaryColor": "#2563eb",
    "secondaryColor": "#64748b",
    "fontFamily": "Inter"
  }
}
```

### PUT Success
```json
{
  "success": true,
  "data": {
    "siteId": 1,
    "logoUrl": null,
    "primaryColor": "#ef4444",
    "secondaryColor": "#3b82f6",
    "fontFamily": "Open Sans",
    "companyName": "Test Company",
    "companyWebsite": "https://test.com",
    "createdAt": "2026-03-12T19:00:00.000000Z",
    "updatedAt": "2026-03-12T19:00:00.000000Z"
  }
}
```

### Error Responses

| Code | Condition | Response |
|------|-----------|----------|
| 401 | Not authenticated | `{"success": false, "message": "Unauthenticated."}` |
| 403 | User doesn't own site | `{"success": false, "error": {"code": "FORBIDDEN", "message": "..."}}` |
| 404 | Site not found | `{"success": false, "error": {"code": "NOT_FOUND", "message": "..."}}` |
| 422 | Validation error | `{"success": false, "message": "...", "errors": {...}}` |
