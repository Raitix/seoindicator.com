## API Specification

### Endpoint
```
POST /api/v1/badge/impression
```

### Request Body
```json
{
  "hash": "abc123def456...",  // Required: 32-char alphanumeric public hash
  "referrer_domain": "example.com"  // Optional: referrer domain
}
```

### Response Codes
| Code | Condition |
|------|-----------|
| 204 No Content | Success - impression recorded |
| 404 Not Found | Invalid hash or non-public audit |
| 422 Unprocessable Entity | Validation error |
| 429 Too Many Requests | Rate limit exceeded (10 req/min per IP) |

### Rate Limiting
- **Limit:** 10 requests per minute per IP
- **Key:** IP address
- **Headers:** `X-RateLimit-Limit`, `X-RateLimit-Remaining`

## Notes for Developer

### Implementation Requirements

1. **Controller Structure:**
```php
class BadgeImpressionController extends Controller
{
    public function store(BadgeImpressionRequest $request): JsonResponse|Response
    {
        // Find audit by hash
        // Validate is_public
        // Extract referrer from request or Referer header
        // Hash IP address
        // Create BadgeImpression record
        // Return 204 No Content
    }
}
```

2. **Request Validation:**
```php
class BadgeImpressionRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'hash' => ['required', 'string', 'regex:/^[a-zA-Z0-9]{32}$/'],
            'referrer_domain' => ['nullable', 'string', 'max:255'],
        ];
    }
}
```

3. **Route Registration:**
```php
Route::post('/badge/impression', [BadgeImpressionController::class, 'store'])
    ->middleware('throttle:10,1')
    ->name('api.v1.badge.impression');
```

4. **IP Hashing:**
```php
$ipHash = BadgeImpression::hashIp($request->ip());
```

5. **Referrer Extraction:**
```php
// Priority: request body > Referer header
$referrerDomain = $request->input('referrer_domain') 
    ?? BadgeImpression::extractDomain($request->header('Referer'));
```

### Security Considerations

- Never log IP addresses in plain text
- Never expose audit details in error responses
- Return same 404 for non-existent and non-public audits (prevents enumeration)
- Rate limit per IP to prevent abuse
