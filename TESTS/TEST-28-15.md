- **Color:** Single color, inherits from text color
- **Style:** Match Lucide icons for visual consistency

## Notes for Developer

### When to Create Custom Icons
1. **Start with Lucide** - Use Lucide icons as the primary source
2. **Check Lucide catalog** - Verify Lucide doesn't have a suitable alternative
3. **SEO-specific needs** - Only create when Lucide lacks SEO-specific iconography

### Design Checklist
- [ ] viewBox="0 0 24 24" on root SVG
- [ ] stroke-width="2" on paths
- [ ] rx="1" on rectangles for rounded corners
- [ ] stroke="currentColor" for color inheritance
- [ ] fill="none" on stroke-based icons
- [ ] stroke-linecap="round" for smooth ends
- [ ] stroke-linejoin="round" for smooth corners

### File Structure
```
frontend/components/icons/custom/
├── index.ts           # Barrel export
├── registry.ts        # CUSTOM_ICONS registry
├── types.ts           # CustomIconName type
└── [icon-name].tsx    # Individual icon components (as needed)
```

### Integration Pattern
```tsx
import { IndicatorIcon } from '@/components/indicators';
import { CUSTOM_ICONS } from '@/components/icons/custom';

// Use custom icon
<IndicatorIcon 
  customIcon={<CUSTOM_ICONS['robot-indicator'] />} 
  size="md" 
/>
```
