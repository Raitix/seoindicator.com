## Notes for Developer

### Implementation Requirements

1. **Create `frontend/app/sitemap.ts`:**
   ```typescript
   import { MetadataRoute } from 'next';
   import { COMPARISON_SLUGS } from '@/lib/compare/registry';

   export default function sitemap(): MetadataRoute.Sitemap {
     const baseUrl = 'https://seoindicator.com';

     // Comparison slug pages
     const comparisonEntries = COMPARISON_SLUGS.map((slug) => ({
       url: `${baseUrl}/compare/${slug}/`,
       lastModified: new Date(),
       changeFrequency: 'monthly' as const,
       priority: 0.8,
     }));

     // Comparison index page
     const indexEntry = {
       url: `${baseUrl}/compare/`,
       lastModified: new Date(),
       changeFrequency: 'weekly' as const,
       priority: 0.7,
     };

     return [
       // ... existing entries
       indexEntry,
       ...comparisonEntries,
     ];
   }
   ```

2. **Create or update `frontend/app/robots.ts`:**
   ```typescript
   import { MetadataRoute } from 'next';

   export default function robots(): MetadataRoute.Robots {
     return {
       rules: {
         userAgent: '*',
         allow: ['/'],
       },
       sitemap: 'https://seoindicator.com/sitemap.xml',
     };
   }
   ```

### Key Points

- **Priority 0.8** for comparison slug pages (high conversion value)
- **Priority 0.7** for comparison index page (navigation hub)
- **Monthly frequency** for slug pages (stable competitor data)
- **Weekly frequency** for index page (new comparisons added)
- Trailing slashes required for all comparison URLs
- COMPARISON_SLUGS from TASK-32-2 registry module

### Sitemap Protocol Compliance

- URLs must be absolute (https://)
- priority: 0.0 to 1.0
- changeFrequency: always, hourly, daily, weekly, monthly, yearly, never
- lastModified: W3C Datetime (ISO 8601) or Date object
- Max 50,000 URLs per sitemap
- Max 50MB uncompressed per sitemap
