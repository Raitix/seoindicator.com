## Mock Data

### Accessible Page
```html
<!DOCTYPE html>
<html lang="en">
<body>
  <header role="banner">
    <nav role="navigation" aria-label="Main menu">
      <a href="/">Home</a>
    </nav>
  </header>
  
  <main role="main">
    <h1>Page Title</h1>
    <form>
      <label for="search">Search</label>
      <input id="search" type="text" aria-label="Search">
      <button type="submit">Search</button>
    </form>
  </main>
  
  <footer role="contentinfo">
    <p>&copy; 2024 Company</p>
  </footer>
</body>
</html>
```
