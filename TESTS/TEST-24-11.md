}

### Required Sizes

| Size | Status | Notes |
|------|--------|-------|
| 192x192 | **Required** | PWA minimum |
| 512x512 | **Required** | Splash screen |
| Other sizes | Recommended | Enhanced UX |

### Status Indicators

| Status | Color | Icon | Description |
|--------|-------|------|-------------|
| valid | Green | ✓ checkmark | Icon exists and is valid |
| invalid | Red | ✗ X | Icon exists but has issues |
| missing | Yellow | ⚠ warning | Icon file not found |

### Error Message Types

| Error Type | Example Message |
|------------|-----------------|
| Not Found | "Icon file not found (404)" |
| Invalid Format | "Invalid format: expected PNG, got SVG" |
| Size Mismatch | "Declared 192x192 but actual is 180x180" |
| Too Large | "Icon exceeds 512KB limit (1.2MB)" |
