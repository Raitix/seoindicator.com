## Test Cases

### Test 1: Extend RankCheckerService - Accept Competitor Domains
- **Type:** Unit
- **Description:** Verify RankCheckerService can accept competitor domains parameter
- **Preconditions:** RankCheckerService exists
- **Steps:**
  1. Create RankCheckerService instance
  2. Call checkKeyword with competitorDomains parameter
  3. Verify method accepts array of competitor domains
- **Expected Result:** Method accepts competitor domains without error

### Test 2: Fetch Rankings for Single Competitor
- **Type:** Unit (with mocking)
- **Description:** Verify competitor ranking is fetched alongside user ranking
- **Preconditions:** RankCheckerService with mocked SERP fetcher
- **Steps:**
  1. Mock SERP response with positions for user domain and competitor
  2. Call checkKeyword with keyword and competitor domain
  3. Verify both rankings are returned
- **Expected Result:**
  ```php
  [
    'user' => ['position' => 5, 'url' => 'https://user.com/page'],
    'competitors' => [
      ['domain' => 'competitor.com', 'position' => 8, 'url' => 'https://competitor.com/page']
    ]
  ]
  ```

### Test 3: Fetch Rankings for Multiple Competitors
- **Type:** Unit (with mocking)
- **Description:** Verify rankings for multiple competitors are fetched
- **Preconditions:** RankCheckerService with mocked SERP fetcher
- **Steps:**
  1. Mock SERP response with positions for user + 3 competitors
  2. Call checkKeyword with 3 competitor domains
  3. Verify all 4 rankings are returned
- **Expected Result:** Returns rankings for user and all 3 competitors

### Test 4: Store Competitor Rankings in Database
- **Type:** Integration
- **Description:** Verify competitor rankings are stored in competitor_rankings table
- **Preconditions:** All tables exist, RankCheckerService instantiated
- **Steps:**
  1. Create keyword, user, and competitor records
  2. Run rank check with competitor
  3. Query competitor_rankings table
  4. Verify record created with correct data
- **Expected Result:** Competitor ranking stored with:
  - competitor_id
  - keyword_id
  - position
  - url
  - checked_at

### Test 5: Handle Competitor Not Ranking
- **Type:** Unit

- **Steps:**

  2. Run rank check

- **Expected Result:**
