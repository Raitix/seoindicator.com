### API Mocking
API calls are mocked using MSW or jest.mock:

```typescript
// Mock the API hook
vi.mock('@/lib/hooks/useComparisonData', () => ({
  useComparisonData: vi.fn((projectId: string) => ({
    data: mockComparisonData,
    isLoading: false,
    error: null,
    refetch: vi.fn(),
  })),
}));
```
