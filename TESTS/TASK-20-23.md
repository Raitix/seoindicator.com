## Implementation Notes for Developer

### Tool Slug Mapping
The mobile-friendly guide uses `toolSlug: 'mobile-friendly-checker'` in the registry. The ToolEmbed component must recognize this slug.

**Valid slugs for ToolEmbed:**
- `meta-tag-analyzer`
- `keyword-density`
- `social-preview`
- `mobile-friendly-checker`

### Guide Page Structure
```
Mobile-Friendly Guide Page
├── GuideHero
├── GuideSection: What is Mobile-Friendliness?
├── GuideSection: Mobile-First Indexing
├── GuideSection: Responsive Design Principles
├── GuideSection: Common Mobile SEO Issues
├── GuideSection: Testing Your Site
├── ToolEmbed (toolSlug="mobile-friendly-checker")  ← INSERT HERE
├── GuideChecklist
└── RelatedGuides
```

### Component Usage
```tsx
<ToolEmbed
  toolSlug="mobile-friendly-checker"
  title="Test Your Site's Mobile-Friendliness"
  description="Enter your URL to check if your page is mobile-friendly"
  showCta={true}
  ctaText="Use Full Mobile-Friendly Checker"
/>
```

### Routes
- Guide page: `/seo-guides/mobile-friendly/`
- Full tool page: `/tools/mobile-friendly-checker/`
