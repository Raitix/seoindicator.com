# TEST: API Endpoint Health and GSC

## Overview
Validation tests for API routes `/api/health`, `/api/v1/projects/{projectId}/gsc`, and `/api/v1/projects/{projectId}/gsc/opportunities` as defined in TASK-12-12.

## Test Cases

### 1. `/api/health`
**Description:** Ensure the `/api/health` endpoint is accessible and returns a valid health status.
**Test Steps:**
1. Send a `GET` request to `/api/health`.
2. Assert the HTTP response code is `200`.
3. Validate the returned JSON has `status: "ok"`.

### 2. `/api/v1/projects/{projectId}/gsc`
**Description:** Validate the authorization logic for the GSC endpoint.
**Test Steps:**
1. Send a `GET` request to replace the placeholder `{projectId}` with `1234`.
2. Assert the HTTP response returns `401` or `403` when not authenticated.

### 3. `/api/v1/projects/{projectId}/gsc/opportunities`
**Description:** Similar unauthenticated access validation for the opportunities sub-endpoint.
**Test Steps:**
1. Send a `GET` for {`projectId: 1234`}.
2. Check 401 Refluxes Cases
