## Notes for Developer

1. **Component Structure:**
   - Use React Query for data fetching
   - Implement skeleton loading states
   - Handle partial data failures gracefully

2. **Authentication:**
   - Check `isAuthenticated` before rendering
   - Redirect to `/login` if not authenticated
   - Show loading state during auth check

3. **Responsive Design:**
   - Use Tailwind responsive classes
   - Stats grid: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4`
   - Consider card view for analyses on mobile

4. **Error Handling:**
   - Provide retry functionality
   - Show partial data when some sections fail
   - Use error boundaries for critical failures

5. **Accessibility:**
   - Proper heading hierarchy
   - ARIA labels on interactive elements
   - Keyboard navigation support
   - Focus management

6. **API Integration:**
   - Endpoint: `GET /api/v1/dashboard`
   - Response includes stats, costSummary, recentAnalyses, quickInsights
   - See SPEC-025 for full API specification
