## Security Considerations (CRITICAL)

1. **NEVER trust webhook payload** - Always verify signature via PayPal headers
2. **Certificate chain validation** - Verify PAYPAL-CERT-URL is from PayPal domain
3. **Timing-constant comparison** - Use secure comparison for signatures
4. **Log all attempts** - For audit and debugging (mask sensitive data)
5. **Idempotency** - Prevent double-charges from webhook retries
6. **Response time** - Must respond within 5 seconds (PayPal retries on timeout)
7. **No sensitive data in logs** - Never log client secrets, tokens, or PII
8. **Amount validation** - Verify capture amount matches original order
9. **User validation** - Verify user exists before adding credits

## PayPal Webhook Signature Verification Algorithm

```php
// 1. Get required headers
$transmissionId = $request->header('PAYPAL-TRANSMISSION-ID');
$transmissionTime = $request->header('PAYPAL-TRANSMISSION-TIME');
$certUrl = $request->header('PAYPAL-CERT-URL');
$signature = $request->header('PAYPAL-TRANSMISSION-SIG');
$authAlgo = $request->header('PAYPAL-AUTH-ALGO');

// 2. Validate certificate URL is from PayPal
if (!str_starts_with($certUrl, 'https://api.paypal.com/') && 
    !str_starts_with($certUrl, 'https://api.sandbox.paypal.com/')) {
    throw new InvalidSignatureException('Invalid certificate URL');
}

// 3. Fetch PayPal certificate
$certificate = file_get_contents($certUrl);

// 4. Construct expected signature string
$expectedSig = $transmissionId . '|' . $transmissionTime . '|' . $webhookId . '|' . crc32($body);

// 5. Verify signature using certificate
$verified = openssl_verify(
    $expectedSig,
    base64_decode($signature),
    $certificate,
    OPENSSL_ALGO_SHA256
);

// 6. Return result
return $verified === 1;
```

## Notes for Developer

1. **Controller Location:** `app/Http/Controllers/Api/V1/Payment/PayPalWebhookController.php`
2. **Service Location:** `app/Services/Gateway/PayPalWebhookService.php` (or use PayPalGatewayService->handleWebhook())
3. **Route:** `POST /api/v1/payments/paypal/webhook`
4. **No authentication middleware** - PayPal signs requests with headers
5. **Use PayPal SDK for signature verification** or implement custom verification
6. **Database transactions** for atomic balance updates
7. **Response timing is critical** - PayPal retries webhooks until 200 received
8. **custom_id format:** `user_{userId}_package_{packageId}`

### Log Structure
```php
Log::info('PayPal webhook received', [
    'event_id' => $event->id,
    'event_type' => $event->event_type,
    'processing_time_ms' => $processingTime,
    'status' => 'success',
    'user_id' => $userId,
]);
```

### Response Timing
- PayPal expects response within 5 seconds
- For long operations, return 200 immediately and process asynchronously
- PayPal will retry webhook up to 25 times over 3 days if not acknowledged
