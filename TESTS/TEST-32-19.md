4. **Test accessibility** with jest-axe for all components
5. **Use snapshot tests sparingly** - prefer explicit assertions
6. **Mobile testing** - use `@testing-library/react` viewport utilities
7. **Analytics tracking** - mock the analytics function for CTA tests
