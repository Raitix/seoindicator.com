## Service Interface

```php
class DashboardAggregator
{
    /**
     * Get full dashboard data with caching
     */
    public function getDashboardData(int $userId): array;

    /**
     * Get quick stats cards data
     */
    public function getStats(int $userId): array;

    /**
     * Get recent analyses list (last 10)
     */
    public function getRecentAnalyses(int $userId): array;

    /**
     * Get cost summary by period
     */
    public function getCostSummary(int $userId): array;

    /**
     * Get quick insights (most used tool, avg time, success rate)
     */

}
```

## Notes for Developer

### Controller Implementation

1. **Create Controller**: `backend/app/Http/Controllers/Api/V1/DashboardController.php`

2. **Create Service**: `backend/app/Services/DashboardAggregator.php`

3. **Register Routes** in `routes/api.php`:
```php
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::get('/dashboard/stats', [DashboardController::class, 'stats']);
    Route::get('/dashboard/recent-analyses', [DashboardController::class, 'recentAnalyses']);
    Route::get('/dashboard/cost-summary', [DashboardController::class, 'costSummary']);
});
```

### Key Implementation Points

1. **Caching**: Use Laravel's `Cache::remember()` with 60-second TTL

2. **User Isolation**: All queries filtered by `auth()->id()`

3. **Dependencies**: Inject `AnalysisHistoryRepository` and `CostTrackingService`

4. **Response Format**: Use Laravel's `response()->json()` with success wrapper

5. **Error Handling**: Return appropriate HTTP codes (401, 500)

6. **Performance**: Optimize queries with eager loading and proper indexes

### Service Dependencies

```php
class DashboardAggregator
{
    public function __construct(
        private AnalysisHistoryRepository $analysisRepo,
        private CostTrackingService $costService
    ) {}
}
```

### Date Calculations

- **This Month**: `whereMonth('analyzed_at', now()->month)`
- **This Week**: `whereBetween('analyzed_at', [now()->startOfWeek(), now()])`
- **Today**: `whereDate('analyzed_at', today())`
