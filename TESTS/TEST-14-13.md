## Authorization Logic

1. User must be authenticated (Sanctum)
2. User must own the site (via `SiteUser` pivot table)
3. Non-owners receive 403 Forbidden
4. Unauthenticated users receive 401 Unauthorized

## Notes for Developer

1. **Controller Location:** `backend/app/Http/Controllers/Api/V1/AuditController.php`

2. **Request Validation:** Create `StoreAuditRequest` form request with validation rules

3. **Job Dispatch:** Ensure `ProcessCrawlJob` accepts audit model

4. **Cache Keys:** Use `audit:{id}:progress` pattern for progress data

5. **Authorization:** Check site ownership via `SiteUser` pivot table

6. **Single Running Audit:** Query for existing running/pending audits before creating new

7. **Rate Limiter:** Configure in `AppServiceProvider::boot()`:
   ```php
   RateLimiter::for('audit-trigger', function (Request $request) {
       return Limit::perHour(5)->by($request->user()->id);
   });
   ```

8. **Routes:** Add to `routes/api.php`:
   ```php
   Route::middleware('auth:sanctum')->group(function () {
       Route::post('sites/{site}/audits', [AuditController::class, 'store'])
           ->middleware('throttle:audit-trigger');
       Route::get('audits/{audit}', [AuditController::class, 'show']);
       Route::get('sites/{site}/audits', [AuditController::class, 'index']);
       Route::delete('audits/{audit}', [AuditController::class, 'destroy']);
   });
   ```
