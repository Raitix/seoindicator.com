## Test Scenarios

### Get Ranking History Endpoint
| ID | Method | Endpoint | Scenario | Expected Result |
|----|--------|----------|----------|-----------------|
| API-001 | GET | /api/v1/keywords/:id/history | Valid keyword | 200, history array with summary |
| API-002 | GET | /api/v1/keywords/:id/history | Keyword with no history | 200, empty history array |
| API-003 | GET | /api/v1/keywords/:id/history | Invalid keyword ID | 404 Not Found |
| API-004 | GET | /api/v1/keywords/:id/history?from=2026-01-01 | Date range filter | 200, only entries after from date |
| API-005 | GET | /api/v1/keywords/:id/history?to=2026-01-31 | Date range filter | 200, only entries before to date |
| API-006 | GET | /api/v1/keywords/:id/history?limit=50 | Limit results | 200, max 50 entries |

### History Response Structure Tests

| RES-003 | Response includes summary | { currentPosition, bestPosition, worstPosition, averagePosition, totalChecks } |
| RES-004 | NULL position handling | position: null shown correctly |

## Edge Cases
- Keyword never checked (no history)
- History spanning multiple years
- Position changes from ranked to not ranked
- Position changes from not ranked to ranked
- Large history (1000+ entries)
- Date range with no entries
- Future date in from/to params
