## Notes for Developer

1. **Context Structure**: The AuthContext should be created with React.createContext<AuthContextType | null>(null)
2. **Provider Location**: Wrap the provider in layout.tsx or a dedicated auth layout
3. **API Client**: Use the existing API client from lib/api/client.ts
4. **Token Storage**: Prefer httpOnly cookies (Sanctum) over localStorage for security
5. **Error Format**: Follow the existing error format from other API responses
6. **TypeScript Types**: Create types in lib/types/auth.ts
7. **Redirect Logic**: Use Next.js router for redirects, not window.location
8. **Loading States**: Ensure loading states cover all async operations
9. **Error Clearing**: Clear errors on new attempts, not automatically
10. **401 Handling**: Implement axios interceptor for automatic logout on 401
