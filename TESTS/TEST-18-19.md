## Test Scenarios

### Viewport Meta Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| VM-01 | Proper viewport | `<meta name="viewport" content="width=device-width, initial-scale=1">` | hasViewport: true |
| VM-02 | Missing viewport | No viewport meta | hasViewport: false |
| VM-03 | Fixed width | `width=1024` | hasViewport: true, notResponsive: true |
| VM-04 | User-scalable disabled | `user-scalable=no` | hasViewport: true, warning |
| VM-05 | Minimum-scale set | `minimum-scale=1.0` | acceptable |

### Responsive Design Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| RD-01 | CSS media queries | `@media (max-width: 768px)` | hasMediaQueries: true |

| RD-03 | No responsive CSS | Fixed-width layout | isResponsive: false |
| RD-04 | View container | `.container-fluid` or similar | detected |

## Mock Data

### Mobile-Friendly HTML
```html
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <style>
    @media (max-width: 768px) { .sidebar { display: none; } }
    body { font-size: 16px; }
    button { min-height: 48px; min-width: 48px; }
  </style>
</head>
<body>
  <button>Click Me</button>
</body>
</html>
```

### Non-Mobile-Friendly HTML
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { width: 1200px; font-size: 10px; }
    button { padding: 2px; }
  </style>
</head>
<body>
  <button>X</button>
</body>
</html>
```
