## Notes for Developer

1. **Unlock State Hook:** Create `useAuditUnlock` hook to manage unlock state
2. **Cookie Management:** Use `js-cookie` or native `document.cookie`
3. **Partial Content:** Server returns `isPartial: true` for anonymous users
4. **Full Content:** After email submit, set cookie and refresh data
5. **Skip Flow:** Alternative path for users who don't want to provide email
6. **Redirect:** Support `?redirect=/signup` parameter for post-submit redirect
