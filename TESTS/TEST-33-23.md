## Key Test Patterns

### Email Validation Testing
```typescript
// Test invalid email formats
await user.type(emailInput, 'invalid-email');
await user.click(submitButton);
expect(screen.getByTestId('validation-error')).toHaveTextContent('Invalid email format');
```

### API Mocking
```typescript
mockFetch.mockResolvedValueOnce({ 
  ok: true, 
  json: () => Promise.resolve({ success: true }) 
});
```

### Cookie Testing
```typescript
// Set unlock cookie
setUnlockedAudit('abc123', 'test@example.com');

// Verify cookie exists
expect(isAuditUnlocked('abc123')).toBe(true);
```

### Deduplication Testing
```typescript
// Store email
storeEmailCaptured('test@example.com');

// Verify case-insensitive check
expect(checkEmailCaptured('TEST@EXAMPLE.COM')).toBe(true);
```
