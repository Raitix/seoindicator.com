## Overview
Tests for integrating backlink profile score into the overall visibility score calculation. Verifies that the `VisibilityScoreService` correctly incorporates the backlink component with proper weighting (20%), handles projects without backlink data gracefully, and implements appropriate caching.

## Implementation Notes

### VisibilityScoreService Interface
```php
class VisibilityScoreService
{
    public function calculate(Project $project, bool $force = false): int;
    
    public function calculatePositionComponent(Project $project): float;
    
    public function calculateSerpComponent(Project $project): float;
    
    public function calculateBacklinkComponent(Project $project): float;
    
    public function calculateVolumeComponent(Project $project): float;
    
    public function clearCache(int $projectId): void;
}
```

