## Component Specification

### Props

```typescript
interface EmbedCodeGeneratorProps {
  auditHash: string;           // 32-char public audit hash
  score: number;               // 0-100 SEO score
  siteUrl?: string;            // Optional site URL for display
  onCopy?: (type: EmbedType, code: string) => void;  // Optional callback
  className?: string;          // Optional CSS classes
  showInstructions?: boolean;  // Show embedding tips (default: true)
}

type EmbedType = 'svg' | 'js' | 'iframe';
type BadgeSize = 'small' | 'medium' | 'large';
type BadgeTheme = 'light' | 'dark';
```

### Features

| Feature | Description |
|---------|-------------|
| Live Badge Preview | Visual preview of badge in selected size/theme |
| Size Selector | Small (120x40), Medium (150x100), Large (300x150) |
| Theme Selector | Light/Dark variants |
| Embed Type Tabs | SVG Image, JavaScript, iframe |
| Code Display | Read-only textarea with generated code |
| Copy Button | One-click copy with "Copied!" feedback |
| Instructions | Optional embedding tips section |

### Embed Code Formats

**SVG Image:**
```html
<a href="https://seoindicator.com/audit/{hash}/">
  <img src="https://seoindicator.com/badge/{hash}/{size}.svg" 
       alt="SEO Score: {score}/100" 
       width="{width}" height="{height}" />
</a>
```

**JavaScript:**
```html
<div data-seoindicator-badge="{hash}" 
     data-size="{size}" 
     data-theme="{theme}"></div>
<script src="https://seoindicator.com/badge.js" async></script>
```

**iframe:**
```html
<iframe src="https://seoindicator.com/badge/{hash}/large?theme={theme}" 
        width="300" height="150" 
        frameborder="0" 
        loading="lazy"></iframe>
```

## Notes for Developer

1. **Component Structure:**
   - Use shadcn/ui Card component as container
   - Separate preview, controls, code, and instructions sections
   - Use tabs for embed type selection

2. **State Management:**
   - Use React useState for size, theme, embedType, copied
   - Use useRef for timer management
   - Memoize embed code generation

3. **Accessibility:**
   - All interactive elements must have aria-labels
   - Use aria-live for copy feedback
   - Ensure keyboard navigation works

4. **Performance:**
   - Debounce preview updates if using real-time
   - Use memo for expensive computations
   - Avoid unnecessary re-renders

5. **Security:**
   - Validate auditHash format before generating code
   - Escape special characters in generated code
   - No XSS in preview rendering
