# TEST-33-16: Badge.js Embed Script Tests

## Task Reference
- **Task:** [TASK-33-16](../TASKS/TASK-33-16.md)
- **Feature:** [FEAT-33](../FEATURES/FEAT-33.md) - Public SEO Audit Reports & Embeddable Score Widget
- **Specification:** [SPEC-33](../SPECIFICATIONS/SPEC-33.md)

## Overview
Comprehensive unit tests for the badge.js embed script that enables third-party sites to display interactive SEO score badges. Tests cover initialization, rendering, API integration, tracking, UMD compatibility, and all 12 acceptance criteria.

| `frontend/__tests__/scripts/badge-build.test.ts` | 15+ | Build output verification |
