## Validation Rules

### Path Parameter
| Parameter | Type | Validation |
|-----------|------|------------|

### Query Parameters
| Parameter | Type | Validation |
|-----------|------|------------|

| `estimated_tokens` | integer | Optional, positive integer (> 0) |

| Analysis Type | Tokens | Description |
|---------------|--------|-------------|
| quick | 500 | Quick analysis (~350 input + ~150 output) |
| standard | 2000 | Standard analysis (~1400 input + ~600 output) |
| deep | 5000 | Deep analysis (~3500 input + ~1500 output) |
