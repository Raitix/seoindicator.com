## Overview

Tests for the `GuideSchema` component that generates HowTo schema.org structured data for all 17 SEO guide pages. The component will be located at `components/guides/GuideSchema.tsx`.

### HowTo Schema Structure

```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "Guide Title",
  "description": "Guide summary",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Section Title",
      "text": "Section content (truncated)"
    }
  ],
  "estimatedCost": {
    "@type": "MonetaryAmount",
    "currency": "USD",
    "value": "0"
  },
  "totalTime": "PT5M"
}
```

## Notes for Developer

1. **Component Location:** `frontend/components/guides/GuideSchema.tsx`

2. **Props Interface:**
   ```typescript
   interface GuideSchemaProps {
     guide: SEOGuide | null;
   }
   ```

3. **Implementation Pattern:**
   ```tsx
   export function GuideSchema({ guide }: GuideSchemaProps) {
     if (!guide) return null;
     
     const schema = generateHowToSchema(guide);
     
     return (
       <script
         type="application/ld+json"
         dangerouslySetInnerHTML={{
           __html: JSON.stringify(schema)
         }}
       />
     );
   }
   ```

4. **Usage in Page:**
   ```tsx
   // In guide page component
   <Head>
     <GuideSchema guide={guide} />
   </Head>
   ```

5. **Validation:**
   - Test with Google Rich Results Test: https://search.google.com/test/rich-results
   - Validate JSON-LD structure with: https://validator.schema.org/

6. **Content Truncation:**
   - HowToStep `text` should be truncated to ~200 chars to avoid overly long schema
   - Use ellipsis (...) for truncated content

7. **All 17 Guide Slugs:**
   - meta-title, meta-description, h1-headings, heading-hierarchy
   - image-alt-text, image-optimization, internal-links, external-links
   - page-speed, mobile-friendly, https-security, structured-data
   - canonical-urls, robots-txt, xml-sitemap
   - open-graph, twitter-cards
