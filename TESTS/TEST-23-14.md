### Large Dataset Generator
```typescript
export function generateLargeHistory(days: number): BacklinkHistoryData[] {
  const data: BacklinkHistoryData[] = [];
  const today = new Date();
  
  for (let i = days; i >= 0; i--) {
    const date = new Date(today);
    date.setDate(date.getDate() - i);
    
    data.push({
      date: date.toISOString().split('T')[0],
      total_backlinks: 1000 + (days - i) * 10 + Math.floor(Math.random() * 50),
      referring_domains_count: 50 + (days - i) + Math.floor(Math.random() * 5),
      dofollow_count: Math.floor((1000 + (days - i) * 10) * 0.72),
      nofollow_count: Math.floor((1000 + (days - i) * 10) * 0.28),
      avg_domain_trust: 35 + (days - i) * 0.1 + Math.random() * 5,
      anchor_diversity_score: 50 + (days - i) * 0.2,
    });
  }
  
  return data;
}
```

## Notes for Developer

### Component Props
```typescript
interface BacklinkHistoryChartProps {
  projectId: number;          // Required: Project to fetch history for
  dateRange?: {               // Optional: Initial date range
    from: string;             // ISO date string (YYYY-MM-DD)
    to: string;               // ISO date string (YYYY-MM-DD)
  };
}
```

### API Endpoint
```
GET /api/v1/projects/{projectId}/backlinks/history?from=YYYY-MM-DD&to=YYYY-MM-DD
```

### Date Range Presets
| Label | Days Back | Calculation |
|-------|-----------|-------------|
| 7 days | 7 | `subDays(now, 7)` |
| 30 days | 30 | `subDays(now, 30)` |
| 90 days | 90 | `subDays(now, 90)` |
| 1 year | 365 | `subDays(now, 365)` |

### Chart Colors
| Series | Color | Hex |

### Implementation Notes
1. Use TanStack Query with `useQuery` for data fetching
2. Memoize date calculations to prevent unnecessary re-renders
3. Use `ResponsiveContainer` from Recharts for adaptive sizing
4. Implement `CustomTooltip` component for detailed hover info
5. Handle loading state with Shadcn/UI `Skeleton` component
6. Handle empty state with custom `EmptyState` component
