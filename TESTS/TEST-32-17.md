### Security Notes
- Strip HTML/script tags from input
- Truncate names to 50 characters max
- No database queries (stateless route)
- No external HTTP requests

### Performance Tips
- Images are cached by CDN (Cache-Control header)
- No database lookups needed
- ImageResponse renders in memory
