## Notes for Developer

### Service Structure
```
app/Services/Crawler/
├── RateLimiterService.php
└── Data/
    └── RateLimitResult.php

app/Http/Middleware/
└── CrawlerRateLimit.php
```

### Key Implementation Points

1. **Cache Keys** - Use exact format: `crawler:rate:{type}:{id}`
2. **Atomic Operations** - Use Cache::increment/decrement for thread safety
3. **Carbon Instances** - resetAt must be Carbon, convert to ISO in JSON
4. **Admin Bypass** - Admins bypass user limits only, not domain/global
5. **Middleware** - Check all 4 limits (user, concurrent, domain, global)
6. **429 Response** - Include both body JSON and headers

### Configuration Defaults
```php
'rate_limits' => [
    'user_daily' => 10,
    'user_concurrent' => 3,
    'domain_per_second' => 1,
    'global_concurrent' => 10,
    'window_hours' => 24,
]
```
