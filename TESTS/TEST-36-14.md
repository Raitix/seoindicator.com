## Notes for Developer

### Component Structure
```
ContentDecayWidget.tsx
├── DecaySummaryCard (severity badges, totals)
├── TopCandidatesList (up to 3 items)
│   └── CandidateItem (URL, score, actions)
├── LastScanTimestamp
└── ViewAllLink
```

### Navigation Structure
```
SEO Tools
├── Keyword Rankings
├── Site Audits
├── Content Decay  ← NEW
├── AI Visibility
└── Annotations
```

### State Priority
1. Loading (during initial fetch)
2. Error (on API failure)
3. Empty (no candidates)
4. Data (show summary + candidates)

### Color Coding for Severity
- Critical: Red (#ef4444)
- High: Orange (#f97316)
- Medium: Yellow (#eab308)

### Accessibility Requirements
- All interactive elements must have aria-labels
- Loading states must announce via aria-live
- Error states must use role="alert"
- Focus management on actions
- Keyboard navigation for all controls
