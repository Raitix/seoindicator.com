## Notes for Developer

1. **Widget State Machine:**
   ```
   Loading → Error (on API failure)
   Loading → Empty (totalCandidates === 0)
   Loading → Data (totalCandidates > 0)
   ```

2. **Severity Color Classes:**
   - Critical: `text-red-600 bg-red-50` - data-severity="critical"
   - High: `text-orange-600 bg-orange-50` - data-severity="high"
   - Medium: `text-yellow-600 bg-yellow-50` - data-severity="medium"

3. **Navigation Structure:**
   ```
   SEO Tools
   ├── Keyword Rankings
   ├── Site Audits
   ├── Content Decay  ← NEW (after Audits)
   ├── AI Visibility
   └── Annotations
   ```

4. **Number Formatting:**
   - 0 → "0"
   - 500 → "500"
   - 1500 → "1.5K"
   - 2500000 → "2.5M"

5. **URL Truncation:**
   - Max length: 40 characters
   - Truncate with ellipsis
   - Full URL in title attribute
