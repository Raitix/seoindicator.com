## Calculation Formula

### PWA Component Calculation
```php
/**
 * Calculate PWA component contribution to visibility score.
 * 
 * Weight: 10% of overall visibility score
 * Formula: (pwa_score / 100) * 10 points
 * 
 * @param Project $project
 * @return float PWA component score (0-10)
 */
protected function calculatePWAComponent(Project $project): float
{
    $pwaScore = $project->pwaAnalysis?->pwa_score ?? 0;
    
    // Clamp to valid range
    $pwaScore = max(0, min(100, $pwaScore ?? 0));
    
    // Calculate 10% contribution
    return ($pwaScore / 100) * 10;
}
```

### Updated Visibility Score Formula
```
Visibility Score = 
  Position Component (50% weight) +
  SERP Feature Component (25% weight) +
  Volume Distribution Component (15% weight) +
  PWA Component (10% weight)

Maximum: 100 points
```
