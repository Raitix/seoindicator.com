## Notes for Developer

### Integration Point
The main integration is in `APIProxyController::analyze()`:

```php
public function analyze(ProxyAnalyzeRequest $request): JsonResponse
{
    $startTime = microtime(true);
    $analysisHistoryService = app(AnalysisHistoryService::class);
    
    try {
        // ... existing validation and tool execution ...
        
        $duration = $analysisHistoryService->calculateDuration($startTime);
        
        $analysis = $analysisHistoryService->createAnalysis([
            'user_id' => auth()->id(),
            'site_id' => $request->site_id ?? null,
            'tool_name' => $tool,
            'input_url' => $url,
            'status' => 'completed',
            'results' => $result->toArray(),
            'analysis_duration_ms' => $duration,
        ]);

        // Trigger cost tracking
        app(CostTrackingService::class)->recordCost($analysis, [
            'units' => 1,
        ]);

        return response()->json(array_merge(
            $result->toArray(),
            ['analysis_id' => $analysis->id]
        ));
        
    } catch (\Exception $e) {
        $analysisHistoryService->createAnalysis([
            'user_id' => auth()->id(),
            'tool_name' => $tool,
            'input_url' => $url,
            'status' => 'failed',
            'error_message' => $e->getMessage(),
        ]);
        
        throw $e;
    }
}
```

### Service Interface
```php
interface AnalysisHistoryServiceInterface
{
    public function createAnalysis(array $data): AnalysisHistory;
    public function completeAnalysis(int $id, array $results, int $duration): void;
    public function failAnalysis(int $id, string $errorMessage): void;
    public function calculateDuration(float $startTime): int;
}
```

### Rate Limit Handling
Do NOT create history records for rate-limited requests (429 responses). Only create records when actual tool execution is attempted.

### Anonymous Users
The tools API supports both authenticated and anonymous usage. When `auth()->id()` is null, create the record with `user_id = null`.
