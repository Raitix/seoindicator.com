## Redirect Flow

```
1. User visits protected route (e.g., /settings)
   ↓
2. Middleware redirects to /login?redirect=/settings
   OR
   Application stores 'seoindicator_redirect' in localStorage
   ↓
3. User sees login form
   ↓
4. User authenticates successfully
   ↓
5. Login page reads redirect destination:
   - Priority 1: URL param (?redirect=/path)
   - Priority 2: localStorage (seoindicator_redirect)
   - Fallback: /dashboard
   ↓
6. Redirect to destination
   ↓
7. Clear seoindicator_redirect from localStorage
```

---

## Security Validation Rules

### Valid Redirects
- `/dashboard`
- `/settings`
- `/projects/123`
- `/dashboard/settings?tab=general`

### Invalid Redirects (blocked → fallback to /dashboard)
- `https://evil.com` - External URL
- `//evil.com` - Protocol-relative URL
- `javascript:alert('xss')` - JavaScript URL
- `data:text/html,<script>` - Data URL
- `dashboard` - Missing leading slash
- `/dashboard/../../../etc/passwd` - Path traversal

### Key Implementation Points

1. **Read redirect target on mount:**
```typescript
const searchParams = useSearchParams();
const urlRedirect = searchParams.get('redirect');
const localStorageRedirect = localStorage.getItem('seoindicator_redirect');
```

2. **Priority logic:**
```typescript
const getRedirectDestination = () => {
  // URL param takes priority
  if (urlRedirect && isValidRedirect(urlRedirect)) {
    return urlRedirect;
  }
  
  // Fall back to localStorage
  if (localStorageRedirect && isValidRedirect(localStorageRedirect)) {
    return localStorageRedirect;
  }
  
  // Default
  return '/dashboard';
};
```

3. **Validate redirect:**
```typescript
const isValidRedirect = (redirect: string): boolean => {
  // Must start with /
  if (!redirect.startsWith('/')) return false;
  
  // Reject external URLs
  if (redirect.startsWith('//')) return false;
  if (/^https?:\/\//i.test(redirect)) return false;
  
  // Reject dangerous protocols
  if (/^javascript:/i.test(redirect)) return false;
  if (/^data:/i.test(redirect)) return false;
  
  return true;
};
```

4. **Clear after redirect:**
```typescript
const handleLoginSuccess = () => {
  const destination = getRedirectDestination();
  
  // Clear stored redirect
  localStorage.removeItem('seoindicator_redirect');
  
  // Navigate
  router.push(destination);
};
```
