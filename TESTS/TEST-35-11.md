## Notes for Developer

### Implementation Priority

1. **High Priority:** Quota enforcement, rate limiting (ToS compliance)
2. **Medium Priority:** SERP parsing, caching
3. **Lower Priority:** Robots.txt handling, rotating user agents

### Critical Considerations

1. **Google ToS:** This is the riskiest task. Be prepared to adjust based on:
   - CAPTCHA responses
   - Rate limiting from Google
   - Layout changes

2. **Mock-First Development:** All HTTP requests MUST be mocked in unit tests. Only integration tests should make real requests (and even then, sparingly).

3. **Error Recovery:** Implement graceful degradation:
   - Log all blocked requests
   - Provide clear error messages
   - Suggest retry strategies

4. **Future Enhancements:**
   - Proxy support for scaling
   - Multiple search engines (Bing, DuckDuckGo)
   - Scheduled automated checks
