## Notes for Developer

1. **Migration File**: Create `database/migrations/2026_03_01_000001_create_analysis_history_table.php`

2. **Model File**: Create `app/Models/AnalysisHistory.php`

3. **JSON Cast**: Use Laravel's `protected $casts = ['results' => 'array'];`

4. **Enum Values**: `pending`, `completed`, `failed` (lowercase only)

5. **URL Max Length**: HTTP spec limit is 2083 characters

6. **Indexes**: Critical for performance on history queries:
   - `(user_id, analyzed_at DESC)` - User's analysis history
   - `tool_name` - Filter by tool
   - `status` - Filter by status
