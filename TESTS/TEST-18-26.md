## Test Scenarios

### POST /api/v1/analyze - Create Analysis

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CA-01 | Valid domain | `{ domain: "example.com" }` | 202 Accepted, analysis ID returned |
| CA-02 | Invalid domain format | `{ domain: "not-a-domain" }` | 422 Unprocessable Entity |
| CA-03 | Empty domain | `{ domain: "" }` | 422 Unprocessable Entity |
| CA-04 | Missing domain | `{}` | 422 Unprocessable Entity |
| CA-05 | Domain with path | `{ domain: "example.com/page" }` | Path stripped, 202 Accepted |
| CA-06 | Domain with protocol | `{ domain: "https://example.com" }` | Protocol normalized, 202 |
| CA-07 | Authenticated user | Valid domain + auth token | user_id linked |
| CA-08 | Anonymous user | Valid domain, no auth | session_id generated |
| CA-09 | Rate limit exceeded | > 3 analyses/day (anon) | 429 Too Many Requests |
| CA-10 | Rate limit auth | > 10 analyses/day (auth) | 429 Too Many Requests |

### GET /api/v1/analyses/{id} - Get Analysis Results

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| GR-01 | Completed analysis | Valid ID, status: completed | 200 OK with full results |
| GR-02 | Running analysis | Valid ID, status: running | 200 OK with status |
| GR-03 | Pending analysis | Valid ID, status: pending | 200 OK with status |
| GR-04 | Failed analysis | Valid ID, status: failed | 200 OK with error |
| GR-05 | Non-existent ID | Invalid ID | 404 Not Found |
| GR-06 | Other user's analysis | Different user's ID | 403 Forbidden (auth) |
| GR-07 | Own analysis | User's own ID | 200 OK |
| GR-08 | Expired analysis | Expired cache | Triggers re-analysis |

### GET /api/v1/analyze - Get by Domain (Cached)

| GD-04 | Invalid domain | Invalid domain format | 422 Unprocessable Entity |

### GET /api/v1/analyses - List Analyses

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
