## Notes for Developer

### Component Structure

```
/components/admin/
├── MetricCard.tsx
│   ├── Props: title, value, trend, format, href, isLoading, error
│   ├── Features: Number formatting, trend indicator, loading skeleton, error state
│   └── Accessibility: aria-label, keyboard navigation
│
├── MetricGrid.tsx
│   ├── Props: cards[], refreshInterval, onRefresh, lastUpdated
│   ├── Features: Responsive grid, auto-refresh, manual refresh
│   └── Responsive: 1 col (mobile), 2 cols (tablet), 3+ cols (desktop)
│
├── TrendIndicator.tsx
│   ├── Props: value, format, positiveColor, negativeColor
│   ├── Features: Directional arrows, color coding, animation
│   └── Accessibility: aria-describedby for direction
│
└── HealthBadge.tsx
    ├── Props: status, label, showIcon, size, pulse, onClick
    ├── Features: Color coding, optional pulse animation
    └── Statuses: healthy (green), degraded (yellow), unhealthy (red)
```

### Key Implementation Details

1. **Number Formatting:**
   - Use Intl.NumberFormat for localization
   - K/M suffix for large numbers (1.23K, 1.23M)
   - Currency format with $ prefix
   - Percentage format with % suffix

2. **Trend Indicators:**
   - Positive: Green arrow up (↑)
   - Negative: Red arrow down (↓)
   - Zero/Null: Neutral dash (−)
   - Animate on value change

3. **Loading State:**
   - Skeleton with pulse animation
   - `role="status"` and `aria-live="polite"`
   - Maintains card structure (no layout shift)

4. **Error State:**
   - Error message with retry button
   - `role="alert"` for accessibility
   - Retains last known value if available

5. **Auto-Refresh:**
   - Configurable interval (default: 30s)
   - Show countdown or "Last updated X ago"
   - Cancel on unmount

6. **Navigation:**
   - Cards are clickable (if href provided)
   - Use Next.js `Link` component
   - Keyboard accessible (Enter to navigate)
