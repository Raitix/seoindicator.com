## Mock Data

### Recommendation Response
```typescript
interface RecommendationResponse {
  keywords: KeywordRecommendation[];
  features: FeatureRecommendation[];
  metadata: {
    industry: string;
    topics_detected: string[];
    generated_at: string;
  };
}

interface KeywordRecommendation {
  keyword: string;
  opportunity_score: number;
  reason: string;
  volume?: number;
  competition?: number;
}

interface FeatureRecommendation {
  feature: string;
  name: string;
  priority: 'high' | 'medium' | 'low';
  reason: string;
}
```

## Notes for Developer

1. **Service Location**: `backend/app/Services/PersonalizationEngine.php`

2. **API Endpoints**:
   - `GET /api/v1/recommendations?url={url}&industry={industry}`
   - `POST /api/v1/recommendations/feedback`

3. **Opportunity Score Factors**:
   - Search volume: 0-40 points
   - Competition (inverse): 0-30 points
   - Industry relevance: 0-15 points
   - Trending bonus: 0-15 points

4. **Feature Mappings by Industry**:
   - E-commerce: competitor_tracking, product_monitoring
   - SaaS: feature_comparison, trial_tracking
   - Local: local_pack, review_monitoring
   - Blog: content_calendar, trending_topics

5. **Learning System**:
   - Store feedback in `recommendation_feedback` table
   - Apply learning rate of 0.1 for weight updates
   - Retrain model weekly
