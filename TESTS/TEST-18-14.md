## Test Scenarios

### Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| HE-01 | Single H1 present | `<h1>Title</h1>` | exists: true, count: 1 |
| HE-02 | No H1 | No h1 tag | exists: false, count: 0 |
| HE-03 | Empty H1 | `<h1></h1>` | exists: true, empty: true |
| HE-04 | H1 with image | `<h1><img alt="text"></h1>` | Handled correctly |

### Count Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| HC-01 | Single H1 | 1 H1 tag | count: 1, isSingle: true |

| ID | Scenario | Input | Expected Output |

## Notes for Developer
- Use `filter('h1')` to select H1 elements
- Extract text content, strip HTML tags
- Best practice: single H1 per page
- Consider H1 hierarchy (H1 > H2 > H3)
