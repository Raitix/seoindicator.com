## Notes for Developer

### Implementation Hints

1. **Sliding Window Algorithm**: Use cache to store timestamp array per identifier
2. **Cache Key Format**: `ai_rate_limit:{type}:{identifier}`
3. **Window Expiry**: Filter out timestamps older than window duration on each check
4. **Atomic Operations**: Use cache lock for concurrent request handling

### Configuration Structure
```php
// config/ai.php
'rate_limits' => [
    'user' => [
        'limit' => env('AI_RATE_LIMIT_USER', 20),
        'window_seconds' => 3600,
    ],
    'ip' => [
        'limit' => env('AI_RATE_LIMIT_IP', 10),
        'window_seconds' => 3600,
    ],
],
```

### Test Mocking
- Mock `Cache::get()` and `Cache::put()` for unit tests
- Use `Cache::fake()` for feature tests
- Mock `request()->ip()` for IP-based tests
