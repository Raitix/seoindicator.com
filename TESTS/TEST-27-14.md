## Key Implementation Notes

1. **Route Redirect:** `/admin` should use `replace()` to redirect to `/admin/overview` (not `push()`)

2. **Auth Guard Flow:**
   - Check `isLoading` first → show loading
   - Check `isAuthenticated && user` → show login prompt
   - Check `user.is_admin` → show forbidden
   - Otherwise → render children

3. **Active State Logic:**
   - Exact match: `activePath === href`
   - Nested match: `activePath.startsWith(href + '/')`

4. **Sidebar Collapse:**
   - Icons always visible
   - Labels hidden when collapsed
   - Toggle button controls state

5. **Loading States:**
   - Use skeleton components
   - ARIA: `role="status"` and `aria-live="polite"`

6. **Error States:**
   - Show error message with retry button
   - ARIA: `role="alert"`

7. **Responsive Design:**
   - Sidebar: `w-64` (256px)
   - Main content: flex-1 with `p-6` padding
