# TEST-33-28: Public Audit Analytics Tests

## Task Reference
- **Task:** TASK-33-28 - Implement Public Audit Analytics
- **Specification:** SPEC-33 - Public SEO Audit Reports & Embeddable Score Widget
- **Description:** Implement analytics aggregation for public audits, including views, leads, and geographic breakdown.

## Overview
Test suite for the `PublicAuditAnalyticsService` and `AuditAnalyticsController` that aggregate analytics data from `public_audit_views` and `badge_impressions` tables to provide a comprehensive analytics dashboard API.

## Notes for Developer

### Service Implementation
1. Create `PublicAuditAnalyticsService` in `app/Services/Audit/`
2. Use dependency injection for models (PublicAuditView, BadgeImpression)
3. Implement caching with 5-minute TTL
4. Use database aggregation (SUM, COUNT, GROUP BY) for performance
5. Handle null/empty data gracefully

### Controller Implementation
1. Create `AuditAnalyticsController` in `app/Http/Controllers/Api/V1/`
2. Use Laravel's `authorize()` for ownership check
3. Validate date range parameters
4. Return JSON response with `success` key
5. Apply rate limiting middleware

### Database Optimization
1. Ensure indexes on `audit_id`, `viewed_at`, `impression_at`
2. Consider materialized views for heavy aggregation
3. Use `->selectRaw()` for aggregation queries
