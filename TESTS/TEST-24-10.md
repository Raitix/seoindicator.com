# TEST-24-10: PWA Dashboard Components

## Overview
Unit tests for the PWA Dashboard React components. Tests cover PWADashboard container, ManifestStatusCard component, loading/error states, and responsive design.

**Task:** TASK-24-10
**Risk Level:** Low
**Dependencies:** TASK-24-8 (PWA Analysis API Endpoints)

---

## Components

### 1. PWADashboard
Main container component that orchestrates PWA analysis display.

**Props:**
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `siteId` | number | Yes | Site ID for API calls |
| `onAnalyzeClick?` | () => void | No | Callback for analyze button |
| `className?` | string | No | Additional CSS classes |

**State:**
- Fetches PWA analysis data from API on mount
- Shows loading skeleton during fetch
- Shows error state if no analysis exists
- Shows data when available

### 2. ManifestStatusCard
Card component displaying manifest presence and validity status.

**Props:**
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `hasManifest` | boolean | Yes | Whether manifest exists |
| `manifestUrl?` | string | No | Manifest URL if present |
| `manifestValid?` | boolean | No | Manifest validity status |
| `fields?` | ManifestFields | No | Field presence data |
| `className?` | string | No | Additional CSS classes |

**Fields Interface:**
```typescript
interface ManifestFields {
  name: { present: boolean; value?: string };
  short_name: { present: boolean; value?: string };
  start_url: { present: boolean; value?: string };
  display: { present: boolean; value?: string };
}
```

### 3. PWAScoreGauge
Visual gauge component for PWA score display.

**Props:**
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `score` | number | Yes | PWA score (0-100) |
| `readinessLevel` | string | Yes | Readiness level text |
| `className?` | string | No | Additional CSS classes |

## API Response Types

### GET /api/v1/sites/{siteId}/pwa

```typescript
interface PWAAnalysisResponse {
  success: boolean;
  data: {
    hasManifest: boolean;
    manifestUrl: string | null;
    manifestValid: boolean;
    pwaScore: number;
    readinessLevel: 'none' | 'basic' | 'enhanced' | 'full';
    fields: {
      name: { present: boolean; value?: string };
      short_name: { present: boolean; value?: string };
      start_url: { present: boolean; value?: string };
      display: { present: boolean; value?: string };
      background_color?: { present: boolean; value?: string };
      theme_color?: { present: boolean; value?: string };
      description?: { present: boolean; value?: string };
    };
    icons: {
      total: number;
      valid: number;
      required: {
        '192x192': { present: boolean };
        '512x512': { present: boolean };
      };
      errors: Array<{ size: string; error: string; severity: string }>;
    };
    recommendations: Array<{
      type: string;
      field?: string;
      message: string;
      priority: 'high' | 'medium' | 'low';
    }>;
    analyzedAt: string;
  };
}
```

### POST /api/v1/sites/{siteId}/pwa/analyze

```typescript
interface AnalyzeResponse {
  success: boolean;
  data: {
    jobId: string;
    status: 'queued';
    message: string;
  };
}
```

## Implementation Requirements

### Data Fetching
- Use SWR or React Query for data fetching
- Endpoint: `GET /api/v1/sites/{siteId}/pwa`
- Cache with stale-while-revalidate pattern
- Polling optional for queued jobs

### Error Handling
- 404: Show "Analyze Now" CTA
- 401/403: Show login prompt
- 500: Show retry button
- 429: Show retry countdown

### Responsive Design
- Mobile (<768px): Single column, stacked cards
- Tablet (768-1024px): 2 column grid
- Desktop (>1024px): 3 column grid

### Color Coding
| Status | Color | Tailwind Class |
|--------|-------|----------------|
| Valid/Good | Green | `text-emerald-400`, `bg-emerald-500/10` |
| Warning | Yellow | `text-yellow-400`, `bg-yellow-500/10` |
| Error/Missing | Red | `text-red-400`, `bg-red-500/10` |
