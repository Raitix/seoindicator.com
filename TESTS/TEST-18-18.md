## Test Scenarios

### Status Code Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| SC-01 | Correct 404 status | Request non-existent URL, get 404 | correctStatus: true |
| SC-02 | Wrong status 200 | Returns 200 for non-existent | correctStatus: false |
| SC-03 | Wrong status 301 | Redirects to homepage | correctStatus: false |
| SC-04 | Wrong status 302 | Temporary redirect | correctStatus: false |

### Custom Page Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CP-01 | Custom 404 page | Custom design for 404 | hasCustomPage: true |
| CP-02 | Default server 404 | Apache/Nginx default | hasCustomPage: false |
| CP-03 | Redirect to homepage | No 404 page, redirects | hasCustomPage: false |
| CP-04 | Soft 404 | 200 page with "not found" text | soft404: true |

### Helpfulness Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| HE-01 | Navigation present | Links to home, sitemap | hasNavigation: true |
| HE-02 | Search form present | Search functionality | hasSearch: true |
| HE-03 | Helpful message | "Page not found, try..." | isHelpful: true |
| HE-04 | Contact link | Link to support | hasContactLink: true |
| HE-05 | Minimal page | Just "404" text | isHelpful: false |

### Design Consistency Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| DC-01 | Consistent design | Same header/footer as site | isConsistent: true |
| DC-02 | Different design | Completely different look | isConsistent: false |
| DC-03 | Missing navigation | No site nav on 404 | isConsistent: false |

### Scoring Tests
