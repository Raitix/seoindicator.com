## Test Scenarios

### Favicon Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| FE-01 | favicon.ico present | HTTP 200 on /favicon.ico | exists: true |
| FE-02 | Link rel icon | `<link rel="icon" href="/icon.png">` | exists: true |
| FE-03 | No favicon | Neither method | exists: false |
| FE-04 | Multiple formats | .ico + .png + .svg | exists: true, formats: [...] |

### Favicon Format Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| FF-01 | ICO format | `/favicon.ico` | format: 'ico' |
| FF-02 | PNG format | `<link rel="icon" type="image/png">` | format: 'png' |
| FF-03 | SVG format | `<link rel="icon" type="image/svg+xml">` | format: 'svg' |
| FF-04 | GIF format | `<link rel="icon" type="image/gif">` | format: 'gif' |

### Favicon Size Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| FS-01 | Multiple sizes | `sizes="16x16 32x32 48x48"` | hasMultipleSizes: true |
| FS-02 | Apple touch icon | `<link rel="apple-touch-icon">` | hasAppleIcon: true |
| FS-03 | Android manifest | `/manifest.json` with icons | hasAndroidIcon: true |
| FS-04 | Single size only | Only 16x16 | hasMultipleSizes: false |

### Favicon Validity Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| FV-01 | Valid image | Returns actual image | isValid: true |
| FV-02 | Invalid image | Returns HTML or error | isValid: false |
| FV-03 | Correct dimensions | 16x16, 32x32, etc. | dimensionsOk: true |
| FV-04 | Wrong dimensions | Odd size like 17x17 | dimensionsOk: false |

### Scoring Tests

| ID | Scenario | Input | Expected Score |
|----|----------|-------|----------------|
| SC-01 | Perfect favicon | Multiple sizes + formats + valid | 3 (Excellent) |
| SC-02 | Good favicon | Basic favicon present | 2 (Good) |
| SC-03 | Poor favicon | Missing or invalid | 1 (Poor) |

### Interface Compliance Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| IC-01 | ID returns correct | id() | 'favicon' |
| IC-02 | Name returns correct | name() | 'Favicon' |
| IC-03 | Category returns correct | category() | 'technical' |
| IC-04 | Weight returns correct | weight() | 0.02 |

### Edge Case Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| EC-01 | SVG favicon | `<link rel="icon" href="icon.svg">` | detected |
| EC-02 | Data URI favicon | `href="data:image/png;base64,..."` | detected |
| EC-03 | External favicon | CDN-hosted favicon | detected |
| EC-04 | Relative path | `href="img/favicon.png"` | resolved correctly |
