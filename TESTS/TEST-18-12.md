## Test Scenarios

### Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| RE-01 | Robots.txt exists | HTTP 200 on /robots.txt | exists: true |
| RE-02 | Robots.txt missing | HTTP 404 | exists: false |
| RE-03 | Redirect to robots.txt | 301/302 to valid file | follows redirect |
| RE-04 | Server error | HTTP 500 | exists: false, error logged |

### Validity Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| RV-01 | Valid robots.txt | Properly formatted | isValid: true |
| RV-02 | Empty robots.txt | Empty file | isValid: true (allows all) |
| RV-03 | Invalid syntax | Malformed directives | isValid: false |
| RV-04 | Binary file | Non-text content | isValid: false |
| RV-05 | Very large file | > 500KB | isValid: true, truncated |

### Indexing Permission Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| IP-01 | Allows all | `User-agent: * Allow: /` | allowsIndexing: true |

| IP-03 | Blocks specific paths | `Disallow: /admin/` | allowsIndexing: true |
| IP-04 | Complex rules | Multiple user-agents | correctly parsed |
| IP-05 | Crawl-delay | `Crawl-delay: 10` | detected, noted |
| IP-06 | Noindex directive | `Noindex: /private/` | detected, noted |

### Sitemap Detection Tests
