## Expected Route Implementation

```typescript
// frontend/app/api/og/audit/[hash]/route.ts
import { ImageResponse } from '@vercel/og';
import { NextRequest } from 'next/server';
import { PublicAudit } from '@/lib/audit/public-audit';
import { BadgeService } from '@/lib/audit/badge-service';

export async function GET(
  request: NextRequest,
  { params }: { params: { hash: string } }
) {
  const { hash } = params;
  
  // Validate hash format
  if (!/^[a-zA-Z0-9]{32}$/.test(hash)) {
    return new Response(JSON.stringify({ error: 'Not Found' }), {
      status: 404,
      headers: { 'Content-Type': 'application/json' },
    });
  }
  
  // Find public audit
  const audit = await PublicAudit.findByHash(hash);
  
  // Return 404 for non-existent or non-public
  if (!audit || !audit.is_public) {
    return new Response(JSON.stringify({ error: 'Not Found' }), {
      status: 404,
      headers: { 'Content-Type': 'application/json' },
    });
  }
  
  // Get score color
  const scoreColor = BadgeService.getScoreColor(audit.overall_score);
  
  // Generate image
  return new ImageResponse(
    (
      <div style={{ /* layout styles */ }}>
        {/* Logo, URL, Score, Categories, CTA */}
      </div>
    ),
    {
      width: 1200,
      height: 630,
    }
  );
}
```

## Technical Notes

### @vercel/og Library
- Uses Satori under the hood for SVG generation
- Converts SVG to PNG
- Supports custom fonts
- Supports emoji (twemoji by default)
- Works on Vercel Edge Runtime

### Alternative Libraries
- `html-to-image` - Generate images from HTML
- `puppeteer` - Full browser rendering (heavier)
- `sharp` - Image processing

### Caching Strategy
1. **HTTP Cache**: `Cache-Control: public, max-age=3600` (1 hour)
2. **CDN Cache**: Vercel Edge Network caches automatically
3. **ISR Alternative**: Pre-generate on audit publish, serve static file

### Performance Optimization
- Pre-generate OG images on audit publish (store in blob storage)
- Use ISR for static OG images
- Fallback to dynamic generation if pre-generated not available

## Notes for Developer

1. **Hash Validation**: Use regex `/^[a-zA-Z0-9]{32}$/` to validate hash format
2. **Image Dimensions**: Always use 1200x630 (OG standard)
3. **Score Display**: Large, centered, with color coding
4. **Category Layout**: Two columns, two rows for the 4 categories
5. **URL Truncation**: Max ~50 characters, add "..." if longer
6. **Cache Headers**: `public, max-age=3600` for CDN caching
7. **Error Format**: JSON `{ error: "Not Found" }` with `application/json`
8. **Same 404**: Non-existent and non-public audits return identical 404
9. **No Sensitive Data**: Only show public_hash, never show audit ID or user info
10. **Font Loading**: Use Inter font for consistent branding
