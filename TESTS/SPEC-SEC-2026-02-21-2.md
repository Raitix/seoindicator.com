# TEST PLAN: SPEC-SEC-2026-02-21-2

## Objective
Ensure the correctness, security, and reliability of rotating the `APP_KEY` and configuring related GitHub secrets.

## Test Scope
This test plan covers the following aspects:
- Functional validation: Confirm that secrets are securely rotated and set up in GitHub repository secrets.
- Workflow validation: Ensure that `.github/workflows/deploy.yml` properly references secrets and deploys successfully.
- Edge and failure cases: Test scenarios where the secrets are invalid, missing, or improperly set.
- Environmental impacts: Verify session invalidation and its resolution process.

---

## Test Cases

### Functional Tests

#### TC-01: `APP_KEY` Generation
**Description:** Validate that `php artisan key:generate --show` generates a valid `APP_KEY`.
- **Precondition:** Laravel application setup.
- **Steps:**
  1. Run the command: `php artisan key:generate --show`.
  2. Capture the output key.
- **Expected Result:** Output key is a valid 32-character random string.

#### TC-02: GitHub Secret Validation
**Description:** Confirm `APP_KEY` is securely stored as a GitHub repository secret.
- **Precondition:** Admin access to the GitHub repository.
- **Steps:**
  1. Upload the generated `APP_KEY` to repository secrets as `LARAVEL_APP_KEY`.
  2. Verify secret exists and is encrypted.
- **Expected Result:** Admin is able to access `LARAVEL_APP_KEY` in secrets; value matches generated key.

#### TC-03: Workflow Secret Injection
**Description:** Ensure deployment workflow references GitHub secrets correctly.
- **Precondition:** Updated `.github/workflows/deploy.yml`.
- **Steps:**
  1. Review workflow for environment secret usage.
  2. Test syntax correctness with a `dry-run`.
- **Expected Result:** No syntax errors; workflow uses `LARAVEL_APP_KEY` securely.

---

### Edge Cases

#### TC-04: Missing GitHub Secrets
**Description:** Simulate deployment without `LARAVEL_APP_KEY` in GitHub secrets.
- **Precondition:** Secret `LARAVEL_APP_KEY` is unset.
- **Steps:**
  1. Trigger deploy pipeline.
- **Expected Result:** Deployment fails with environment variable error.

#### TC-05: Invalid Secrets Format
**Description:** Upload improperly formatted `APP_KEY` to GitHub secrets.
- **Precondition:** `APP_KEY` has incorrect format.
- **Steps:**
  1. Upload a non-32-character string as `LARAVEL_APP_KEY`.
  2. Trigger deploy pipeline.
- **Expected Result:** Pipeline fails with validation error.

---

### Environmental Impact

#### TC-06: Session Invalidity
**Description:** Verify that user sessions become invalid after `APP_KEY` rotation.
- **Precondition:** Existing active user sessions.
- **Steps:**
  1. Rotate `APP_KEY`.
  2. Validate logged-in user sessions.
- **Expected Result:** Users are logged out; login screen is presented.
