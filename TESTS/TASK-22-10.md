## Notes for Developer

1. **Service Location:** `app/Services/Crawler/CrawlQueueService.php`
2. **Link Extractor:** `app/Services/Crawler/LinkExtractorService.php`
3. **DTOs:** Create QueueItem and QueueStats data classes
4. **Database vs Redis:** Start with database queue, Redis optional
5. **Bloom Filter:** Use `bloom-filter` package if needed, or simple set for MVP

### Recommended Class Structure

```php
// CrawlQueueService.php
namespace App\Services\Crawler;

class CrawlQueueService
{
    public function addToQueue(string $jobId, array $links, int $depth): void;
    public function getNextItem(string $jobId): ?QueueItem;
    public function markProcessing(string $itemId, string $workerId = null): void;
    public function markCompleted(string $itemId): void;
    public function markFailed(string $itemId, string $error): void;
    public function markSkipped(string $itemId, string $reason = null): void;
    public function getQueueStats(string $jobId): QueueStats;
    public function cleanupQueue(string $jobId): void;
}

// LinkExtractorService.php
namespace App\Services\Crawler;

class LinkExtractorService
{
    public function extractLinks(string $html, string $baseUrl, array $options = []): array;
    public function extractImages(string $html, string $baseUrl): array;
    public function extractScripts(string $html, string $baseUrl): array;
    public function extractStylesheets(string $html, string $baseUrl): array;
    public function extractIframes(string $html, string $baseUrl): array;
}

// QueueItem.php (DTO)
namespace App\Services\Crawler\Data;

class QueueItem
{
    public string $id;
    public int $crawlJobId;
    public string $url;
    public int $depth;
    public int $priority;
    public string $status;
    public ?string $parentUrl;
    public int $attempts;
    public ?string $error;
    public \DateTime $createdAt;
    public \DateTime $updatedAt;
    public ?\DateTime $lockedAt;
    public ?string $lockedBy;
}

// QueueStats.php (DTO)
namespace App\Services\Crawler\Data;

class QueueStats
{
    public int $total;
    public int $pending;
    public int $processing;
    public int $completed;
    public int $failed;
    public int $skipped;
}
```

### Priority Calculation
```php
// Depth 0 = High priority (67-100)
// Depth 1 = Medium priority (34-66)
// Depth 2 = Low priority (0-33)
$priority = max(0, 100 - ($depth * 33));
```

### Retry Backoff
```php
// Exponential backoff: 2^attempt seconds
$delay = pow(2, $attempts); // 1s, 2s, 4s...
```
