## Notes for Developer

1. **Service Location:** `app/Services/Crawler/CrawlQueueService.php`
2. **Link Extractor:** `app/Services/Crawler/LinkExtractorService.php`
3. **Duplicate Detector:** `app/Services/Crawler/DuplicateDetector.php`
4. **Dependency Injection:** Inject CrawlJob, Logger, DuplicateDetector via constructor
5. **Configuration:** Use `config('crawler.queue.*')` keys
6. **Queue Storage:** Use database (crawl_queue_items table) or Redis
7. **Locking:** Use Laravel Cache atomic locks for concurrent processing
8. **Bloom Filter:** Consider `bloom-filter` package for large-scale deduplication

### Recommended Class Structure

```php
// CrawlQueueService.php
namespace App\Services\Crawler;

class CrawlQueueService
{
    public function addToQueue(string $jobId, array $links, int $depth): void;
    public function getNextItem(string $jobId): ?QueueItem;
    public function markProcessing(string $itemId): bool;
    public function markCompleted(string $itemId): bool;
    public function markFailed(string $itemId, string $error): bool;
    public function markSkipped(string $itemId, string $reason): bool;
    public function getQueueStats(string $jobId): QueueStats;
    public function clearQueue(string $jobId, array $excludeStatuses = []): void;
}

// LinkExtractorService.php
namespace App\Services\Crawler;

class LinkExtractorService
{
    public function extractFromHtml(string $html, string $baseUrl, array $options = []): array;
    public function extractAnchorLinks(string $html, string $baseUrl): array;
    public function extractImageSources(string $html, string $baseUrl): array;
    public function extractStylesheetLinks(string $html, string $baseUrl): array;
    public function extractIframeSources(string $html, string $baseUrl): array;
}

// DuplicateDetector.php
namespace App\Services\Crawler;

class DuplicateDetector
{
    public function isDuplicate(string $url, string $context = 'default'): bool;
    public function add(string $url, string $context = 'default'): void;
    public function clear(string $context = 'default'): void;
}

// QueueItem.php (DTO)
namespace App\Services\Crawler\Data;

class QueueItem
{
    public string $id;
    public int $crawlJobId;
    public string $url;
    public int $depth;
    public int $priority;
    public string $status;
    public ?string $parentUrl;
    public int $attempts;
    public ?string $error;
    public ?Carbon $lockedAt;
    public ?string $workerId;
    public Carbon $createdAt;
    public Carbon $updatedAt;
}

// QueueStats.php (DTO)
namespace App\Services\Crawler\Data;

class QueueStats
{
    public int $total;

    public int $processing;
```
