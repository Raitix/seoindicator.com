## Overview

Test suite for `ImageAltChecker` - an SEO checker that identifies images missing alt text. Alt text is critical for accessibility and SEO, helping search engines understand image content and enabling screen readers to describe images to visually impaired users.

### Key Features Tested
1. Image extraction from HTML using DOM Crawler
2. Missing alt attribute detection
3. Empty alt="" attribute detection
4. Alt text length validation (>125 chars = warning)
5. Missing src attribute detection
6. Decorative image handling (empty alt is acceptable)
7. Context data population (image URLs, counts)

## Notes for Developer

1. **Use BaseChecker**: Extend `BaseChecker` which already has `extractImages()` method
2. **Issue Types**: Return findings with issue types `missing_image_alt`, `image_alt_too_long`, `image_missing_src`
3. **Severity**: Use 'notice' for missing alt, 'warning' for missing src
4. **Context Structure**:
   ```php
   [
       'images' => ['/path1.jpg', '/path2.jpg'],  // Missing alt srcs
       'count' => 2,
       'empty_alt_count' => 1,
       'too_long_count' => 0,
       'total_images' => 5
   ]
   ```
5. **Configuration**: Read `config('audit.images.max_alt_length', 125)` for length threshold
6. **Sanitization**: Use `htmlspecialchars()` or Laravel's `Str::limit()` for output safety
