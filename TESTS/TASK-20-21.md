## Technical Reference

### Sitemap Protocol (sitemap.org)
- Required tags: `<urlset>`, `<url>`, `<loc>`
- Optional tags: `<lastmod>`, `<changefreq>`, `<priority>`
- Max URLs per sitemap: 50,000
- Max file size: 50MB uncompressed
- Encoding: UTF-8

### Sitemap Index Structure
- Required: `<sitemapindex>`, `<sitemap>`, `<loc>`
- Optional: `<lastmod>`
- Use for sites with >50,000 URLs or >50MB

### Submission Methods
1. Google Search Console (manual)
2. Ping URL: `http://www.google.com/ping?sitemap=URL`
3. robots.txt reference: `Sitemap: https://example.com/sitemap.xml`
