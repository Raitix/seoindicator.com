## Notes for Developer

1. **Hook Location**: `frontend/hooks/useExperiment.ts`

2. **Service Location**: `backend/app/Services/ExperimentService.php`

3. **API Endpoint**: `GET /api/v1/experiments/{name}/variant`

4. **Assignment Algorithm**:
   - Use user_id hash for deterministic assignment
   - Map hash to traffic allocation buckets
   - Cache assignment in session/localStorage

5. **Integration Points**:
   - Call `useExperiment` in OnboardingContext
   - Include variant in all analytics events
   - Allow feature flags based on variant
