## Notes for Developer

### Component Interface

```typescript
interface PublicAuditCTAProps {
  auditHash: string;
  siteUrl: string;
  score: number;
}

interface LeadFormData {
  email: string;
}
```

### Key Implementation Points

1. **Form Validation**: Use React Hook Form with Zod schema
2. **API Integration**: POST to `/api/v1/public-audit/{hash}/lead`
3. **Social Sharing**: Use `navigator.share` with fallback to `window.open`
4. **Embed Code**: Generate HTML snippet with SVG badge
5. **Analytics**: Track form submit, share clicks, embed copies

### File Structure

```
frontend/components/audit/
├── PublicAuditCTA.tsx          # Main component
├── PublicAuditCTA.module.css   # Styles (or use Tailwind)
└── ...
```

### API Integration Pattern

```typescript
const submitLead = async (email: string, auditHash: string) => {
  const response = await fetch(`/api/v1/public-audit/${auditHash}/lead`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email })
  });
  
  if (!response.ok) {
    throw new Error('Failed to submit');
  }
  
  return response.json();
};
```
