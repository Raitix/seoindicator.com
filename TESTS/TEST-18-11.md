## Overview

Test coverage for `MetaDescriptionChecker` - SEO indicator checker that analyzes meta description tags for existence, length optimization, and keyword presence.

### Checker Properties
| Property | Value |
|----------|-------|
| ID | `meta_description` |
| Name | `Meta Description` |
| Category | `content` |
| Weight | `0.08` |

### Scoring Criteria
| Score | Condition |
|-------|-----------|
| 3 (Excellent) | Description exists, 150-160 chars, contains target keywords |
| 2 (Good) | Description exists, 120-170 chars, some keywords present |
| 1 (Poor) | Missing description, too short (<120), too long (>170), or no keywords |
| 0 (N/A) | Reserved for edge cases (not typically used) |

## Notes for Developer

### Implementation Requirements

1. **Class Location:** `backend/app/Services/SEO/Checkers/MetaDescriptionChecker.php`

2. **Required Methods:**
   - `id(): string` → return `'meta_description'`
   - `name(): string` → return `'Meta Description'`
   - `category(): string` → return `'content'`
   - `weight(): float` → return `0.08`
   - `check(Crawler, string, array): IndicatorResult`
   - `getSuggestions(IndicatorResult): array`

3. **Scoring Logic:**
   ```
   Score 3: exists AND 150-160 chars AND has keywords
   Score 2: exists AND (120-170 chars OR has keywords)
   Score 1: missing OR too short/long OR no redeeming qualities
   ```

4. **CSS Selector:** `meta[name="description"]`

5. **Details to Include:**
   - `exists`: boolean
   - `content`: string (actual description text)
   - `char_count`: int
   - `is_optimal_length`: boolean
   - `is_acceptable_length`: boolean
   - `keywords_found`: array of matched keywords
   - `is_auto_generated`: boolean (if detectable)
   - `duplicate_count`: int (if multiple found)

6. **Auto-Generated Patterns to Detect:**
   - "This is the excerpt..."
   - "Page X of Y results..."
   - "Posted on [date]..."
   - Trailing "..." suggesting truncation
   - All lowercase, no punctuation
