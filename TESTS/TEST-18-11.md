## Test Scenarios

### Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| MD-01 | Meta description present | `<meta name="description" content="SEO services...">` | exists: true |
| MD-02 | Meta description missing | No meta description | exists: false, score: 1 |
| MD-03 | Empty content | `<meta name="description" content="">` | exists: true, empty: true |
| MD-04 | Multiple descriptions | Two meta description tags | uses first, warning |
| MD-05 | Wrong attribute | `<meta description="text">` | Not detected (needs name="description") |

### Length Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| ML-01 | Too short (< 120 chars) | Content < 120 chars | isOptimalLength: false |
| ML-02 | Sub-optimal (120-149 chars) | Content 120-149 chars | isOptimalLength: false |
| ML-03 | Optimal (150-160 chars) | Content 150-160 chars | isOptimalLength: true |
| ML-04 | Acceptable (161-170 chars) | Content 161-170 chars | isOptimalLength: false |
| ML-05 | Too long (> 170 chars) | Content > 170 chars | isOptimalLength: false |
| ML-06 | Exact 150 chars | Content exactly 150 chars | isOptimalLength: true |
| ML-07 | Exact 160 chars | Content exactly 160 chars | isOptimalLength: true |

### Keywords Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| MK-01 | Primary keyword present | Description with target keyword | hasKeywords: true |
| MK-02 | Multiple keywords | Description with multiple keywords | hasKeywords: true |
| MK-03 | No keywords | Generic description | hasKeywords: false |
| MK-04 | Auto-generated pattern | "This is the default description..." | appearsAutoGenerated: true |

### Scoring Tests

| ID | Scenario | Input | Expected Score |
|----|----------|-------|----------------|
| SC-01 | Perfect description | 150-160 chars + keywords | 3 (Excellent) |
| SC-02 | Good description | Exists with minor issues | 2 (Good) |
| SC-03 | Poor description | Missing or too short/long | 1 (Poor) |

### Suggestion Generation Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| SG-01 | Missing description | No meta description | Suggest adding |
| SG-02 | Too short | < 120 chars | Suggest extending |
| SG-03 | Too long | > 170 chars | Suggest shortening |
| SG-04 | No keywords | Generic description | Suggest adding keywords |
| SG-05 | Auto-generated | Default WordPress/Drupal | Suggest customizing |

### Interface Compliance Tests

### Edge Case Tests

| ID | Scenario | Input | Expected Output |

## Expected Result Structure

```php
new IndicatorResult(
    id: 'meta_description',
    name: 'Meta Description',
    category: 'content',
    score: 3,
    weight: 0.08,
    passed: true,
    details: [
        'exists' => true,
        'description' => 'Get professional SEO services...',
        'length' => 145,
        'isOptimalLength' => false,
        'hasKeywords' => true,
        'appearsAutoGenerated' => false,
    ],
    suggestions: [
        [
            'type' => 'warning',
            'message' => 'Description length (145 chars) is below optimal (150-160 chars).',
            'action' => 'Add more compelling text to reach optimal length.',
        ]
    ]
);
```
