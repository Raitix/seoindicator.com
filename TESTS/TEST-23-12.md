## Overview

Unit tests for the `BacklinkSuggestionService` that generates actionable suggestions for improving backlink profile. The service analyzes metrics from `BacklinkProfileScorer` and produces prioritized recommendations based on detected issues.

## Notes for Developer

### Implementation Requirements

1. **Service Class:** `App\Services\SEO\BacklinkSuggestionService`
2. **Primary Method:** `generate(Project $project): array` or `generateFromMetrics(array $metrics): array`
3. **Return Structure:** Array of suggestion objects, sorted by priority (high → medium → low)

### Suggestion Thresholds

```php
private const THRESHOLD_REFERRING_DOMAINS = 50;     // Below = suggest
private const THRESHOLD_EXACT_MATCH_RATIO = 0.25;   // Above = suggest
private const THRESHOLD_DOMAIN_TRUST = 40;          // Below = suggest
private const THRESHOLD_GROWTH_DECLINE = -5;        // Below = suggest
private const THRESHOLD_NOFOLLOW_RATIO = 0.50;      // Above = suggest
```

### Suggestion Structure

```php
[
    'id' => string,           // Unique identifier
    'title' => string,        // Short title
    'description' => string,  // Detailed recommendation
    'priority' => string,     // 'high', 'medium', 'low'
    'impact' => string,       // 'high', 'medium', 'low'
    'metrics' => [            // Optional: supporting data
        'current' => mixed,
        'benchmark' => mixed,
        'gap' => mixed,
    ],
]
```

### Priority Sorting

Suggestions should be sorted by priority level:
1. High priority first
2. Medium priority second
3. Low priority last

Within same priority, sort by impact (high → medium → low).
