```json

  "success": false,
  "error": {
    "code": "FETCH_FAILED",
    "message": "Could not access the page",
    "details": "The server returned a 403 Forbidden response",
    "suggestion": "The page may be blocking automated access. Try a different URL."
  },
  "request_id": "req_abc123",
  "timestamp": "2026-02-27T12:00:00Z"
}
```

### ToolError Props
```typescript
interface ToolErrorProps {
  code: ErrorCode;
  message: string;
  suggestion?: string;
  onRetry?: () => void;
  onDismiss?: () => void;
  showRetry?: boolean;
  severity?: 'error' | 'warning' | 'info';
}
```

### Error Codes Configuration
```typescript
const ERROR_CODES = {
```

## Notes for Developer

1. **Error Handler Service**: Create `backend/app/Services/ToolErrorHandler.php` with methods:
   - `createError(string $code, array $context = []): ToolError`
   - `isRetryable(ToolError $error): bool`
   - `getRetryDelay(ToolError $error, int $attempt): int`
   - `logError(ToolError $error, Request $request): void`

2. **Error Response**: Use Laravel's `response()->json()` with consistent format

3. **Frontend Component**: Create `frontend/components/tools/ToolError.tsx`

4. **Error Boundary**: Create `frontend/components/tools/ErrorBoundary.tsx`

5. **Retry Logic**: Implement in `frontend/lib/utils/retry.ts` for client-side retries

6. **Configuration**: Error codes and messages should be configurable via config file
