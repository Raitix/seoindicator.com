## Notes for Developer

1. **Service Location:** Create `CompetitorComparisonService` at `app/Services/AIVisibility/CompetitorComparisonService.php`

2. **Cache Keys:** Use format `ai_visibility:{type}:{projectId}:{identifier}` for consistency

3. **Trend Thresholds:**
   - `< 5%` change = `stable`
   - `>= 5%` increase = `up`
   - `>= 5%` decrease = `down`

4. **Co-mention Detection:** Both brand and competitor must appear in the same response's `mentions` array

5. **Advantage Detection:**
   - Count mention types for each brand
   - Brand has advantage if it has more of a specific type than competitor
   - Types: `recommendation`, `comparison`, `use_case`, `feature`, `neutral`

6. **Database Queries:** Use a single query with JOINs where possible to avoid N+1

7. **Error Handling:** Return empty arrays for no data, throw exceptions for invalid parameters
