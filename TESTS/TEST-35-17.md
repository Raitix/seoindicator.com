## Notes for Developer

1. **API Mocking:** All tests use mocked API responses. When TASK-35-13 is complete, integration tests can be added.

2. **Geocoding:** The form includes address geocoding. Mock the geocode API response:
   ```typescript
   vi.mock('@/lib/api/geocode', () => ({
     geocodeAddress: vi.fn().mockResolvedValue({
       latitude: 40.7128,
       longitude: -74.0060
     })
   }));
   ```

3. **GBP Connection:** The connection status is read-only in this UI. GBP connection is handled by a separate task.

4. **Form Validation:** Use Zod schema for form validation matching the backend validation rules.

5. **Responsive Design:** Test both mobile (375px) and desktop (1024px+) viewports.

6. **Accessibility:** Ensure all interactive elements have proper ARIA labels and keyboard navigation.
