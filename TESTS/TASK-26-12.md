## Overview

Unit tests for PayPalGatewayService, implementing `PaymentGatewayInterface` as an alternative payment provider to Stripe. Uses PayPal Orders API v2 for payment processing.

**Test Approach:**
- Mock PayPal SDK (`paypal/rest-api-sdk-php`)
- Follow patterns from StripeGatewayServiceTest
- Test all PaymentGatewayInterface methods
- Security-critical webhook signature verification tests
- Idempotency and error handling tests

## Notes for Developer

1. **PayPal Orders API v2**: Use Orders API, not classic Payments API
2. **Webhook Signature**: PayPal uses different signature method than Stripe
3. **No Customer Storage**: PayPal uses payer_id from orders, no customer objects
4. **Amount Format**: PayPal uses string amounts ("10.00"), not cents
5. **Idempotency**: Use PayPal-Request-Id header
6. **Return/Cancel URLs**: Must be set in order creation for frontend redirect
