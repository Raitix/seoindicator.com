## Overview
Test coverage for the PayPal Smart Buttons capture order endpoint. This endpoint is called by the frontend after a user approves the payment in the PayPal popup. It captures the approved order, adds credits to the user's account, and updates the transaction status.

### Endpoint Under Test
- **POST** `/api/v1/payments/paypal/capture`
- **Authentication:** Required (Bearer token)
- **Purpose:** Capture an approved PayPal order and credit the user

## Notes for Developer

### Implementation Checklist
- [ ] `capturePayPalOrder()` method in PaymentController
- [ ] Validate `order_id` exists in pending transactions
- [ ] Validate `order_id` belongs to authenticated user
- [ ] Validate order state is 'approved' (not captured, cancelled, expired)
- [ ] Call `PayPalGatewayService->capturePayment($orderId)`
- [ ] On success: call `CreditService->addCredits()`
- [ ] Update transaction status to 'completed'
- [ ] Return transaction_id, amount, credits, new_balance

### Security Requirements
- **Order ownership verification BEFORE capture** - prevents IDOR
- **Prevent double capture** - check order state, use DB transactions
- **Idempotency** - same order_id returns same result
- **Audit logging** - log all capture attempts

### Database Transaction Flow
```php
DB::transaction(function () use ($order, $user, $amount) {
    // 1. Lock order for update
    $order = Transaction::lockForUpdate()->find($orderId);
    
    // 2. Check state
    if ($order->status !== 'approved') {
        throw new OrderNotApprovedException();
    }
    
    // 3. Capture via PayPal
    $captureResult = $this->paypal->capturePayment($orderId);
    
    // 4. Add credits
    $this->creditService->addCredits($user, $credits, 'purchase', [
        'order_id' => $orderId,
        'capture_id' => $captureResult->capture_id,
    ]);
    
    // 5. Update order status
    $order->update(['status' => 'completed']);
});
```

### Response Format
Follow SPEC-006 standard:
```php
return response()->json([
    'success' => true,
    'data' => [
        'transaction_id' => $transaction->id,
        'amount' => $captureResult->amount,
        'credits' => $credits,
        'new_balance' => $this->creditService->getBalance($user),
    ]
]);
```
