## Notes for Developer

### Service Interface
```php
class ModelPricingService
{
    // Model listing
    public function getAvailableModels(): Collection;
    public function getModelById(int $id): ?AIModel;
    public function getModelByProviderId(string $provider, string $modelId): ?AIModel;
    
    // Pricing
    public function getModelPricing(string $modelId): ?array;
    public function calculateAnalysisCost(string $modelId, int $estimatedTokens, ?int $outputTokens = null): float;
    
    // Sync
    public function syncModelsFromOpenRouter(): int;
    public function invalidateModelCache(): void;
    
    // User preferences
    public function getUserDefaultModel(User $user): ?AIModel;
    public function setUserDefaultModel(User $user, int $modelId): void;
}
```

### Cache Keys
- `ai_models_available` - List of active models (1 hour TTL)
- `user_default_model:{user_id}` - User's default model (1 hour TTL)

### Cost Calculation Formula
```
input_cost = (input_tokens / 1000) * cost_per_1k_input
output_cost = (output_tokens / 1000) * cost_per_1k_output
total_cost = round(input_cost + output_cost, 2)
```

### OpenRouter Sync Notes
- API endpoint: `https://openrouter.ai/api/v1/models`
- Free to query (no cost)
- Rate limited but generous limits
- Sync should be idempotent
- Models not in response get deactivated

### Security Requirements
- Validate model_id before database lookup
- Use parameterized queries (Eloquent)
- Rate limit sync operations
- Log sync operations for audit
- Sanitize model names (strip HTML/scripts)
