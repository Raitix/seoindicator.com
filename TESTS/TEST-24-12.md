## Component Behavior Notes

### Sorting
Recommendations are sorted client-side by priority:
1. High priority (first)
2. Medium priority (second)
3. Low priority (last)

Within the same priority, original order is preserved (stable sort).

### Section Expansion
- High priority section is **expanded by default**
- Medium and Low sections are **collapsed by default**
- User can toggle any section by clicking header
- If total recommendations ≤ 3, all sections expanded

### maxVisible
When `maxVisible` prop is set:
- Only first N recommendations shown
- "+N more" button reveals all
- After reveal, button changes to "Show less"
- Sorting still applies (highest priority visible first)

### Empty State
When `recommendations` is empty or undefined:
- Success message displayed
- Green checkmark icon
- No "View Guide" button
- No sections rendered
