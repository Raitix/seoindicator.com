# TEST-33-34: E2E Tests for Badge Embedding

## Task Reference
- **Task:** [TASK-33-34](../TASKS/TASK-33-34.md)

## Overview
Comprehensive end-to-end tests for the badge embedding system using Playwright. Tests verify that badges work correctly when embedded on third-party pages, including SVG badges, JavaScript badges, iframe badges, click navigation, tracking, auto-refresh, and accessibility.
