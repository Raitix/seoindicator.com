## Overview
Test suite for CrawlController REST API endpoints. The Crawler API enables initiation of JS-rendered crawl jobs, status tracking, content retrieval, and job management for the Headless Crawler Service.

### Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/crawler/crawl` | Initiate crawl job |
| GET | `/api/v1/crawler/jobs/{jobId}` | Get crawl job status |
| GET | `/api/v1/crawler/jobs/{jobId}/content` | Get crawled content |
| DELETE | `/api/v1/crawler/jobs/{jobId}` | Cancel crawl job |
| GET | `/api/v1/crawler/jobs` | List user's crawl jobs |

### Authentication
- Bearer token (Sanctum)
- Users can only access their own jobs

### TDD Approach
Tests use mocked CrawlerService interface:
- `createJob(userId, url, options): CrawlJob`
- `getJob(jobId): ?CrawlJob`
- `cancelJob(jobId): bool`
- `getJobContent(jobId): ?CrawlContent`
- `listJobs(userId, filters): CrawlJob[]`

## Notes for Developer

### Routes Required (routes/api.php)
```php
Route::prefix('v1/crawler')->middleware(['auth:sanctum', 'throttle:crawler'])->group(function () {
    Route::post('crawl', [CrawlController::class, 'store']);
    Route::get('jobs', [CrawlController::class, 'index']);
    Route::get('jobs/{jobId}', [CrawlController::class, 'show']);
    Route::get('jobs/{jobId}/content', [CrawlController::class, 'content']);
    Route::delete('jobs/{jobId}', [CrawlController::class, 'destroy']);
});
```

### Controller Required
`app/Http/Controllers/Api/V1/CrawlController.php`

### Request Validation Required
`app/Http/Requests/CrawlRequest.php`

### Key Implementation Details

1. **Job ID Format**: `crawl-{uuid}` (prefix + UUID v4)
2. **Authentication**: Sanctum session/Bearer token
3. **Authorization**: 
   - User owns job (via user_id on crawl_jobs)
   - Return 404 for unauthorized access (prevents enumeration)
4. **SSRF Protection**: Comprehensive URL validation before queueing
5. **Rate Limiting**:
   - 10 crawl jobs per user per day
   - 3 concurrent jobs per user
   - Custom throttle middleware
6. **Response Status Codes**:
   - 202 Accepted (POST /crawl)
   - 200 OK (GET, DELETE)
   - 409 Conflict (wrong job state)
   - 422 Validation Error
   - 429 Rate Limit Exceeded
7. **Async Processing**: Jobs queued to Laravel queue
