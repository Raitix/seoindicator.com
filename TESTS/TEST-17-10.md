## Notes for Developer

1. **Component Location**: `frontend/components/onboarding/ProgressBar.tsx`

2. **Props Interface**:
```typescript
interface ProgressBarProps {
  currentStep: number;
  completedSteps: number[];
  totalSteps: number;
  showLabels?: boolean;
  className?: string;
}
```

3. **Visual Design**:
```
[●]──[●]──[◉]──[○]──[○]
Step 1  2    3    4    5

● = Completed (checkmark)
○ = Upcoming (outlined)
◉ = Current (highlighted)
```

4. **Accessibility Requirements**:
   - role="progressbar" with aria-valuenow/min/max
   - aria-label with percentage
   - Each step indicator needs aria-label
   - Screen reader text for progress

5. **Animation**:
   - CSS transitions for step changes
   - Smooth fill animation on connectors
