## Implementation Notes for Developer

### Database Queries

**Pending by Queue:**
```php
DB::table('jobs')
    ->select('queue', DB::raw('COUNT(*) as count'))
    ->groupBy('queue')
    ->get();
```

**Failed Last 24h:**
```php
DB::table('failed_jobs')
    ->where('failed_at', '>=', now()->subDay())
    ->count();
```

**Average Processing Time:**
```php
// Using queue_jobs table (if tracking start/complete times)
DB::table('queue_jobs')
    ->where('status', 'completed')
    ->whereNotNull('started_at')
    ->whereNotNull('completed_at')
    ->selectRaw('AVG(TIMESTAMPDIFF(MICROSECOND, started_at, completed_at) / 1000) as avg_ms')
    ->value('avg_ms');
```

### Worker Count Registration

Workers should register themselves via cache:

```php
// In worker startup
Cache::put('queue:workers:count', $workerCount, 300); // 5 min TTL
```

Or integrate with Laravel Horizon:

```php
if (class_exists(\Laravel\Horizon\Horizon::class)) {
    return Horizon::masterSupervisor()->processes;
}
```
