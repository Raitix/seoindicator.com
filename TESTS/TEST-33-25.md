## Notes for Developer

### Implementation Requirements

1. **generateMetadata function** must be exported from `frontend/app/audit/[hash]/page.tsx`

2. **Title truncation logic:**
   - Max title length: ~60 chars for SEO (allow up to 70 with branding)
   - Truncate long URLs: `url.slice(0, 30) + '...'` if needed
   - Always include " | SEOIndicator" branding

3. **Description formatting:**
   - Format: "SEO audit for {url} - Score: {score}/100. View technical SEO analysis and recommendations."
   - Max length: 160 characters (Google's display limit)

4. **Canonical URL:**
   - Use `NEXT_PUBLIC_SITE_URL` environment variable
   - Format: `{SITE_URL}/audit/{hash}/`
   - Always HTTPS, always trailing slash

5. **OG Image URL:**
   - Format: `{SITE_URL}/badge/{hash}/og.png`
   - Dimensions: 1200x630 (standard OG image size)
   - Alt text: "SEO Score: {score}/100"

6. **Twitter Card:**
   - Always use `summary_large_image` for best display
   - Mirror OG title and description
   - Same image as OG

7. **Error handling:**
   - Return fallback metadata for errors
   - Use `noindex` robots for error cases
   - Don't expose internal URLs or error details

### generateMetadata Implementation Pattern

```typescript
export async function generateMetadata({ params }: PageProps): Promise<Metadata> {
  const { hash } = await params;
  const audit = await getAuditData(hash);

  if (!audit) {
    return {
      title: 'Audit Not Found',
      description: 'The requested SEO audit could not be found.',
      robots: 'noindex',
    };
  }

  // Strip protocol for display
  const displayUrl = audit.siteUrl
    .replace(/^https?:\/\//, '')
    .replace(/\/$/, '');

  // Truncate long URLs for title
  const truncatedUrl = displayUrl.length > 40 
    ? displayUrl.slice(0, 37) + '...' 
    : displayUrl;

  const title = `${truncatedUrl} SEO Audit Report | SEOIndicator`;
  const description = `SEO audit for ${displayUrl} - Score: ${audit.overallScore}/100. View technical SEO analysis and recommendations.`;
  const canonical = `${process.env.NEXT_PUBLIC_SITE_URL}/audit/${hash}/`;

  return {
    title,
    description,
    robots: 'index, follow',
    alternates: { canonical },
    openGraph: {
      title: `${displayUrl} SEO Score: ${audit.overallScore}/100`,
      description: `SEO audit results for ${displayUrl}`,
      url: canonical,
      type: 'website',
      images: [{
        url: `${process.env.NEXT_PUBLIC_SITE_URL}/badge/${hash}/og.png`,
        width: 1200,
        height: 630,
        alt: `SEO Score: ${audit.overallScore}/100`,
      }],
    },
    twitter: {
      card: 'summary_large_image',
      title: `${displayUrl} SEO Score: ${audit.overallScore}/100`,
      description: `SEO audit results for ${displayUrl}`,
      images: [`${process.env.NEXT_PUBLIC_SITE_URL}/badge/${hash}/og.png`],
    },
  };
}
```
