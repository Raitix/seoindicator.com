## Notes for Developer

### Implementation Requirements

1. **Controller Location:** `app/Http/Controllers/Api/V1/ModelController.php`

2. **Route Registration:** Add to `routes/api.php`:
   ```php
   Route::get('/models', [ModelController::class, 'index']);
   ```

3. **Service Dependency:** Inject `ModelPricingService` via constructor

4. **Query Parameters to Handle:**
   - `provider` (string, optional) - Filter by provider name
   - `free_only` (boolean, optional) - Filter to free tier models only
   - `capability` (string, optional) - Filter by capability name
   - `sort` (string, optional) - Sort by 'price', 'name', 'context' (default: 'name')

5. **Response Building:**
   - Use `success` field (boolean)
   - Include `data` array with all model fields
   - Include `meta` object with `total` and `free_tier_count`

6. **Authentication Handling:**
   - Endpoint is public (no auth required)
   - If user is authenticated, query `is_user_default` for each model
   - Set `is_user_default: true` for user's default model

7. **Validation:**
   - Validate `sort` is one of: 'price', 'name', 'context'
   - Sanitize string inputs for SQL injection prevention
   - Convert `free_only` to boolean

8. **Performance:**
   - Consider caching the response (1-hour TTL recommended)
   - Use ETag for conditional requests
