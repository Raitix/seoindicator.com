## Test Scenarios

### Canonical Existence Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CE-01 | Canonical present | `<link rel="canonical" href="https://example.com/page">` | hasCanonical: true |
| CE-02 | Canonical missing | No canonical link | hasCanonical: false |
| CE-03 | Multiple canonicals | Two canonical links | hasCanonical: true, warning |
| CE-04 | Empty href | `<link rel="canonical" href="">` | hasCanonical: true, isEmpty: true |

### Canonical Validity Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CV-01 | Valid absolute URL | `https://example.com/page` | isValid: true |
| CV-02 | Valid relative URL | `/page` | isValid: true, normalized |
| CV-03 | Invalid URL | `not-a-url` | isValid: false |
| CV-04 | Different protocol | `http://` when page is `https://` | warning |
| CV-05 | Different domain | Canonical to different domain | warning |

### Self-Referencing Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| SR-01 | Self-referencing | Canonical matches current URL | isSelfReferencing: true |
| SR-02 | Different path | Canonical to different path | isSelfReferencing: false |
| SR-03 | Query string diff | Canonical without query params | detected |
| SR-04 | Trailing slash diff | `/page` vs `/page/` | normalized comparison |

### Cross-Domain Canonical Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| CD-01 | Cross-domain allowed | Canonical to syndicated content | isCrossDomain: true, note |
| CD-02 | Same domain | Canonical within same site | isCrossDomain: false |

### Scoring Tests

| ID | Scenario | Input | Expected Score |
|----|----------|-------|----------------|
| SC-01 | Perfect canonical | Valid + self-referencing | 3 (Excellent) |
| SC-02 | Good canonical | Valid with minor issues | 2 (Good) |
| SC-03 | Poor canonical | Missing or invalid | 1 (Poor) |

### Interface Compliance Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| IC-01 | ID returns correct | id() | 'canonical' |
| IC-02 | Name returns correct | name() | 'Canonical URL' |
| IC-03 | Category returns correct | category() | 'technical' |
| IC-04 | Weight returns correct | weight() | 0.06 |

### Edge Case Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| EC-01 | HTTP header canonical | `Link: <https://...>; rel="canonical"` | Detected |
| EC-02 | Both header and link | Both present, same URL | OK |
| EC-03 | Conflicting canonicals | Header and link differ | Warning |
| EC-04 | Pagination canonical | `rel="canonical"` on page 2 | Check for rel="prev/next" |
| EC-05 | Protocol-relative | `//example.com/page` | Normalized |

## Mock Data

### Perfect Canonical
```html
<!DOCTYPE html>
<html>
<head>
  <link rel="canonical" href="https://example.com/page">
</head>
<body></body>
</html>
```

### Missing Canonical
```html
<!DOCTYPE html>
<html>
<head>
  <title>Page</title>
</head>
<body></body>
</html>
```

### Multiple Canonicals
```html
<!DOCTYPE html>
<html>
<head>
  <link rel="canonical" href="https://example.com/page">

</head>
<body></body>
</html>
```
