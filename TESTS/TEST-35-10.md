- Use `GBPApiServiceInterface` mock for API client

### SentimentAnalyzer Implementation
- Should be a standalone class (no external dependencies)
- Keyword lists should be comprehensive (50+ words each)
- Negation detection should look 1-2 words before sentiment word
- Consider "not very good" as negative (not positive)

### Queue Job
- `SyncGBPReviewsJob` should call `GBPReviewsService::syncReviews()`
- Test job dispatch and retry logic
- Test failure handling

### Edge Cases to Test
- Empty review text (sentiment: neutral)
- Very long review text (5000+ chars)
- Unicode/emoji in review text
- API pagination with 100+ pages
- Concurrent sync requests (locking)
