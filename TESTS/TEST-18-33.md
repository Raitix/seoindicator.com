## Shared Test Patterns

### Mock Indicator Result
```php
protected function createMockIndicatorResult(
    string $id,
    int $score,
    bool $passed = true
): IndicatorResult {
    return new IndicatorResult(
        id: $id,
        name: ucfirst(str_replace('_', ' ', $id)),
        category: 'test',
        score: $score,
        weight: 0.05,
        passed: $passed,
        details: [],
        suggestions: []
    );
}
```

### Mock HTML Crawler
```php
protected function createCrawler(string $html): Crawler
{
    return new Crawler($html);
}
```

### Mock HTTP Response
```php
Http::fake([
    'example.com/*' => Http::response('<html><body>Test</body></html>', 200),
    'timeout.com/*' => Http::timeout(),
    'error.com/*' => Http::response(null, 500),
]);
```
