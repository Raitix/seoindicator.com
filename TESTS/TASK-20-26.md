## Expected .htaccess Configuration

```apache
# ============================================================
# SEO Guides Clean URL Configuration
# ============================================================

# Enable RewriteEngine
RewriteEngine On

# SEO Guides: Redirect non-trailing-slash to trailing-slash
# /seo-guides -> /seo-guides/
RewriteCond %{REQUEST_URI} ^/seo-guides$ [NC]
RewriteRule ^(.*)$ /seo-guides/ [L,R=301]

# SEO Guides: Redirect guide pages without trailing slash
# /seo-guides/[slug] -> /seo-guides/[slug]/
RewriteCond %{REQUEST_URI} ^/seo-guides/([a-z0-9-]+)$ [NC]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ /seo-guides/%1/ [L,R=301]

# SEO Guides: Serve index.html for trailing-slash URLs
# /seo-guides/ -> /seo-guides/index.html
# /seo-guides/[slug]/ -> /seo-guides/[slug]/index.html
RewriteCond %{REQUEST_URI} ^/seo-guides/$ [NC]
RewriteCond %{REQUEST_FILENAME} -d
RewriteRule ^(.*)$ %1/index.html [L]

RewriteCond %{REQUEST_URI} ^/seo-guides/([a-z0-9-]+)/$ [NC]
RewriteCond %{REQUEST_FILENAME} -d
RewriteRule ^(.*)$ /seo-guides/%1/index.html [L]

# Security: Block access to hidden files
<FilesMatch "^\.">
    Order allow,deny
    Deny from all
</FilesMatch>

# Security: Block access to backup files
<FilesMatch "\.(bak|backup|old|orig|save)$">
    Order allow,deny
    Deny from all
</FilesMatch>

# Security headers
<IfModule mod_headers.c>
    Header set X-Content-Type-Options "nosniff"
    Header set X-Frame-Options "SAMEORIGIN"
    Header set X-XSS-Protection "1; mode=block"
</IfModule>
```

## Notes for Developer

1. **Apache Configuration:**
   - Ensure `mod_rewrite` is enabled: `a2enmod rewrite`
   - Place rules after existing API routing rules
   - Test on staging before production

2. **Next.js Configuration:**
   - `trailingSlash: true` in `next.config.ts`
   - Static export outputs `/seo-guides/[slug]/index.html`

3. **Testing Order:**
   - Test on local server first
   - Test on staging environment
   - Test on production after deployment

4. **Rollback Plan:**
   - Keep backup of original `.htaccess`
   - Test immediately after deployment
   - Revert if any routes break

5. **SEO Considerations:**
   - Use 301 (permanent) redirects, not 302
   - Ensure canonical URLs have trailing slash
   - Update sitemap.xml with correct URLs
