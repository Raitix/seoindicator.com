**Issue:** Vitest/Jest mocking incompatibility

```typescript
// Incorrect (Jest syntax used in Vitest project):
(useSWR as jest.Mock).mockReturnValue({...})

// Should be (Vitest syntax):
vi.mock('swr', () => ({
  default: vi.fn(() => ({ data: ..., isLoading: ... }))
}))
```

- API-003-01 to API-003-03: invalidateBalance tests

**Resolution Required:**
Update `__tests__/lib/api/credits.test.ts` to use Vitest's `vi` mocking utilities instead of Jest's `jest.Mock`.

**Assessment:**
- Component tests fully pass - actual components work correctly
