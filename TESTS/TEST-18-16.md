## Test Scenarios

### Alt Attribute Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AA-01 | Alt present | `<img alt="SEO services diagram">` | hasAlt: true |
| AA-02 | Alt missing | `<img src="image.jpg">` | hasAlt: false |
| AA-03 | Empty alt | `<img alt="">` | hasAlt: true, isEmpty: true |
| AA-04 | Space alt | `<img alt="   ">` | hasAlt: true, isEmpty: true |
| AA-05 | Null alt | `<img>` (no alt attribute) | hasAlt: false |

### Descriptive Alt Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| DA-01 | Descriptive alt | `alt="Team working on SEO strategy"` | isDescriptive: true |
| DA-02 | Generic alt | `alt="image"` | isDescriptive: false |
| DA-03 | Filename as alt | `alt="IMG_0001.jpg"` | isDescriptive: false |
| DA-04 | Too short | `alt="A"` | isDescriptive: false |
| DA-05 | Too long | 125+ char alt | isDescriptive: true, warning |

### Keywords in Alt Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| KA-01 | Keywords present | `alt="SEO services dashboard screenshot"` | hasKeywords: true |
| KA-02 | No keywords | `alt="A beautiful image"` | hasKeywords: false |
| KA-03 | Multiple keywords | `alt="SEO audit report with analytics"` | hasKeywords: true |

## Mock Data

### Good Alt Text
```html
<img src="seo-dashboard.png" alt="SEO dashboard showing keyword rankings over time">
<img src="team.jpg" alt="SEO team collaborating on client strategy">
```

### Missing Alt
```html
<img src="chart.png">
<img src="logo.png" alt="">
```

### Bad Alt Text
```html
<img src="product.jpg" alt="image">
<img src="screenshot.png" alt="screenshot.png">
```
