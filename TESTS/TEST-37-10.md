## Task Reference

## Status
`Tests Coverage Complete`

## Overview
Tests for Next.js middleware or AuthGuard component that protects routes requiring authentication. Ensures unauthenticated users are redirected to login with their intended destination preserved.

## Implementation Options

### Option A: Next.js Middleware (Preferred)
- **File:** `frontend/middleware.ts`
- **Runs:** Server-side before page render
- **Benefits:** No flash of protected content, more secure
- **Approach:** Check for auth token cookie, redirect if missing

### Option B: AuthGuard Component
- **File:** `frontend/components/auth/AuthGuard.tsx`
- **Runs:** Client-side in React tree
- **Benefits:** Access to AuthContext state
- **Approach:** Wrap protected route content

**Recommendation:** Next.js middleware (Option A) for "no flash" requirement.

## Notes for Developer

### Implementation Approach
1. **Preferred:** Create `frontend/middleware.ts` using Next.js middleware
2. Middleware checks for `seoindicator_token` cookie
3. If missing/invalid on protected route → redirect to `/login?redirect=<path>`
4. Public routes should be defined in a constant array

### Protected Routes List
```typescript
const protectedRoutes = [
  '/dashboard',
  '/settings',
  '/projects',
  '/competitors',
  '/comparison',
  '/notifications',
  '/sites',
  '/locations',
  '/ranking-history',
  '/guides',
  '/badges',
  '/history',
  '/audit',
  '/admin', // Also requires admin role
];
```

### Public Routes List
```typescript
const publicRoutes = [
  '/',
  '/login',
  '/register',
  '/forgot-password',

  '/verify-email',
  '/tools',
```

### Next.js Middleware Pattern
```typescript
// middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const token = request.cookies.get('seoindicator_token');
  const pathname = request.nextUrl.pathname;

  const isProtectedRoute = protectedRoutes.some(
    route => pathname === route || pathname.startsWith(route + '/')
  );

  if (isProtectedRoute && !token) {
    const loginUrl = new URL('/login', request.url);
    loginUrl.searchParams.set('redirect', pathname);
    return NextResponse.redirect(loginUrl);
  }

  // Redirect authenticated users away from login
  if (token && pathname === '/login') {
    return NextResponse.redirect(new URL('/dashboard', request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico|public).*)'],
};
```
