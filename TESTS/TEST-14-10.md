# TEST-14-10: Broken Link Checker Tests

## Task Reference
- Task: [TASK-14-10](../TASKS/TASK-14-10.md)

## Overview
Comprehensive test suite for BrokenLinkChecker service responsible for validating internal and external links during site crawling. Tests cover link extraction, HTTP status verification, HEAD/GET fallback for external links, and broken link categorization.

## Notes for Developer

1. **Service Interface Expected:**
   ```php
   interface BrokenLinkCheckerInterface
   {
       public function check(string $html, string $baseUrl, array $options = []): CheckSummary;
       public function checkUrl(string $url): BrokenLinkResult;
       public function setConfig(array $config): void;
   }
   ```

2. **HTTP Client Mocking:**
   ```php
   Http::fake([
       'https://example.com/existing' => Http::response('', 200),
       'https://example.com/notfound' => Http::response('', 404),
       'https://example.com/redirect' => Http::response('', 301, ['Location' => '/new']),
   ]);
   ```

3. **SSRF Protection Required:**
   - Block localhost, 127.0.0.1, ::1
   - Block private IP ranges (10.x, 172.16-31.x, 192.168.x)
   - Block cloud metadata IP (169.254.169.254)

4. **Performance Considerations:**
   - Cache already-checked URLs
   - Use HEAD requests for external links
   - Process links in batches
   - Implement rate limiting per domain

5. **Error Handling:**
   - Never throw exceptions on link check failures
   - Return error result with details
   - Log failures for debugging
