## Overview
Tests for adding clickable links from analysis results table rows to corresponding SEO guides. Users can click an indicator name in the results table to navigate to the relevant guide page for more information.

## Indicator-to-Guide Mapping

The following mapping is required to convert analysis indicator IDs to guide slugs:

| Indicator ID | Guide Slug | Notes |
|--------------|------------|-------|
| `meta_tags` | `meta-title` | Primary meta tags guide |
| `headings` | `h1-headings` | Primary heading guide |
| `images` | `image-alt-text` | Primary image guide |
| `links` | `internal-links` | Default to internal links |
| `url_structure` | `canonical-urls` | Closest match |
| `content_quality` | `h1-headings` | Fallback to headings |
| `mobile_friendly` | `mobile-friendly` | Direct match |
| `page_speed` | `page-speed` | Direct match |
| `structured_data` | `structured-data` | Direct match |
| `security` | `https-security` | Direct match |
| `accessibility` | `image-alt-text` | Closest match |
| `social_tags` | `open-graph` | Primary social guide |
| `canonical` | `canonical-urls` | Direct match |
| `robots` | `robots-txt` | Direct match |
| `sitemap` | `xml-sitemap` | Direct match |
| `internal_links` | `internal-links` | Direct match |

## Notes for Developer

1. **Mapping Function Location:** Add `getGuideSlugForIndicator()` to `frontend/lib/guides/registry.ts` or create new file `frontend/lib/guides/indicator-to-guide.ts`

2. **Link Component:** Use Next.js `Link` component for client-side navigation:
   ```tsx
   import Link from 'next/link';
   
   <Link href={`/seo-guides/${slug}`} aria-label={`View guide for ${name}`}>
     {displayName}
   </Link>
   ```

3. **Fallback Behavior:** Unknown indicators should render as plain text, not throw errors

4. **Styling:** Link should inherit parent text styling to maintain visual consistency

5. **Accessibility:** Add aria-label to describe the link purpose

6. **No External Links:** All guide links are internal navigation (no target="_blank")

7. **Click Propagation:** Use `e.stopPropagation()` on link click to prevent row expansion toggle
