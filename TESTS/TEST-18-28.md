## Test Scenarios

### Anonymous User Rate Limiting

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AR-01 | Within limit | < 3 analyses/day | 202 Accepted |
| AR-02 | At limit | 3 analyses | 202 Accepted |
| AR-03 | Over limit | 4th analysis | 429 Too Many Requests |
| AR-04 | Limit reset | Next day | Counter reset |
| AR-05 | Different IPs | Multiple IPs | Each has own limit |

### Authenticated User Rate Limiting

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AU-01 | Within limit | < 10 analyses/day | 202 Accepted |
| AU-02 | At limit | 10 analyses | 202 Accepted |
| AU-03 | Over limit | 11th analysis | 429 Too Many Requests |
| AU-04 | Different users | Multiple users | Each has own limit |
| AU-05 | Limit per user | Not per API key | User-based limit |

### Rate Limit Headers

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| RH-01 | X-RateLimit-Limit | Any request | Header present |
| RH-02 | X-RateLimit-Remaining | Within limit | Correct count |
| RH-03 | X-RateLimit-Reset | Any request | Unix timestamp |
| RH-04 | Retry-After | 429 response | Seconds until reset |

### Rate Limit Response

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| RR-01 | 429 response body | Rate limited | JSON with error details |
| RR-02 | Error code | Rate limited | RATE_LIMITED code |
| RR-03 | Retry info | Rate limited | retry_after in response |
| RR-04 | Human message | Rate limited | "Too many analyses..." |
