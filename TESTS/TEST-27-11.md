## Edge Cases Covered

1. **Cascade Failure Prevention** - Each service check has try-catch to prevent one failure from affecting others
2. **Missing Tables** - Queue check handles missing `jobs` and `failed_jobs` tables gracefully
3. **Timeout Handling** - Database timeout returns unhealthy status with error message
4. **Zero Latency** - Handles very fast queries that report 0ms latency
5. **Empty Services** - Overall status returns 'healthy' when no services checked
6. **Missing Status Key** - Overall status handles malformed service data
