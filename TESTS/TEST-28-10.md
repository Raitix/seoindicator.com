## Notes for Developer

### Implementation Files to Create
1. `frontend/components/ui/LinearProgress.tsx`
2. `frontend/components/ui/CircularProgress.tsx`

### Key Implementation Details

1. **Determinate vs Indeterminate Detection:**
   ```typescript
   const isDeterminate = value !== undefined;
   ```

2. **Value Clamping:**
   ```typescript
   const clampedValue = Math.min(100, Math.max(0, value));
   ```

3. **CircularProgress SVG Calculation:**
   ```typescript
   const strokeWidth = 4;
   const radius = (size - strokeWidth) / 2;
   const circumference = 2 * Math.PI * radius;
   const offset = circumference - (value / 100) * circumference;
   ```

4. **ARIA Attributes:**
   - Determinate: Set `aria-valuenow`, `aria-valuemin`, `aria-valuemax`
   - Indeterminate: Only `role="progressbar"` (no value attributes)

5. **Animation:**
   - Linear indeterminate: Use CSS animation with `translateX` or `width` keyframes
   - Circular indeterminate: Use CSS animation with `rotate` transform

6. **Dark Theme:**
   - Use CSS variables for colors (adapts to theme automatically)
   - Track circle: Use `bg-slate-800` or `--surface-2`
