## Notes for Developer

1. **Mock Data Approach:** Since TASK-27-13 (Health API) is not implemented, use mock data with optional API service layer that can be swapped when backend is ready.

2. **Auto-refresh Implementation:** Use `useEffect` with `setInterval` for 30-second polling. Provide pause/resume controls.

3. **Error Boundaries:** Consider wrapping panels in error boundaries for graceful failure.

4. **WebSocket Future:** Structure code to allow future WebSocket upgrade for real-time updates.

5. **Sound Notifications:** Optional - can be implemented with Audio API and localStorage preference.

6. **Accessibility:** All status changes should be announced to screen readers using aria-live regions.
