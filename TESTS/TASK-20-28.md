## Notes for Developer

1. **Image Generation Options:**
   - **Manual:** Create in Canva/Figma and export 18 images
   - **Semi-automated:** Create template, batch export with tool like Figma
   - **Automated:** Use `@vercel/og` or `puppeteer` for code-generated images

2. **Recommended Approach:**
   - Create a base template with SEOIndicator branding
   - Generate images programmatically using guide data
   - Use sharp or canvas for Node.js image generation

3. **Meta Tag Updates Required:**
   - Update `app/seo-guides/page.tsx` metadata to include `og:image`
   - Update `app/seo-guides/[slug]/page.tsx` generateMetadata function
   - Add `images` array to openGraph metadata object

4. **Image Storage:**
   - Store in `public/guides/og/` directory
   - Use descriptive filenames: `og-{slug}.png`
   - Commit images to repository (not .gitignored)

5. **Free Tools:**
   - **Canva Free:** Manual design with templates
   - **Figma:** Free for individuals, good batch export
   - **@vercel/og:** Code-generated (requires Vercel)
   - **sharp/canvas:** Node.js image generation
