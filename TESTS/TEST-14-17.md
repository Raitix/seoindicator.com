## Overview
Comprehensive unit tests for the AuditWidget React component that displays site audit summary with quick actions on the dashboard. Tests cover all 4 widget states: No Audits, Running, Completed with Issues, and All Fixed.

## Notes for Developer

1. **Component Location:** `frontend/components/dashboard/AuditWidget.tsx`

2. **Export:** Add to `frontend/components/dashboard/index.ts`

3. **Integration:** Import in site dashboard page:
   ```typescript
   import { AuditWidget } from '@/components/dashboard/AuditWidget';
   ```

4. **API Hook:** Create/use `useAuditWidgetData(siteId)` hook for data fetching

5. **Polling Logic:** When `runningAudit` is provided, parent should poll for updates using `pollingInterval`

6. **State Priority:**
   - If `runningAudit` exists → show running state (even if `lastAudit` provided)
   - If `lastAudit` with zero issues → show all fixed state
   - If `lastAudit` with issues → show completed state
   - Otherwise → show no audits state

7. **Cancel Audit:** The cancel button should call the audit cancel API (from TASK-14-13)
