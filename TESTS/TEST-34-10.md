## Mock Data

### Dashboard Data Structure

```typescript
interface DashboardData {
  project: {
    id: number;
    brandName: string;
    keywords: string[];
    competitors: string[];
    isActive: boolean;
    trackingFrequency: 'daily' | 'weekly' | 'monthly';
    lastQueriedAt: string;
  };
  metrics: {
    mentionRate: MetricValue;
    shareOfVoice: MetricValue;
    sentimentScore: SentimentMetric;
  };
  mentionRateOverTime: TimeSeriesPoint[];
  competitorComparison: CompetitorData[];
  recentMentions: Mention[];
  queryCategories: CategoryData[];
  quickActions: {
    canRunQuery: boolean;
    nextQueryAt: string;
    hasExportData: boolean;
  };
}

interface MetricValue {
  value: number;
  previousValue: number;
  change: number;
  trend: 'up' | 'down' | 'stable';
}

interface SentimentMetric extends MetricValue {
  label: 'Positive' | 'Negative' | 'Neutral' | 'Mixed';
}

interface TimeSeriesPoint {
  date: string;
  overall: number;
  chatgpt: number;
  perplexity: number;
}

interface CompetitorData {
  name: string;
  value: number;
  isBrand: boolean;
}

interface Mention {
  id: string;
  brandContext: string;
  platform: 'chatgpt' | 'perplexity' | 'claude';
  sentiment: 'positive' | 'negative' | 'neutral' | 'mixed';
  queriedAt: string;
}

interface CategoryData {
  name: string;
  value: number;
}
```

## Notes for Developer

1. **API Integration:** Tests use mocked fetch responses. Real API will return same data structure.

2. **Chart Libraries:** Recharts is mocked for deterministic testing. Verify visual output manually.

3. **Responsive Design:** Use CSS Grid/Flexbox with Tailwind breakpoints:
   - Mobile: `grid-cols-1`
   - Tablet: `md:grid-cols-2`
   - Desktop: `lg:grid-cols-3`

4. **Loading States:** 
   - Skeleton for metric cards (3 cards)
   - Spinner for charts
   - Progressive reveal as data loads

5. **Error Boundaries:** Wrap chart sections in error boundaries for graceful failure.

6. **Data Caching:** Use React Query with 5-minute stale time for dashboard data.

7. **Component Structure:**
   ```
   /app/ai-visibility/[projectId]/page.tsx
   /components/ai-visibility/
   ├── MetricCard.tsx
   ├── MentionRateChart.tsx
   ```
