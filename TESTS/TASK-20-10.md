## Notes for Developer

1. **Content Population:** Update the `sections` and `checklist` arrays in registry.ts for `image-optimization` guide
2. **Read Time Calculation:** Based on word count, typically 200-250 words per minute
3. **Code Examples:** Must include lazy loading examples in HTML and optionally Next.js Image component
4. **Core Web Vitals:** Mention LCP (Largest Contentful Paint) and CLS (Cumulative Layout Shift)
5. **File Formats:** Cover WebP, AVIF, JPEG, PNG with use case recommendations
6. **Checklist Items:** 5-10 items with appropriate priority levels
7. **Related Guides:** Must include `page-speed` and `image-alt-text`
8. **Content Quality:** Each section should be informative, actionable, and SEO-friendly

## Content Guidelines

### Section Content Requirements
- Each section should have 150-400 words
- Use markdown formatting (bold, lists, links)
- Include practical tips and examples
- Reference external tools/services (free tools only per CONSTITUTION.md)

### Checklist Item Requirements
- Clear, actionable text
- Appropriate priority level
- Covers key optimization areas
- Practical for users to implement

### Code Example Requirements
- Syntactically valid code
- Clear description of purpose
- Appropriate language tag
- Modern best practices
