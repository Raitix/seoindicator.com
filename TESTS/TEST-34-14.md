## Overview

Test suite for Analytics API endpoints that expose AI Visibility analytics data through REST API.

**Endpoints:**
1. `GET /api/v1/ai-visibility/projects/{id}/analytics` - Aggregated analytics
2. `GET /api/v1/ai-visibility/projects/{id}/comparison` - Brand vs competitors comparison
3. `GET /api/v1/ai-visibility/projects/{id}/trend` - Trend analysis over time
4. `GET /api/v1/ai-visibility/projects/{id}/queries` - Paginated query history
