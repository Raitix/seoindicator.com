## Notes for Developer

1. **Service Location**: `backend/app/Services/WebsiteKeywordSuggester.php`

2. **API Endpoint**: `GET /api/v1/suggestions/from-url?url={url}`

3. **Implementation Approach**:
   - Use Guzzle HTTP client for fetching
   - Use DOMDocument or similar for parsing
   - Cache in Redis with 1-hour TTL

4. **Error Handling**:
   - Timeout after 5 seconds
   - Return empty array on failure
   - Log errors for debugging

5. **Security**:
   - Validate URL format
   - Block internal IPs (SSRF prevention)
   - Rate limit per user
