## Test Overview

This document defines comprehensive tests for the Payment Methods Management API endpoints:
- `GET /api/v1/payments/methods` - List user's saved payment methods
- `DELETE /api/v1/payments/methods/{id}` - Delete a payment method

### Dependencies for Testing
- **StripeGatewayService** (TASK-26-8) - Mock the `getPaymentMethods()` and `deletePaymentMethod()` methods
- **PaymentGatewayInterface** - Use interface for mocking

### Mock Setup

// Mock PaymentGatewayInterface
$mock = Mockery::mock(PaymentGatewayInterface::class);

// For list tests
$mock->shouldReceive('getPaymentMethods')
    ->with($user)
    ->andReturn([
        [
            'id' => 'pm_test123',
            'type' => 'card',
            'card' => [
                'brand' => 'visa',
                'last4' => '4242',
                'exp_month' => 12,
                'exp_year' => 2026,
            ],
        ],
    ]);

// For delete tests
$mock->shouldReceive('deletePaymentMethod')
    ->with('pm_test123')
    ->andReturn(true);

$mock->shouldReceive('getPaymentMethodOwner')

    ->andReturn($user->id);

$this->app->instance(PaymentGatewayInterface::class, $mock);

## Database Schema (Required)

The `payment_methods` table is required for this task. If not created by TASK-26-1, it should be created as part of this task:

```php
Schema::create('payment_methods', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->onDelete('cascade');
    $table->string('stripe_customer_id'); // cus_...
    $table->string('stripe_payment_method_id')->nullable(); // pm_...
    $table->string('provider')->default('stripe');
    $table->string('brand')->nullable(); // visa, mastercard
    $table->string('last_four', 4)->nullable();
    $table->integer('exp_month')->nullable();
    $table->integer('exp_year')->nullable();
    $table->boolean('is_default')->default(false);
    $table->timestamps();

    $table->unique(['user_id', 'stripe_payment_method_id']);
    $table->index('stripe_customer_id');
});
```
