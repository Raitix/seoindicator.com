### Confirmed Drift
- The route group now uses `throttle:public-audit`, which drives Laravel through `RateLimiter::limiter('public-audit')`.
- The test file still partially mocks the older RateLimiter method path (`tooManyAttempts()`, `hit()`, etc.) and does not mock `limiter()`, so many requests fail with `Mockery\Exception\BadMethodCallException` before endpoint assertions execute.
- The badge contract documented below is stale: legacy notes expect `badge_url`/score-label style payload details, while the current controller returns `audit_url`, `impressions_endpoint`, `clicks_endpoint`, and a single `embed_code` string.

Treat the remainder of this file as the original delivery baseline from 2026-03-06 until TASK-33-31 is repaired and re-verified.

## Prerequisites

### Database Tables required:
- `audits` - with `visibility`, `public_hash`, `public_hash_created_at` columns
- `public_audit_views` - for view tracking
- `sites` - for audit relationships
- `audit_issues` - for issue data

### Models required:
- `App\Models\Audit` - with visibility and hash support
- `App\Models\Site` - for site URL
- `App\Models\AuditIssue` - for issues data

### Controller to implement:
- `App\Http\Controllers\Api\V1\PublicAuditController`
  - `show($hash)` - GET endpoint
  - `lead($hash)` - POST endpoint
  - `badge($hash)` - GET endpoint

### Routes to add:
```php
Route::get('public-audit/{hash}', [PublicAuditController::class, 'show']);
Route::post('public-audit/{hash}/lead', [PublicAuditController::class, 'lead']);
Route::get('public-audit/{hash}/badge', [PublicAuditController::class, 'badge']);
```
