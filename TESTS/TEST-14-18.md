```php
namespace App\Services\Audit\DTOs;

class AuditReportSection
{
    public function __construct(
        public readonly array $summary,
        public readonly array $criticalIssues,
        public readonly array $warningIssues,
        public readonly array $recommendations,
    ) {}
    
    public static function fromAudit(Audit $audit): self;
    public function toArray(): array;
    public function jsonSerialize(): array;

```

**PdfReportGenerator Extension:**
```php
// Add to existing PdfReportGenerator class
protected function addAuditSection(Pdf $pdf, AuditReportSection $audit): void
{
    // Add section header
    $pdf->addSectionHeader('Technical SEO Audit');
    
    // Add summary boxes
    $pdf->addSummaryBoxes([
        ['label' => 'Critical', 'value' => $audit->summary['critical'], 'color' => 'red'],
        ['label' => 'Warning', 'value' => $audit->summary['warning'], 'color' => 'orange'],
        ['label' => 'Notice', 'value' => $audit->summary['notice'], 'color' => 'yellow'],
    ]);
    
    // Add critical issues (limit to 10)
    if (count($audit->criticalIssues) > 0) {
        $pdf->addSubHeader('Critical Issues');
        foreach (array_slice($audit->criticalIssues, 0, 10) as $issue) {
            $pdf->addIssueItem($issue);
        }
    }
    
    // Add warnings (limit to 5)
    if (count($audit->warningIssues) > 0) {
        $pdf->addSubHeader('Warnings');
        foreach (array_slice($audit->warningIssues, 0, 5) as $issue) {
            $pdf->addIssueItem($issue);
        }
    }
    
    // Add recommendations
    $pdf->addRecommendationsList($audit->recommendations);
}
```

**ReportController Integration:**
```php
// In ReportController.php
public function generate(GenerateReportRequest $request)
{
    $siteId = $request->validated('site_id');
    
    // ... existing data collection
    
    // Add audit data if latest audit exists
    $latestAudit = Audit::where('site_id', $siteId)
        ->where('status', 'completed')
        ->latest()
        ->first();
    
    if ($latestAudit) {
        $reportData->auditData = AuditReportSection::fromAudit($latestAudit);
    }
    
    return $this->generatePdf($reportData);
}
```

### Key Implementation Points

1. **Extend existing PDF infrastructure** - Don't create new generator
2. **Severity limits enforced** - 10 critical, 5 warnings
3. **Color-coded badges** - Red (critical), Orange (warning), Yellow (notice)
4. **Page breaks** - Handle long issue lists gracefully
5. **Consistent styling** - Match existing PDF design language
6. **Null safety** - Handle missing audit data gracefully
