## Overview
Comprehensive tests for integrating technical SEO audit results into PDF reports. Tests cover the AuditReportSection DTO, PDF section rendering, severity breakdown display, issue listing with pagination, recommendations formatting, and ReportController integration. Follows TDD principles - tests are written before implementation.

### Expected Class Structure

#### AuditReportSection DTO
```php
namespace App\Exporters\DTOs;

class AuditReportSection
{
    public function __construct(
        public readonly array $summary,
        public readonly array $criticalIssues,
        public readonly array $warningIssues,
        public readonly array $recommendations,
    ) {}

    public static function fromArray(array $data): self;
    public function toArray(): array;
}
```

#### PdfReportGenerator Extension
```php
// In PdfReportGenerator.php
protected function addAuditSection(Pdf $pdf, AuditReportSection $audit): void
{
    // Add section header
    $pdf->addSectionHeader('Technical SEO Audit');
    
    // Add summary boxes
    $pdf->addSummaryBoxes([...]);
    
    // Add critical issues (limit to 10)
    // Add warnings (limit to 5)
    // Add recommendations
}
```

#### ReportController Integration
```php
// In ReportController.php
public function generate(GenerateReportRequest $request)
{
    // ... existing data collection
    
    // Add audit data if latest audit exists
    $latestAudit = Audit::where('site_id', $siteId)
        ->where('status', 'completed')
        ->latest()
        ->first();
    
    if ($latestAudit) {
        $reportData->auditData = $this->buildAuditSection($latestAudit);
    }
    
    return $this->generatePdf($reportData);
}
```
