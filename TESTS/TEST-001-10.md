### Add Job Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| ADD-001 | Add single keyword check job | Job created with type='single' |

| ID | Scenario | Expected Result |
|----|----------|-----------------|
| GET-001 | getJob with valid ID | Returns Job object |

### Update Job Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| UPD-001 | Update status to running | status='running', startedAt set |
| UPD-002 | Update status to completed | status='completed', completedAt set |

| ID | Scenario | Expected Result |

## Edge Cases
- Empty queue
- Queue with 1000+ pending jobs
- Concurrent job access
- Job with null keywordId (batch job)
- Job with both keywordId and siteId
- Invalid priority value
- Extremely long error messages
