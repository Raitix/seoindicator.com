## Notes for Developer

1. **API Hooks**: Create `useContentDecay.ts` hook file with:
   - `useContentDecaySummary(siteId)`
   - `useContentDecayCandidates(siteId, filters)`
   - `useContentDecayCandidate(id)`
   - `useContentDecaySettings(siteId)`
   - `useContentDecayRecovery(siteId, dateRange)`
   - `useRunContentDecayScan(siteId)`
   - `useUpdateCandidateStatus(id)`
   - `useExportContentDecay(siteId, format)`

2. **Page Routes**: Create pages at:
   - `app/sites/[siteId]/content-decay/page.tsx`
   - `app/sites/[siteId]/content-decay/board/page.tsx`
   - `app/sites/[siteId]/content-decay/recovery/page.tsx`
   - `app/sites/[siteId]/content-decay/settings/page.tsx`

3. **Authentication**: All pages require authentication. Use `useSession` or equivalent.

4. **SEO Metadata**: Each page should export `metadata` object.

5. **Loading States**: Use skeleton components during data fetching.

6. **Error States**: Show error message with retry button on failure.
