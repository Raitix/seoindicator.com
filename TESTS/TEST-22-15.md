## Overview
Test suite for CrawlWorker queue job that processes crawl jobs from the queue, orchestrating the full crawl pipeline including SSRF validation, browser instance management, page rendering, content extraction, and result storage.

### Worker Architecture
```
CrawlWorker
├── handle(CrawlerService $crawler) - Main execution
│   ├── Retrieve job from database
│   ├── Set status to 'running'
│   ├── Execute crawl pipeline
│   │   ├── Validate URL (SSRF check)
│   │   ├── Launch browser instance
│   │   ├── Render pages (depth 0, 1, 2)
│   │   ├── Store page results
│   │   └── Update statistics
│   ├── Handle success/failure
│   └── Cleanup resources
└── failed(Throwable $exception) - Failure handler
```

### TDD Approach
All services are mocked using Mockery:
- `CrawlerService` - Job creation, retrieval, cancellation
- `PlaywrightRendererService` - Browser, page rendering
- `UrlValidatorService` - SSRF protection
- `DepthController` - Link depth management
- `SizeLimiter` - Content size limits

### Job Class Structure
```php
<?php

namespace App\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;
use App\Models\CrawlJob;
use App\Models\CrawlPage;
use App\Services\CrawlerService;
use App\Services\PlaywrightRendererService;
use App\Services\UrlValidatorService;
use Illuminate\Support\Facades\Log;
use Throwable;

class CrawlWorker implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $timeout = 300;
    public int $tries = 1;
    public int $maxExceptions = 1;
    public array $backoff = [60];

    public function __construct(
        public string $jobId
    ) {}

    public function uniqueId(): string
    {
        return $this->jobId;
    }

    public function handle(
        CrawlerService $crawler,
        PlaywrightRendererService $renderer,
        UrlValidatorService $urlValidator
    ): void
    {
        // Set memory limit
        ini_set('memory_limit', '256M');
        
        // Retrieve job
        $job = $crawler->getJob($this->jobId);
        
        if (!$job || $job->status !== 'queued') {
            Log::warning('CrawlWorker: Job not available', ['jobId' => $this->jobId]);
            return;
        }
        
        // Set status to running
        $crawler->updateStatus($this->jobId, 'running');
        
        try {
            // Validate URL (SSRF check)
            $urlValidator->validate($job->url);
            
            // Launch browser
            $browser = $renderer->launchBrowser($job->options);
            
            // Render pages based on depth
            $this->renderPages($job, $browser, $renderer, $crawler);
            
            // Close browser
            $renderer->closeBrowser($browser);
            
            // Mark complete
            $crawler->updateStatus($this->jobId, 'completed');
            
        } catch (Throwable $e) {
            $this->handleFailure($crawler, $e);
        }
    }

    public function failed(Throwable $exception): void
    {
        Log::error('CrawlWorker: Job failed', [
            'jobId' => $this->jobId,
            'error' => $exception->getMessage(),
        ]);
        
        // Update job status
        CrawlJob::where('job_id', $this->jobId)->update([
            'status' => 'failed',
            'error' => substr($exception->getMessage(), 0, 65535),
            'completed_at' => now(),
        ]);
    }
    
    private function renderPages(/* ... */): void
    {
        // Implementation with depth handling, cancellation checks, etc.
    }
    
    private function handleFailure(CrawlerService $crawler, Throwable $e): void
    {
        // Cleanup and error handling
    }
}
```

### Key Implementation Details

1. **Memory Limit**: Set to 256MB at job start
2. **Garbage Collection**: Call `gc_collect_cycles()` between pages
3. **Cancellation Check**: Check `status = 'cancelled'` between each page
4. **Browser Instance**: Launch once, reuse for all pages, close in finally block
5. **Error Truncation**: Truncate error messages to fit TEXT column (64KB)
6. **Sensitive Data**: Redact credentials from URLs before logging
7. **Unique Job ID**: Use jobId as uniqueId() to prevent duplicate processing

### Exception Classes to Handle
- `PlaywrightException` - Browser/rendering errors
- `NetworkException` - DNS, connection, timeout errors
- `MemoryLimitExceededException` - Memory overflow
- `UrlValidationException` - SSRF, protocol errors
- `JobNotFoundException` - Job doesn't exist
- `JobCancellationException` - Job was cancelled
