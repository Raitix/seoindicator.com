### custom_id Parsing
```php
// Format: user_{userId}_package_{packageId}
// Example: user_42_package_starter
protected function parseCustomId(?string $customId): array
{
    if (preg_match('/user_(\d+)_package_(.+)/', $customId, $matches)) {
        return [
            'user_id' => (int) $matches[1],
            'package_id' => $matches[2],
        ];
    }
    return ['user_id' => null, 'package_id' => null];
}
```

### Signature String Computation
```php
// Expected format: {transmission_id}|{transmission_time}|{webhook_id}|{crc32_body}
protected function computeExpectedSignatureString(
    string $transmissionId,
    string $transmissionTime,
    string $webhookId,
    string $body
): string {
    $crc = crc32($body);
    return "{$transmissionId}|{$transmissionTime}|{$webhookId}|{$crc}";
}
```

### Timing-Safe Signature Comparison
```php
// CRITICAL: Always use hash_equals for signature comparison
protected function verifySignatureTimingSafe(string $known, string $user): bool
{
    return hash_equals($known, $user);
}
```

## Security Considerations

1. **Signature Verification (CRITICAL):**
   - All 4 required headers must be present
   - Certificate URL must be from PayPal domains only
   - Transmission time must be within tolerance (5 minutes)
   - Timing-safe comparison (hash_equals) prevents timing attacks

2. **Certificate URL Validation:**
   - Only `api.paypal.com` and `api.sandbox.paypal.com` accepted
   - HTTPS required (HTTP rejected)
   - Path must contain `/v1/notifications/certs/`

3. **Idempotency:**
   - Capture ID used as unique identifier
   - Database transaction ensures atomicity
   - Duplicate webhooks return 200 (acknowledged)

4. **Error Handling:**
   - Invalid signatures return 401 (not 500)
   - Malformed payloads return 400
   - Processing errors logged and return 500
   - Transaction rollback on error
