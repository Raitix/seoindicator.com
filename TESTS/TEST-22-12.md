## Overview
Test suite for crawler API request validation, custom validation rules, authorization policies, and rate limiting. Ensures secure and validated input handling for the Headless Crawler Service.

### Components Tested
| Component | File | Purpose |
|-----------|------|---------|
| ValidCrawlUrl Rule | `app/Rules/ValidCrawlUrl.php` | Custom SSRF protection rule |
| MaxContentSize Rule | `app/Rules/MaxContentSize.php` | Content size limit validation |
| CrawlJobPolicy | `app/Policies/CrawlJobPolicy.php` | Authorization for crawl jobs |
| CrawlRateLimiter | `app/Services/Crawler/CrawlRateLimiter.php` | Rate limiting service |

### TDD Approach
- Tests written before implementation
- Mocked dependencies where needed
- Integration tests use real validation
