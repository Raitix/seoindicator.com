The controller should use an API Resource for formatting:

```php
// app/Http/Resources/LocalSEOAlertResource.php
class LocalSEOAlertResource extends JsonResource
{
    public function toArray($request): array
    {
        return [
            'id' => $this->id,
            'type' => $this->alert_type,
            'severity' => $this->severity,
            'title' => $this->title,
            'message' => $this->message,
            'is_read' => $this->is_read,
            'read_at' => $this->read_at?->toISOString(),
            'created_at' => $this->created_at->toISOString(),
            'location' => [
                'id' => $this->location->id,
                'name' => $this->location->name,
            ],
        ];
    }
}
```

## Notes for Developer

### Service Mocking
The LocalSEOAlertServiceInterface should be mocked for controller tests:
- `getUnreadAlerts()` → Returns Collection of alerts
- `markAsRead()` → Returns bool
- `markAllAsRead()` → Returns int count

### Filter Validation
Valid values for filters:
- `severity`: 'info', 'warning', 'critical'
- `alert_type`: 'ranking_improved', 'ranking_dropped', 'new_review', 'negative_review', 'rating_dropped', 'competitor_overtake', 'gbp_disconnected'
- `is_read`: true, false, 1, 0
- `location_id`: positive integer

### Pagination
Default: 15 items per page
Max: 100 items per page

### Rate Limiting
Recommended: 60 requests per minute for read endpoints, 10 per minute for write endpoints
