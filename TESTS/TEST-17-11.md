## Notes for Developer

1. **Skip Link Location**: Each step component (Steps 1-4) should include skip link

2. **Confirmation Dialog**:
   - Use existing dialog component or create reusable confirm dialog
   - Must have proper ARIA attributes
   - Focus trap required

3. **API Endpoint**: `POST /api/v1/onboarding/skip`

4. **State Updates**:
   - `onboarding_status: 'skipped'`
   - `skipped_at: timestamp`
   - `current_step: null`

5. **Resume Flow**:
   - Banner shows on dashboard when `onboarding_status === 'skipped'`
   - Clicking "Complete setup" reopens modal at step 1
