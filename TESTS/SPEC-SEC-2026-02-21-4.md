# Test Documentation: SPEC-SEC-2026-02-21-4 — Validate OAuth Production Configuration

## Overview
Tests to verify OAuth production configuration is secure and properly configured.

## Test Type
- **Primary:** Integration Tests
- **Secondary:** Unit Tests

---

## Test Scenarios

### 1. OAuth Redirect URI Verification

**Test ID:** SEC-4.1  
**Type:** Integration  
**Priority:** Critical

**Description:** Verify OAuth redirect URIs match production domain.

**Preconditions:**
- OAuth provider configured (Google)
- Production domain known

**Test Steps:**
1. Check `config/services.php` for Google redirect URI
2. Verify URI uses HTTPS
3. Verify URI matches production domain
4. Compare with Google Cloud Console settings

**Expected Result:**
```php
'google' => [
    'redirect' => env('GOOGLE_REDIRECT_URI', 'https://seoindicator.com/auth/google/callback'),
]
```

---

### 2. OAuth Secrets in Environment

**Test ID:** SEC-4.2  
**Type:** Unit  
**Priority:** Critical

**Description:** Verify OAuth secrets are loaded from environment, not hardcoded.

**Preconditions:**
- `config/services.php` configured

**Test Steps:**
1. Parse config/services.php
2. Check for `env('GOOGLE_CLIENT_SECRET')`
3. Check for `env('GOOGLE_CLIENT_ID')`
4. Verify no hardcoded values

**Expected Result:**
```php
'google' => [
    'client_id' => env('GOOGLE_CLIENT_ID'),
    'client_secret' => env('GOOGLE_CLIENT_SECRET'),
    'redirect' => env('GOOGLE_REDIRECT_URI'),
]
```

---

### 3. OAuth Secrets Not in Repository

**Test ID:** SEC-4.3  
**Type:** Integration  
**Priority:** Critical

**Description:** Verify OAuth secrets are not in any tracked file.

**Preconditions:**
- Repository has commits

**Test Steps:**
1. Run `git grep -i "GOOGLE_CLIENT_SECRET=" -- '*.php' '*.env*'`
2. Run `git grep -i "GITHUB_CLIENT_SECRET=" -- '*.php' '*.env*'`
3. Check for secret patterns in git history

**Expected Result:**
- No hardcoded OAuth secrets found
- Secrets only in `.env` and GitHub Secrets

---

### 4. Token Encryption at Rest

**Test ID:** SEC-4.4  
**Type:** Unit  
**Priority:** Critical

**Description:** Verify OAuth tokens are encrypted when stored.

**Preconditions:**
- User model or SocialAccount model exists

**Test Steps:**
1. Check model for `$casts` array
2. Verify token field uses `encrypted` cast
3. Or verify mutator encrypts on set

**Expected Result:**
```php
protected $casts = [
    'token' => 'encrypted',
    'refresh_token' => 'encrypted',
];
```

---

### 5. Token Not Logged

**Test ID:** SEC-4.5  
**Type:** Integration  
**Priority:** High

**Description:** Verify OAuth tokens are not written to logs.

**Preconditions:**
- Logging configured
- OAuth flow has been used

**Test Steps:**
1. Perform OAuth login
2. Check `storage/logs/laravel.log`
3. Search for token patterns

**Expected Result:**
- No tokens appear in log files
- Sensitive data is redacted in logs

---

### 6. OAuth State Parameter Used

**Test ID:** SEC-4.6  
**Type:** Integration  
**Priority:** Critical

**Description:** Verify OAuth state parameter is used for CSRF protection.

**Preconditions:**
- OAuth controller exists

**Test Steps:**
1. Initiate OAuth flow
2. Capture redirect URL
3. Verify `state` parameter present
4. Verify state is validated on callback

**Expected Result:**
- State parameter included in OAuth redirect
- Callback validates state before processing

---

### 7. OAuth Scope Minimal

**Test ID:** SEC-4.7  
**Type:** Unit  
**Priority:** Medium

**Description:** Verify OAuth scopes are minimal required for functionality.

**Preconditions:**
- OAuth scopes defined

**Test Steps:**
1. Check requested scopes
2. Compare with required scopes
3. Document justification for each scope

**Expected Result:**
```php
'scopes' => ['openid', 'profile', 'email'], // Minimal scopes
```

---

### 8. Production vs Development Config

**Test ID:** SEC-4.8  
**Type:** Unit  
**Priority:** High

**Description:** Verify different OAuth apps for production and development.

**Preconditions:**
- Multiple environments configured

**Test Steps:**
1. Check if different OAuth credentials per environment
2. Verify production uses production OAuth app
3. Verify local development uses dev OAuth app

**Expected Result:**
- Production: `seoindicator.com` OAuth app
- Development: `localhost` OAuth app
