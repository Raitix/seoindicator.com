## Cache Key Generation Algorithm

```
generateHash(url, html):
1. Extract first 1000 chars of HTML
2. hash1 = SHA-256(html_first_1000_chars)
3. combined = url + ':' + hash1
4. return SHA-256(combined)
```

## Notes for Developer

### Expected Service Interface
```php
class AnalysisCacheService implements AnalysisCacheServiceInterface
{
    public function generateKey(string $url, string $html): string;
    public function generateHash(string $url, string $html): string;
    public function get(string $key): ?AnalysisResult;
    public function put(string $key, AnalysisResult $result, int $ttl = 86400): void;
    public function forget(string $key): bool;
    public function clear(): int;
}
```

### Cache Key Format
- Prefix: `ai_analysis:`
- Hash: 64-character SHA-256 hex string
- Full key example: `ai_analysis:a1b2c3d4e5f6...`

### TTL Handling
- Default: 24 hours (86400 seconds)
- Maximum: 7 days (604800 seconds)
- Negative TTL → uses default
- Excessive TTL → capped to maximum

### Key Generation Details
- URL + HTML hash combination
- HTML truncated to first 1000 chars for performance
- SHA-256 for cryptographic hashing
- Deterministic (same input = same output)
