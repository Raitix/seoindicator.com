## Notes for Developer

### Service Interfaces Required
```php
interface GBPInsightsServiceInterface {
    public function getInsights(int $locationId, string $startDate, string $endDate): array;
    public function getTrend(int $locationId): array;
    public function syncInsights(int $locationId): string; // Returns job ID
}

interface GBPReviewsServiceInterface {
    public function getReviews(int $locationId, array $filters): LengthAwarePaginator;
    public function getStats(int $locationId): array;
    public function syncReviews(int $locationId): string; // Returns job ID
    public function respondToReview(int $reviewId, string $response): array;
}
```

### API Resources
- `InsightsResource` - Transform insights data
- `InsightsTrendResource` - Transform trend data
- `ReviewResource` - Transform review data
- `ReviewStatsResource` - Transform stats data

### Rate Limiting
- Sync endpoints: 3 per hour (prevent API abuse)
- Respond endpoint: 10 per hour
- Read endpoints: 60 per minute

### Queue Jobs
- `SyncGBPInsightsJob` - Background sync
- `SyncGBPReviewsJob` - Background sync
- `PostReviewResponseJob` - Post to GBP API
