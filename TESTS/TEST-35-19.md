## Notes for Developer

1. **Data Fetching:** Use SWR or React Query for data fetching with automatic refetch on window focus
2. **Progressive Loading:** Load critical data first (location info), defer secondary sections
3. **Error Boundaries:** Each section should have its own error boundary to prevent cascade failures
4. **Sparklines:** Use a lightweight chart library (e.g., react-sparklines or Recharts tiny charts)
5. **Refresh:** Implement optimistic UI updates for refresh button
6. **Responsive:** Use Tailwind grid with responsive breakpoints (grid-cols-1 md:grid-cols-2 lg:grid-cols-3)
