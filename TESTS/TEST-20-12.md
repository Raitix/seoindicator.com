## Notes for Developer

1. **Content Population:** Update the `sections` and `checklist` arrays in registry.ts for `external-links` guide
2. **Read Time Calculation:** Based on word count, typically 200-250 words per minute (current: 4 min)
3. **Security Attributes:** MUST explain noopener, noreferrer, and when to use each
4. **Nofollow:** Cover sponsored, UGC, and when to use nofollow
5. **Target Blank:** Explain security risks and how noopener/noreferrer mitigate them
6. **Link Quality:** Emphasize linking to authoritative sources
7. **Broken Links:** Mention checking external links periodically
8. **Checklist Items:** 5-10 items with appropriate priority levels
9. **Related Guides:** Already includes `internal-links` and `https-security` ✅
10. **Content Quality:** Each section should be informative, actionable, and SEO-friendly

## Content Guidelines

### Section Content Requirements
- Each section should have 150-400 words
- Use markdown formatting (bold, lists, links)
- Include practical tips and examples
- Reference Google guidelines where applicable

### Checklist Item Requirements
- Clear, actionable text
- Appropriate priority level
- Covers key optimization areas
- Practical for users to implement

### Code Example Requirements
- Syntactically valid HTML
- Clear description of purpose
- Shows security attributes clearly
- Modern best practices (noopener + noreferrer together)
