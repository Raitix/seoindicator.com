## WCAG 2.1 AA Requirements

### Contrast Ratio Requirements

| Element Type | Minimum Ratio | WCAG Level |
|--------------|---------------|------------|
| Normal text (< 18pt or < 14pt bold) | 4.5:1 | AA |
| Large text (≥ 18pt or ≥ 14pt bold) | 3:1 | AA |
| Non-text elements (icons, UI components) | 3:1 | AA |

## Contrast Calculation Formula

### oklch to XYZ to RGB to Relative Luminance

```
L (lightness in oklch) → L' (perceived lightness)
Relative Luminance (Y) ≈ L'^2.4 (simplified approximation)

For WCAG contrast ratio:
CR = (L1 + 0.05) / (L2 + 0.05)
where L1 >= L2
```

### Accurate Calculation (used in tests):

1. Convert oklch L to relative luminance using CIE luminance function
2. Apply WCAG contrast ratio formula: `(L1 + 0.05) / (L2 + 0.05)`

## Test Implementation Notes

### Color Contrast Test Pattern

```typescript
// Parse oklch value from CSS variable
const oklch = parseOKLCH('--foreground: oklch(0.145 0 0)');

// Calculate relative luminance
const luminance = oklch.L; // Simplified - oklch L is perceptual lightness

// Calculate contrast ratio
function contrastRatio(L1: number, L2: number): number {
  const lighter = Math.max(L1, L2);
  const darker = Math.min(L1, L2);
  return (lighter + 0.05) / (darker + 0.05);
}

// Verify WCAG AA compliance
expect(contrastRatio(foreground.L, background.L)).toBeGreaterThanOrEqual(4.5);
```

### Screen Reader Test Pattern

```typescript
// Check for alt text on images
const images = document.querySelectorAll('img');
images.forEach(img => {
  expect(img).toHaveAttribute('alt');
});

// Check for ARIA labels on buttons
const buttons = document.querySelectorAll('button');
buttons.forEach(button => {
  const hasLabel = button.hasAttribute('aria-label') || 
                   button.hasAttribute('aria-labelledby') ||
                   button.textContent?.trim().length > 0;
  expect(hasLabel).toBe(true);
});
```

### Focus Visibility Test Pattern

```typescript
// Check for focus styles
const focusStyles = cssContent.match(/:focus/g);
expect(focusStyles).not.toBeNull();

// Check for focus-visible support
const focusVisibleStyles = cssContent.match(/:focus-visible/g);
expect(focusVisibleStyles).not.toBeNull();
```
