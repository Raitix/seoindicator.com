## WCAG 2.1 AA Contrast Requirements

### Text Contrast
| Text Type | Minimum Ratio | Notes |
|-----------|---------------|-------|
| Normal text (< 18px or < 14px bold) | 4.5:1 | Most text content |
| Large text (>= 18px or >= 14px bold) | 3:1 | Headings, large labels |

### Non-Text Contrast
| Element Type | Minimum Ratio | Notes |
|--------------|---------------|-------|
| UI Components | 3:1 | Buttons, inputs, icons |
| Graphical Objects | 3:1 | Icons, charts, diagrams |

## Contrast Calculation Algorithm

### Relative Luminance Calculation
```
For each color channel (R, G, B):
  if channel <= 0.03928:
    channel = channel / 12.92
  else:
    channel = ((channel + 0.055) / 1.055) ^ 2.4

L = 0.2126 * R + 0.7152 * G + 0.0722 * B
```

### Contrast Ratio Calculation
```
L1 = lighter luminance
L2 = darker luminance
Ratio = (L1 + 0.05) / (L2 + 0.05)
```

### oklch to sRGB Conversion
```
1. Convert oklch to OKLab
2. Convert OKLab to linear sRGB
3. Convert linear sRGB to sRGB
```
