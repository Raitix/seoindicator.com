## Test Cases

### GET /api/v1/rankings/comparison - Comparison Dashboard

#### Test 1: Get comparison data - success
- **Type:** Feature
- **Steps:**
  1. Create user with keywords and competitor rankings
  2. GET /api/v1/rankings/comparison
  3. Assert 200 OK with summary and results
- **Expected:**
  ```json
  {
    "summary": {
      "totalKeywords": 10,
      "imWinning": 4,
      "theyreWinning": 3,
      "bothRank": 5,
      "onlyIRank": 2,
      "onlyTheyRank": 3
    },
    "results": [...]
  }
  ```

#### Test 2: Filter - all keywords
- **Type:** Feature
- **Steps:**
  1. GET with filter=all
  2. Assert all keywords returned
- **Expected:** Complete list of keywords

#### Test 3: Filter - I'm winning
- **Type:** Feature
- **Steps:**
  1. GET with filter=im-winning
  2. Assert only keywords where user ranks higher
- **Expected:** Only keywords where user position < competitor position

#### Test 4: Filter - They're winning
- **Type:** Feature
- **Steps:**
  1. GET with filter=theyre-winning
  2. Assert only keywords where competitor ranks higher
- **Expected:** Only keywords where competitor position < user position

#### Test 5: Filter - Keyword gaps
- **Type:** Feature
- **Steps:**
  1. GET with filter=gap
  2. Assert only keywords where competitor ranks but user doesn't
- **Expected:** Only keywords where user position is null, competitor has position

#### Test 6: Filter - Both rank
- **Type:** Feature
- **Steps:**
  1. GET with filter=both-rank
  2. Assert only keywords where both have positions
- **Expected:** Both user and competitor have non-null positions

#### Test 7: Summary calculation - correct counts
- **Type:** Unit
- **Steps:**
  1. Create 5 keywords with various ranking scenarios
  2. Call ComparisonService::getSummary()
  3. Verify each count is accurate
- **Expected:**
  - totalKeywords: 5
  - imWinning: count where user ahead
  - theyreWinning: count where competitor ahead
  - bothRank: count where both have positions
  - onlyIRank: count where only user ranks
  - onlyTheyRank: count where only competitor ranks

#### Test 8: Position diff calculation
- **Type:** Unit
- **Steps:**
  1. User position: 5, Competitor position: 10
  2. Calculate diff = user - competitor
  3. Assert diff = -5 (negative = user ahead)
- **Expected:** Diff calculation correct with sign

#### Test 9: Position diff - user behind
- **Type:** Unit
- **Steps:**
  1. User position: 15, Competitor position: 8
  2. Calculate diff
  3. Assert diff = 7 (positive = competitor ahead)
- **Expected:** Positive diff when competitor ahead

#### Test 10: Position diff - null handling
- **Type:** Unit
- **Steps:**
  1. User position: null, Competitor position: 5
  2. Calculate diff
  3. Assert diff = null or special indicator
- **Expected:** Null handled gracefully

#### Test 11: Status determination
- **Type:** Unit
- **Steps:**
  1. Test various scenarios:
     - User 5, Comp 10 → "im-winning"
     - User 15, Comp 8 → "theyre-winning"
     - User null, Comp 5 → "gap"
     - User 5, Comp null → "only-i-rank"
     - User 5, Comp 5 → "both-rank" (tie)
- **Expected:** Correct status for each scenario

#### Test 12: Pagination - page 1
- **Type:** Feature
- **Steps:**
  1. Create 50 keywords with rankings
  2. GET with page=1, perPage=20
  3. Assert 20 results returned
- **Expected:** First 20 results with pagination metadata

#### Test 13: Pagination - metadata
- **Type:** Feature
- **Steps:**
  1. Create 55 keywords
  2. GET with page=1, perPage=20
  3. Assert metadata: total=55, totalPages=3
- **Expected:** Correct pagination metadata

#### Test 14: Multiple competitors - combined view
- **Type:** Feature
- **Steps:**
  1. User has 2 competitors
  2. GET comparison data
  3. Assert results include positions for both competitors
- **Expected:**
  ```json
  {
    "keyword": "seo tools",
    "myPosition": 5,
    "competitors": [
      {"domain": "c1.com", "position": 8, "diff": -3},
      {"domain": "c2.com", "position": 3, "diff": 2}
    ]
  }
  ```

#### Test 15: No competitors configured
- **Type:** Feature
- **Steps:**
  1. User with keywords but no competitors
  2. GET comparison data
  3. Assert only user rankings returned
- **Expected:** Results without competitor data
