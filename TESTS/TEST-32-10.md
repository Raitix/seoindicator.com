# TEST-32-10: ComparisonSchema Component Tests

## Task Reference
- **Task:** TASK-32-10
- **Specification:** SPEC-32 (Competitor Comparison Landing Pages)
- **Feature:** FEAT-032

## Overview
Test suite for the ComparisonSchema component that generates JSON-LD structured data (BreadcrumbList, FAQPage, HowTo) for comparison landing pages. Validates schema structure, JSON-LD rendering, XSS prevention, and Google Rich Results compliance.
