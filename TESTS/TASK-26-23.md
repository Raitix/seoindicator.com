## Overview
Comprehensive test suite for the frontend Stripe payment flow. Tests cover all payment flow steps, Stripe Elements integration, error handling, security requirements, and balance updates. Uses mocked API responses for TDD approach since backend endpoints (TASK-26-9, TASK-26-10) are not yet implemented.

### Stripe Mocking Strategy
```typescript
// Mock Stripe.js
jest.mock('@stripe/stripe-js', () => ({
  loadStripe: jest.fn(() => Promise.resolve({
    elements: jest.fn(),
    confirmPayment: jest.fn(),
    createPaymentMethod: jest.fn()
  }))
}));

// Mock Stripe Elements
jest.mock('@stripe/react-stripe-js', () => ({
  Elements: ({ children }) => children,
  PaymentElement: () => <div data-testid="payment-element" />,
  useStripe: () => mockStripe,
  useElements: () => mockElements
}));
```

### Key Testing Patterns
1. **Mock payment intent API** before mounting StripeCheckout
2. **Wait for Stripe load** before interacting with elements
3. **Use `findBy*` queries** for async Stripe rendering
4. **Test error boundaries** for Stripe load failures
5. **Verify focus management** for accessibility

### Security Checklist for Tests
- [ ] No card numbers in console logs
- [ ] No CVC in any logged data
- [ ] Payment data not in component state snapshots
- [ ] Error messages don't leak sensitive info
- [ ] Mock Stripe never receives real card data
