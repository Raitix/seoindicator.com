## Notes for Developer

### Files to Create
1. `frontend/lib/ab-tests.ts` - Configuration and helpers
2. `frontend/hooks/useABTest.ts` - React hook
3. Update `ComparisonCTA.tsx` - Integrate hook

### Key Implementation Points

1. **Deterministic Assignment:**
   - Use localStorage for persistence
   - Check existing variant before assigning new
   - Random assignment only on first visit

2. **Traffic Allocation:**
   - Use Math.random() for traffic inclusion
   - Users not in test always get control ('a')
   - Traffic allocation checked before variant assignment

3. **Variant Assignment:**
   - Cumulative weight comparison
   - Math.random() * 100 for even distribution
   - Weight sum must equal 100

4. **Analytics Tracking:**
   - Track exposure once per test per session
   - Track conversion on CTA click
   - Include all required properties

5. **Error Handling:**
   - Graceful fallback to control
   - No errors thrown to user
   - Analytics errors don't break functionality
