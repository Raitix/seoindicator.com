# TEST-33-30: BadgeService Unit Tests

## Task Reference

## Overview
Comprehensive unit test suite for the BadgeService, covering SVG badge generation with multiple sizes, themes, and score color coding. Uses TDD approach with PHPUnit and validates SVG structure, accessibility, caching, and security.

## Dependencies

## Notes for Developer
1. BadgeService should implement `generate()` method with signature:
   - `generate(int $score, string $size, ?string $theme = null, ?array $categoryScores = null, bool $forceFresh = false): string`
2. Size validation: only 'small', 'medium', 'large' allowed
3. Theme validation: only 'light', 'dark' allowed
4. Score validation: 0-100 inclusive
5. Use Laravel Cache with 1-hour TTL
6. All SVGs must include accessibility attributes
7. No external resources or scripts in SVG output
