## Expected Service Interface

```php
interface AnalysisPdfGeneratorInterface
{
    /**
     * Generate PDF from analysis result.
     *
     * @param array $analysisData
     * @param array $options
     *   - branding: array (colors, logo, fonts)
     *   - includeDetails: bool
     *   - locale: string
     * @return string PDF binary content
     */
    public function generate(array $analysisData, array $options = []): string;

    /**
     * Stream PDF to response.
     *
     * @param array $analysisData
     * @param array $options
     * @return StreamedResponse
     */
    public function stream(array $analysisData, array $options = []): StreamedResponse;

    /**
     * Get suggested filename.
     *
     * @param string $domain
     * @return string
     */
    public function getFilename(string $domain): string;
}
```
