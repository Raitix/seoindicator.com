## API Specification

### Endpoint
```
POST /api/v1/badge/click
```

### Request Body
```json
{
  "hash": "abc123def456...",      // Required: 32-char alphanumeric public hash
  "click_target": "audit"         // Required: 'audit' or 'home'
}
```

### Response Codes
| Code | Condition |
|------|-----------|
| 204 No Content | Success - click recorded |
| 404 Not Found | Invalid hash or non-public audit |
| 422 Unprocessable Entity | Validation error |
| 429 Too Many Requests | Rate limit exceeded (10 req/min per IP) |

### Rate Limiting
- **Limit:** 10 requests per minute per IP
- **Key:** IP address
- **Headers:** `X-RateLimit-Limit`, `X-RateLimit-Remaining`

## Notes for Developer

### Implementation Requirements

1. **Controller Structure:**
```php
class BadgeClickController extends Controller
{
    public function store(BadgeClickRequest $request): JsonResponse|Response
    {
        // Find audit by hash
        // Validate is_public
        // Hash IP address
        // Find existing impression (IP hash + hash within 24h)
        // If found: update clicked_at and click_target
        // If not found: create new impression with clicked_at set
        // Return 204 No Content
    }
}
```

2. **Request Validation:**
```php
class BadgeClickRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'hash' => ['required', 'string', 'regex:/^[a-zA-Z0-9]{32}$/'],
            'click_target' => ['required', 'string', 'in:audit,home'],
        ];
    }
}
```

3. **Route Registration:**
```php
Route::post('/badge/click', [BadgeClickController::class, 'store'])
    ->middleware('throttle:10,1')
    ->name('api.v1.badge.click');
```

4. **Impression Correlation:**
```php
$ipHash = BadgeImpression::hashIp($request->ip());

$impression = BadgeImpression::where('public_hash', $hash)
    ->where('ip_hash', $ipHash)
    ->where('impression_at', '>=', now()->subDay())
    ->latest('impression_at')
    ->first();

if ($impression) {
    $impression->update([
        'clicked_at' => now(),
        'click_target' => $clickTarget,
    ]);
} else {
    BadgeImpression::create([
        'audit_id' => $audit->id,
        'public_hash' => $hash,
        'ip_hash' => $ipHash,
        'impression_at' => now(),
        'clicked_at' => now(),
        'click_target' => $clickTarget,
    ]);
}
```

5. **Optional Redirect:**
```php
// If ?redirect=1 query param, return redirect instead of 204
if ($request->query('redirect')) {
    $url = $clickTarget === 'audit' 
        ? url("/audit/{$hash}/") 
        : 'https://seoindicator.com/';
    return redirect($url);
}
```

### Security Considerations

- Never log IP addresses in plain text
- Never expose audit details in error responses
- Return same 404 for non-existent and non-public audits (prevents enumeration)
- Rate limit per IP to prevent abuse
- Click target must be exactly 'audit' or 'home' (no other values)

### CTR Calculation

Click-through rate can be calculated from the badge_impressions table:
```php
$impressions = BadgeImpression::where('public_hash', $hash)->count();
$clicks = BadgeImpression::where('public_hash', $hash)->clicked()->count();
$ctr = $impressions > 0 ? ($clicks / $impressions) * 100 : 0;
```
