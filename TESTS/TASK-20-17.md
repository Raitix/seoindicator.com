## Notes for Developer

### Content Requirements

When implementing the guide content, ensure:

1. **What are Canonical URLs?**
   - Define canonical URLs clearly
   - Explain rel="canonical" attribute
   - Describe preferred version concept

2. **Why Canonicals Matter**
   - Explain duplicate content issues
   - Describe SEO impact
   - Mention crawl budget implications

3. **When to Use Canonical Tags**
   - URL parameters (filters, sorting)
   - www vs non-www versions
   - http vs https versions
   - Trailing slash variations
   - Cross-domain syndication
   - Mobile/Desktop variations

4. **Implementation Methods**
   - HTML `<link>` tag in `<head>`
   - HTTP `Link` header
   - XML sitemap canonical hints

5. **Common Mistakes**
   - Canonical chains (A→B→C)
   - Circular canonical loops
   - Self-referencing issues (when to use, when not)
   - Cross-domain canonical misconfigurations
   - Conflicting signals (redirects vs canonicals)

6. **Pagination Canonicals**
   - How to handle paginated content
   - rel="prev"/"next" relationship
   - View-all pages

7. **Code Examples**
   - Standard canonical tag in HTML
   - HTTP header example
   - Cross-domain canonical example
   - Pagination example

8. **Best Practices Checklist**
   - Include 5-10 actionable items
   - At least one critical priority
   - Mix of priorities (critical, important, recommended)

9. **Google Guidelines Reference**
   - Link to official Google documentation
   - Reference Google's canonicalization guidelines

### Related Guides

The guide must reference:
- `https-security` - Protocol-related canonicalization
- `xml-sitemap` - Sitemap canonical hints
