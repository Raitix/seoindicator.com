## TDD Pattern

Tests are written following TDD approach:
- Tests expect the `PerformanceChecker` class to exist
- Tests will fail until implementation is complete
- All threshold values are clearly defined in tests
- Mock `CrawlResult` objects are used for isolation

## Expected Behavior

### Response Time Checking
1. Fast response (< 1000ms) → no issue
2. Acceptable (1000-2000ms) → notice
3. Needs improvement (2000-3000ms) → warning
4. Slow page (> 3000ms) → warning
5. Very slow page (> 5000ms) → critical

### Page Size Checking
1. Small page (≤ 500KB) → no issue
2. Large page (> 500KB) → notice

### Priority
When both issues exist (slow + large), return the higher severity issue (slow_page takes priority).
