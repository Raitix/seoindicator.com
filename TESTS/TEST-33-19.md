# TEST-33-19 - Badge Auto-Refresh Mechanism Tests

## Task Reference
- **Task:** TASK-33-19
- **Feature:** FEAT-033 - Public SEO Audit Reports & Embeddable Score Widget
- **Component:** `frontend/lib/scripts/badge.ts`
- **Test File:** `frontend/__tests__/scripts/badge-autorefresh.test.ts`

## Overview

Comprehensive unit tests for the badge auto-refresh mechanism that ensures embedded SEO score badges stay up-to-date without requiring page reloads. Tests cover interval configuration, timer management, error handling, and integration scenarios.

## Test Scenarios

### AR-CONFIG: Refresh Interval Configuration (5 tests)

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AR-CONFIG-01 | Default refresh interval is 24 hours | N/A | `DEFAULT_REFRESH_INTERVAL = 86400000` |
| AR-CONFIG-02 | Custom refresh interval via config | `refreshInterval: 3600000` | Timer set with custom interval |
| AR-CONFIG-03 | refreshInterval=0 disables auto-refresh | `refreshInterval: 0` | Timer is `null` |
| AR-CONFIG-04 | Negative refreshInterval disables auto-refresh | `refreshInterval: -1000` | Timer is `null` |
| AR-CONFIG-05 | Existing timer is cleared when setting new one | Set timer twice | First timer cleared, second active |

### AR-TIMER: Timer Setup and Cleanup (5 tests)

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AR-TIMER-01 | Timer is set after successful badge load | Valid config | Timer is not null |
| AR-TIMER-02 | Timer fires callback after interval | Wait interval time | Callback called once |

| AR-TIMER-04 | Timer not set when instance is destroyed | `destroyed: true` | Timer is `null` |
| AR-TIMER-05 | Multiple timers can coexist for different badges | Create multiple badges | All timers fire independently |

### AR-MANUAL: Manual Refresh Interaction (4 tests)

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| AR-MANUAL-01 | Manual refresh triggers immediate load | Call `refresh(auditId)` | `loadBadge` called immediately |
| AR-MANUAL-02 | Manual refresh resets auto-refresh timer | Call `refresh()` mid-interval | Timer restarts from 0 |
| AR-MANUAL-03 | Refresh all badges calls loadBadge for each | Call `refresh()` without ID | All badges refreshed |
| AR-MANUAL-04 | Refresh specific badge only loads that badge | Call `refresh('abc123')` | Only specified badge refreshed |
