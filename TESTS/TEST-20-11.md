## Notes for Developer

1. **Content Population:** Update the `sections` and `checklist` arrays in registry.ts for `internal-links` guide
2. **Read Time Calculation:** Based on word count, typically 200-250 words per minute (current: 5 min)
3. **Code Examples:** Must include HTML link examples, breadcrumbs, optionally JSON-LD schema
4. **Hub-and-Spoke Model:** Cover content organization strategy with code visualization
5. **Anchor Text:** Emphasize descriptive text vs "click here" generic text
6. **Orphan Pages:** Explain what they are and how to fix them
7. **Link Equity:** Explain how authority flows through internal links
8. **Checklist Items:** 5-10 items with appropriate priority levels
9. **Related Guides:** Already includes `external-links` and `xml-sitemap` ✅
10. **Content Quality:** Each section should be informative, actionable, and SEO-friendly

## Content Guidelines

### Section Content Requirements
- Each section should have 150-400 words
- Use markdown formatting (bold, lists, links)
- Include practical tips and examples
- Reference free tools for link auditing (Google Search Console)

### Checklist Item Requirements
- Clear, actionable text
- Appropriate priority level
- Covers key optimization areas
- Practical for users to implement

### Code Example Requirements
- Syntactically valid code
- Clear description of purpose
- Appropriate language tag
- Modern best practices
