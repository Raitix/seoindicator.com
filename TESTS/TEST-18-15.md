## Test Scenarios

### Filename Format Tests

| ID | Scenario | Input | Expected Output |
|----|----------|-------|-----------------|
| FF-01 | SEO-friendly filename | `seo-services-london.jpg` | isSeoFriendly: true |
| FF-02 | Underscore separator | `seo_services_london.jpg` | isSeoFriendly: true |
| FF-03 | Spaces in filename | `seo services.jpg` | isSeoFriendly: false |
| FF-04 | Special characters | `image@2x.jpg` | isSeoFriendly: false |
| FF-05 | Uppercase letters | `SEO-Services.jpg` | isSeoFriendly: true (warn about case) |
| FF-06 | Numbers only | `12345.jpg` | isSeoFriendly: false |
| FF-07 | Random hash | `img_abc123def.jpg` | isSeoFriendly: false |

```php
new IndicatorResult(
    id: 'filenames',

    category: 'content',

        'totalFiles' => 5,

            'type' => 'warning',
            'message' => '1 file has non-SEO-friendly filename.',

        ]
    ]
);
```
