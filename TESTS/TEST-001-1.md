## Test Scenarios

### Migration Creation Tests
| ID | Scenario | Expected Result |
|----|----------|-----------------|
| MIG-001 | Run migration on fresh database | Tables created: keywords, ranking_history |
| MIG-002 | Migration creates sites table if not exists | sites table created |
| MIG-003 | Keywords table has all required columns | id, user_id, site_id, keyword, target_url, search_engine, location, device, status, last_checked_at, created_at, updated_at |
| MIG-004 | Ranking_history table has all required columns | id, keyword_id, position, url_found, serp_features, checked_at, check_duration_ms, error |
| MIG-005 | Foreign key constraints created | keywords.site_id → sites.id, ranking_history.keyword_id → keywords.id |
| MIG-006 | Unique constraint on keywords | (site_id, keyword, search_engine, location, device) unique |
| MIG-007 | Indexes created | idx_keywords_site_id, idx_keywords_status, idx_keywords_last_checked, idx_ranking_keyword_id, idx_ranking_checked_at, idx_ranking_keyword_date |

### Migration Rollback Tests
