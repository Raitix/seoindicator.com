## Fix Specifications

### 1. APP_KEY Rotation and Secret Management

**Current State:**
- APP_KEY hardcoded in `.github/workflows/deploy.yml`
- APP_KEY hardcoded in `backend/.env` 
- Database password hardcoded in `backend/.env`

**Required Changes:**

#### 1.1 Remove APP_KEY from deploy.yml
**File:** `.github/workflows/deploy.yml`
**Change:** Replace hardcoded APP_KEY with GitHub Secret reference
```yaml
# BEFORE (line 107):
APP_KEY=${{ secrets.LARAVEL_APP_KEY }}=

# AFTER:
APP_KEY=${{ secrets.LARAVEL_APP_KEY }}
```

#### 1.2 Remove secrets from .env file
**File:** `backend/.env`
**Change:** Move all secrets to `.env.example` format
```env
# BEFORE:
APP_KEY=base64:ghG9hjT3BRc4vHPft4mo3oBXl7DJsqzVTn2fdUJSKUg=
DB_PASSWORD=c3eXRee12ijp7

# AFTER:
APP_KEY=
DB_PASSWORD=
```

#### 1.3 Update .env.example
**File:** `backend/.env.example`
**Change:** Ensure all secret placeholders exist
```env
APP_KEY=
DB_PASSWORD=
DEPLOY_KEY=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```

#### 1.4 Create GitHub Secrets
**Required Secrets:**
- `LARAVEL_APP_KEY` - Generated via `php artisan key:generate --show`
- `DB_PASSWORD` - Production database password
- `DEPLOY_KEY` - Random string for deployment authentication
- `GOOGLE_CLIENT_ID` - Google OAuth client ID
- `GOOGLE_CLIENT_SECRET` - Google OAuth client secret

#### 1.5 Rotate APP_KEY in Production
**Steps:**
1. Generate new APP_KEY: `php artisan key:generate --show`
2. Update GitHub Secret `LARAVEL_APP_KEY` with new value
3. Deploy to apply new APP_KEY
4. **WARNING:** Existing encrypted data (sessions, cookies) will become invalid

### 3. Deployment Endpoints Rate Limiting

**Current State:** DeployController has authentication but no rate limiting

**Required Changes:**

#### 3.1 Implement Laravel Rate Limiting
**File:** `backend/app/Http/Controllers/DeployController.php`
**Change:** Add rate limiting middleware
```php
// Add to controller class
public function __construct()
{
    $this->middleware('throttle:5,15')->only(['migrate', 'rollback']);
}
```

#### 3.2 Configure Custom Rate Limit (Optional)
**File:** `backend/app/Http/Kernel.php`
**Change:** Add custom rate limiter for deploy endpoints
```php
// In boot() method or RouteServiceProvider
RateLimiter::for('deploy', function (Request $request) {
    return Limit::perMinutes(15, 5)->by($request->ip());
});
```

#### 3.3 Add Logging
**Change:** Log failed deployment attempts
```php
// In migrate() and rollback() methods, after failed authentication
Log::warning('Failed deploy attempt', [
    'ip' => $request->ip(),
    'user_agent' => $request->userAgent(),
    'timestamp' => now(),
]);
```
