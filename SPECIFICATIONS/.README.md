# SPECIFICATIONS Template

This folder contains technical specifications.

## Naming Convention
`SPEC-X.md` where X matches the related FEAT-X number.

## Specification File Structure

```markdown
# SPEC-X: [Feature Name] — Technical Specification

## STATUS
`Specification In Progress` | `To Break Into Tasks` | `Breaking Into Tasks` | `Cancelled`

## Overview
_Technical overview of the implementation_

## Requirements
- Functional requirements
- Non-functional requirements

## Technical Design
- Architecture
- Components
- Data flow
- API design

## Implementation Notes
_Key implementation details_

## Dependencies
_External services, libraries, or other features_

## Risks & Mitigations
_Potential issues and how to address them_

## Tasks
- [ ] SPEC-X-1: Task name
- [ ] SPEC-X-2: Task name

## Related
- Feature: FEAT-X
- Tests: TESTS/SPEC-X-*.md
```

---

## Valid Status Values

| Status | Meaning |
|--------|---------|
| `Specification In Progress` | Architect is writing specification |
| `To Break Into Tasks` | Ready for SpecSystemAnalyst to break down |
| `Breaking Into Tasks` | SpecSystemAnalyst is creating tasks |
| `Cancelled` | Specification not viable |
