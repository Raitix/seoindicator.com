## Description
Implement the frontend Stripe payment flow using Stripe.js and Stripe Elements for secure card handling.

## Acceptance Criteria

### Payment Flow Steps
1. **Package Selection**: User selects credit package
2. **Payment Method**: User enters card details via Stripe Elements
3. **Processing**: Show loading state while payment processes
4. **Confirmation**: Show success/failure message
5. **Balance Update**: Refresh credit balance
