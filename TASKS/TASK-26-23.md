## Description
Implement the frontend Stripe payment flow using Stripe.js and Stripe Elements for secure card handling.

## Acceptance Criteria

### Payment Flow Steps
1. **Package Selection**: User selects credit package
2. **Payment Method**: User enters card details via Stripe Elements
3. **Processing**: Show loading state while payment processes
4. **Confirmation**: Show success/failure message
5. **Balance Update**: Refresh credit balance

- [ ] `components/payments/StripeCheckout.tsx`
- [ ] `components/payments/PaymentSuccess.tsx`

### Stripe Elements Integration
- [ ] Load Stripe.js with publishable key
- [ ] Create Payment Element
- [ ] Handle card input validation
- [ ] Show card errors inline
- [ ] Support saved cards (future)

### API Integration
- [ ] Create payment intent: `POST /api/v1/payments/stripe/intent`
- [ ] Submit payment via Stripe.js
- [ ] Handle redirect if required (3D Secure)

### Error Handling

- [ ] Network errors
- [ ] Timeout errors
- [ ] Generic errors with support contact

### User Experience

- [ ] Progress indicator
- [ ] Clear error messages

- [ ] Email receipt option

### Security (Frontend)

- [ ] Use Stripe Elements (PCI compliance)
- [ ] HTTPS only
- [ ] CSRF protection via Laravel Sanctum
