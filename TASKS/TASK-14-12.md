### Features

#### 1. Image Extraction and Validation
```php
class ImageAltChecker implements CheckerInterface
{
    public function check(CrawlResult $result): ?IssueFinding
    {
        $images = $this->extractImages($result->html);
        $missingAlt = $this->findMissingAlt($images);
        
        if (count($missingAlt) > 0) {
            return $this->createFinding(
                issueType: 'missing_image_alt',
                severity: 'notice',
                description: "Found {$count} images missing alt text",
                recommendation: 'Add descriptive alt text to all images for better accessibility and SEO.',
                context: ['images' => $missingAlt]
            );
        }
        
        return null;
    }
    
    protected function extractImages(string $html): array;
    protected function findMissingAlt(array $images): array;
}
```

#### 2. Image Extraction
```php
protected function extractImages(string $html): array
{
    $crawler = new Crawler($html);
    $images = [];
    
    $crawler->filter('img')->each(function (Crawler $node) use (&$images) {
        $images[] = [
            'src' => $node->attr('src'),
            'alt' => $node->attr('alt'),
            'has_alt' => $node->attr('alt') !== null,
            'alt_empty' => $node->attr('alt') === '',
        ];
    });
    
    return $images;
}
```

#### 3. Alt Text Rules
| Condition | Severity | Issue |
|-----------|----------|-------|
| Missing alt attribute | Notice | Missing alt text |
| Empty alt="" | Notice | Empty alt text |
| Alt text present | — | OK |

**Special Cases:**
- Decorative images can have empty alt (alt="")
- This is acceptable but flagged as "review needed"
- Alt text > 125 chars → Notice (too long)

#### 4. Additional Image Checks
```php
// Optional: Check for missing src
protected function checkMissingSrc(array $images): ?IssueFinding
{
    $missing = array_filter($images, fn($img) => empty($img['src']));
    
    if (count($missing) > 0) {
        return $this->createFinding(
            issueType: 'image_missing_src',
            severity: 'warning',
            description: "Found {$count} images with missing src attribute"
        );
    }
    
    return null;
}
```
