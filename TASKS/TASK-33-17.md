# TASK-33-17: Create Badge Impression Tracking API

## STATUS
`To Prioritize`

## PRIORITY
`Medium`

## RISK
`Low`

## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the API endpoint that tracks badge impressions when embedded badges are viewed on third-party sites.

## Acceptance Criteria
- [ ] POST `/api/v1/badge/impression` endpoint
- [ ] Accepts: audit_id (or hash), referrer_domain
- [ ] Validates hash exists and audit is public
- [ ] Stores impression in badge_impressions table
- [ ] IP address hashed for privacy
- [ ] No authentication required
- [ ] Rate limited: 10 requests/minute per IP
- [ ] Returns 204 No Content on success
- [ ] Returns 404 for invalid hash
- [ ] Feature tests for all scenarios

## Dependencies
- TASK-33-3 (badge_impressions table)

## Effort Estimate
**2 hours** - Simple API endpoint

## Technical Notes
- Extract referrer_domain from Referer header
- Use app('hash')->make() for IP hashing
- Use throttle middleware for rate limiting
- Consider using Redis for high-volume writes

## Request Body
```json
{
  "hash": "abc123...",
  "referrer_domain": "example.com"
}
```
