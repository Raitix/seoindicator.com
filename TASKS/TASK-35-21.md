# TASK-35-21: Reviews Management Page

## STATUS
`To Write Tests`

## SPECIFICATION
SPEC-035: Local SEO & Google Business Profile Tracking

## PRIORITY
`High`

## RISK
`Low`

## Description
Create reviews management page for viewing, filtering, and responding to Google reviews.

## Acceptance Criteria
- [ ] Reviews page at /locations/{id}/reviews
- [ ] Review stats header:
  - Average rating with star display
  - Total review count
  - Rating distribution bar chart (1-5 stars)
  - Sentiment breakdown (positive/negative/neutral)
- [ ] Filters:
  - Rating filter (1-5 stars, multi-select)
  - Sentiment filter
  - Has response / No response
  - Date range
- [ ] Reviews list:
  - Paginated (20 per page)
  - Each review shows: author, avatar, rating, date, text, sentiment
  - Owner response if present
  - Action buttons: respond, view on Google
- [ ] Review response modal:
  - Text area for response (max 4096 chars)
  - Character counter
  - Preview of original review
  - Submit/Cancel buttons
  - Loading state during submission
- [ ] Sentiment badge:
  - Color-coded: green (positive), yellow (neutral), red (negative)
  - Icon indicator
- [ ] Sort options:
  - Newest first (default)
  - Oldest first
  - Highest rating
  - Lowest rating
- [ ] Bulk actions (optional):
  - Select multiple reviews
  - Export selected
- [ ] Loading states
- [ ] Component tests
