## Description

## Acceptance Criteria

- [ ] `AIVisibilityAlertController` created at `app/Http/Controllers/Api/V1/AIVisibility/`

- [ ] `GET /api/v1/ai-visibility/alerts` endpoint
  - [ ] Returns paginated list of user's alerts
  - [ ] Query parameters:
    - `project_id`: filter by project (optional)
    - `is_read`: filter by read status (optional)
    - `alert_type`: filter by type (optional)
  - [ ] Response structure:
    ```json
    {
      "data": [
        {
          "id": 1,
          "project_id": 1,
          "project_name": "SEOIndicator",
          "alert_type": "mention_spike",
          "threshold": 20.00,
          "previous_value": 15.00,
          "current_value": 25.00,
          "change_percent": 66.67,
          "is_read": false,
          "is_resolved": false,
          "triggered_at": "2026-03-07T10:00:00Z"
        }
      ],
      "meta": { "unread_count": 5, "total": 20 }
    }
    ```
  - [ ] Sorted by `triggered_at` desc
  - [ ] Authorization: only user's own alerts

- [ ] `GET /api/v1/ai-visibility/alerts/{id}` endpoint
  - [ ] Returns single alert details
  - [ ] Includes related project information
  - [ ] Authorization: user must own alert

- [ ] `POST /api/v1/ai-visibility/alerts/{id}/read` endpoint
  - [ ] Marks alert as read (`is_read = true`)
  - [ ] Returns updated alert
  - [ ] Authorization: user must own alert

- [ ] `POST /api/v1/ai-visibility/alerts/{id}/resolve` endpoint
  - [ ] Marks alert as resolved (`is_resolved = true`)
  - [ ] Sets `resolved_at` timestamp
  - [ ] Returns updated alert
  - [ ] Authorization: user must own alert

- [ ] `POST /api/v1/ai-visibility/alerts/mark-all-read` endpoint
  - [ ] Marks all user's unread alerts as read
  - [ ] Optional `project_id` parameter to scope
  - [ ] Returns count of updated alerts

- [ ] `DELETE /api/v1/ai-visibility/alerts/{id}` endpoint
  - [ ] Deletes alert (soft delete or hard delete based on config)
  - [ ] Returns 204 No Content
  - [ ] Authorization: user must own alert

- [ ] Alert preferences endpoint
  - [ ] `GET /api/v1/ai-visibility/alert-preferences` - get user preferences
  - [ ] `PUT /api/v1/ai-visibility/alert-preferences` - update preferences
  - [ ] Preferences include:
    - Email notifications enabled/disabled
    - Webhook URL (optional)
    - Alert types to receive (all or subset)

- [ ] Error handling
  - [ ] 404 for non-existent alert
  - [ ] 403 for unauthorized access

- [ ] Routes registered in `routes/api.php`
