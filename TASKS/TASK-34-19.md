## Description

Create the `AlertDetectionService` for detecting significant changes in AI visibility metrics and creating alerts.

---

## Acceptance Criteria

- [ ] `AlertDetectionService` class created at `app/Services/AIVisibility/`

- [ ] Alert types supported
  - [ ] `mention_spike`: Brand mention rate increased significantly (+20%)
  - [ ] `mention_drop`: Brand mention rate decreased significantly (-20%)
  - [ ] `competitor_gain`: Competitor gained significant ground (+15%)
  - [ ] `sentiment_change`: Sentiment shifted significantly (±0.3 score)

- [ ] `checkMentionSpike()` method implemented
  - [ ] Compares current period vs previous period
  - [ ] Threshold: +20% change
  - [ ] Creates alert with:
    - `alert_type`: `mention_spike`
    - `threshold`: 20.00
    - `previous_value`: previous rate
    - `current_value`: current rate
    - `change_percent`: calculated percentage
  - [ ] Returns created alert or null

- [ ] `checkMentionDrop()` method implemented
  - [ ] Compares current period vs previous period
  - [ ] Threshold: -20% change
  - [ ] Same alert structure as spike

- [ ] `checkCompetitorGain()` method implemented
  - [ ] Compares competitor mention rates
  - [ ] Threshold: +15% competitor gain vs brand
  - [ ] Creates alert when competitor overtakes brand
  - [ ] Identifies which competitor gained

- [ ] `checkSentimentChange()` method implemented
  - [ ] Compares average sentiment scores
  - [ ] Threshold: ±0.3 change
  - [ ] Creates alert for significant sentiment shift

- [ ] `runAllChecks()` method implemented
  - [ ] Runs all alert checks for a project
  - [ ] Returns array of triggered alerts
  - [ ] Dispatches notification events for each alert

- [ ] Alert deduplication
  - [ ] Won't create duplicate alert for same condition within 24 hours
  - [ ] Updates existing unresolved alert instead

- [ ] Configuration
  - [ ] Thresholds configurable via `config/ai-visibility.php`
  - [ ] Environment variables for customization:
    - `AI_VISIBILITY_SPIKE_THRESHOLD`
    - `AI_VISIBILITY_DROP_THRESHOLD`
    - `AI_VISIBILITY_COMPETITOR_THRESHOLD`

- [ ] Notification dispatch
  - [ ] Fires `AIVisibilityAlertTriggered` event
  - [ ] Event listeners send:
    - In-app notification
    - Email notification (if configured)
    - Webhook notification (if configured)

- [ ] Unit tests created
  - [ ] Test each alert type detection
  - [ ] Test threshold calculations
  - [ ] Test deduplication logic
  - [ ] Test notification dispatch
