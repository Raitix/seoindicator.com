## Implementation Notes
### ARIA Labels
```tsx
// IndicatorCard
<div
  role="button"
  tabIndex={0}
  aria-label={`${title}: ${value}. Status: ${status}. Click to view details.`}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault();
      onClick();
    }
  }}
>
```

### Focus Management
- Focus trap in modals/sheets
- Focus return after modal close
- Focus on error messages
