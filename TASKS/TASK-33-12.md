## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the PublicAuditCTA component that provides email capture for anonymous users and social sharing options. This is the conversion component for public audit pages.

## Acceptance Criteria
- [ ] Email capture form with validation
- [ ] "Get your free audit" primary CTA button
- [ ] Social sharing buttons (Twitter, LinkedIn, Facebook)
- [ ] Badge embed code snippet preview
- [ ] Form submits to lead capture API endpoint
- [ ] Success state shows confirmation message
- [ ] Error state shows retry option
- [ ] Privacy notice below form
- [ ] Accessible: form labels, keyboard navigation
- [ ] Unit tests for all states and interactions

## Dependencies
- TASK-33-5 (lead capture API endpoint)

## Effort Estimate
**3 hours** - Form component with API integration

## Technical Notes
- Use shadcn/ui Input, Button, Form components
- React Hook Form for validation
- Share buttons use navigator.share API (fallback to window.open)
- Embed code in textarea with copy button

## Props Interface
```typescript
interface PublicAuditCTAProps {
  auditHash: string;
  siteUrl: string;
  score: number;
}

interface LeadFormData {
  email: string;
}
```
