## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the TopIssues component that displays a prioritized list of SEO issues found during the audit, with severity indicators and "View full report" prompt for anonymous users.

## Acceptance Criteria
- [ ] Displays top 5 issues for anonymous users
- [ ] Full issue list for logged-in users (owner)
- [ ] Issue severity indicators (Critical/Warning/Info)
- [ ] Issue category badge (Technical/On-Page/Content/Mobile)
- [ ] Brief issue description with impact
- [ ] "View full report" prompt for anonymous users
- [ ] Expandable issue details (click to expand)
- [ ] Accessible: issues listed semantically
- [ ] Unit tests for limited and full views

## Dependencies
- None (standalone UI component)

## Effort Estimate
**2 hours** - List component with conditional rendering

## Technical Notes
- Use shadcn/ui Badge for severity
- Use Card component for issue items
- Conditional rendering based on isPartial prop
- Sort by severity (Critical → Warning → Info)

## Props Interface
```typescript
interface TopIssuesProps {
  issues: Issue[];
  isPartial: boolean;  // true = show only 5
  auditHash?: string;  // for "View full report" link
}

interface Issue {
  id: string;
  title: string;
  description: string;
  severity: 'critical' | 'warning' | 'info';
  category: string;
  impact: string;
}
```
