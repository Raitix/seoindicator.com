- [ ] Displays top 5 issues for anonymous users
- [ ] Full issue list for logged-in users (owner)
- [ ] Issue severity indicators (Critical/Warning/Info)
- [ ] Issue category badge (Technical/On-Page/Content/Mobile)
- [ ] Brief issue description with impact
- [ ] "View full report" prompt for anonymous users
- [ ] Expandable issue details (click to expand)
- [ ] Accessible: issues listed semantically
- [ ] Unit tests for limited and full views

## Effort Estimate

## Technical Notes

- Use Card component for issue items

## Props Interface
```typescript
interface TopIssuesProps {
  issues: Issue[];
  isPartial: boolean;  // true = show only 5
  auditHash?: string;  // for "View full report" link
}

interface Issue {
  id: string;
  title: string;
  description: string;
  severity: 'critical' | 'warning' | 'info';
  category: string;
  impact: string;
}
```
