## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the API endpoint that tracks badge clicks when users interact with embedded badges.

## Acceptance Criteria
- [ ] POST `/api/v1/badge/click` endpoint
- [ ] Accepts: hash, click_target ('audit' | 'home')
- [ ] Finds existing impression record (by IP hash + hash within last 24h)
- [ ] Updates impression with clicked_at and click_target
- [ ] Creates new impression if not found (with clicked_at set)
- [ ] No authentication required
- [ ] Rate limited: 10 requests/minute per IP
- [ ] Returns redirect to target URL or 204
- [ ] Returns 404 for invalid hash
- [ ] Feature tests for all scenarios

## Dependencies
- TASK-33-3 (badge_impressions table)
- TASK-33-17 (impression tracking)

## Effort Estimate
**2 hours** - Simple API endpoint

## Technical Notes
- Use IP hash + hash to correlate impression with click
- Consider using query param for redirect: ?redirect=1
- Click target determines redirect URL:
  - 'audit' → /audit/{hash}/
  - 'home' → https://seoindicator.com/

## Request Body
```json
{
  "hash": "abc123...",
  "click_target": "audit"
}
```
