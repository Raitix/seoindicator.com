## Description
Create API endpoints for admin credit and billing metrics. Provides overview, transaction history, and revenue metrics.

## Acceptance Criteria
- [ ] Controller created at `app/Http/Controllers/Api/V1/Admin/CreditsController.php`
- [ ] GET `/api/v1/admin/credits/overview` returns credit/balance stats
- [ ] GET `/api/v1/admin/credits/transactions` returns recent transactions (paginated)
- [ ] GET `/api/v1/admin/credits/revenue` returns revenue metrics
- [ ] All endpoints protected by AdminAuthorizationMiddleware
- [ ] Rate limiting: 60 requests/minute
- [ ] Transaction list supports filtering (user_id, type, date range)
- [ ] PII excluded or masked in responses
- [ ] Feature tests cover all endpoints
- [ ] API documentation updated
