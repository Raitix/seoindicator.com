## Description
Create an interactive component for users to select an AI model with pricing display and cost estimation.

## Acceptance Criteria

### Component Features
- [ ] Dropdown/modal with model list
- [ ] Model cards with: name, provider, cost, capabilities
- [ ] Cost per analysis display
- [ ] Free tier indicator and limits
- [ ] Capability badges (fast, advanced, vision, tools)
- [ ] Search/filter functionality
- [ ] "Set as default" option
- [ ] Currently selected model highlighted

### Selection Flow
- [ ] Click to open picker
- [ ] Filter by provider/capability
- [ ] Search by model name
- [ ] Select model
- [ ] See cost estimate before confirming
- [ ] Option to save as default

### Cost Display
- [ ] Show estimated cost for analysis type
- [ ] Compare to user's current balance
- [ ] Warning if insufficient balance
- [ ] Link to add credits if needed

### Components to Create
- [ ] `components/models/ModelPicker.tsx` (main component)
- [ ] `components/models/ModelCard.tsx`
- [ ] `components/models/ModelFilter.tsx`
- [ ] `components/models/CostEstimate.tsx`

### API Integration
- [ ] Fetch models from `GET /api/v1/models`
- [ ] Fetch pricing from `GET /api/v1/models/{id}/pricing`
- [ ] Set preference via `POST /api/v1/models/preferences`

### User Experience
- [ ] Keyboard navigation (arrow keys, enter, escape)
- [ ] Smooth animations
- [ ] Loading skeletons
- [ ] Error handling with retry

### Accessibility
- [ ] ARIA labels for picker
- [ ] Keyboard accessible
- [ ] Focus management
- [ ] Screen reader announcements
