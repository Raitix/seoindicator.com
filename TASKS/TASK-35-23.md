# TASK-35-23: Local SEO Alerts UI

## STATUS
`To Write Tests`

## SPECIFICATION
SPEC-035: Local SEO & Google Business Profile Tracking

## PRIORITY
`Medium`

## RISK
`Low`

## Description
Create alerts page and notification components for local SEO alerts.

## Acceptance Criteria
- [ ] Alerts page at /local-seo/alerts
  - Lists all alerts for user across all locations
  - Filters: severity, type, read/unread, location
  - Sort by date (newest first)
  - Pagination
- [ ] Alert card component:
  - Severity badge (info/warning/critical)
  - Alert type icon
  - Title and message
  - Location name (linked)
  - Timestamp
  - Read/unread indicator
  - Mark as read button
- [ ] Alert detail modal:
  - Full alert information
  - Related data (e.g., ranking change details)
  - Quick action button (e.g., "View rankings")
- [ ] Unread count badge:
  - Shows in navigation
  - Updates in real-time (or on navigation)
- [ ] Mark all as read button
  - In header
  - Confirmation dialog
- [ ] Alert type icons:
  - ranking_improved: arrow-up icon (green)
  - ranking_dropped: arrow-down icon (red)
  - new_review: message icon (blue)
  - negative_review: alert icon (orange)
  - rating_dropped: star icon (red)
  - competitor_overtake: users icon (yellow)
  - gbp_disconnected: link-off icon (critical/red)
- [ ] Toast notifications:
  - For new alerts
  - Auto-dismiss after 5 seconds
  - Click to view details
- [ ] Responsive design
- [ ] Component tests

## Dependencies
- TASK-35-16 (Local SEO Alerts API Controller)

## Effort Estimate
3 hours

## Technical Notes
- Consider WebSocket integration for real-time alerts
- Critical alerts might warrant push notifications
- Store dismissed alerts in localStorage
