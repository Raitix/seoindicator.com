## Description
Create LocalRankService for checking local pack and local organic rankings using geo-targeted SERP scraping. This implements the FREE alternative to paid rank tracking APIs.

## Acceptance Criteria
- [ ] LocalRankService created with interface
- [ ] Method: checkLocalRanking(BusinessLocation $location, Keyword $keyword): ?LocalRanking
  - Performs geo-targeted search
  - Extracts local pack positions (map results)
  - Extracts local organic positions
  - Returns LocalRanking model with results
- [ ] Method: buildGeoSearchUrl(string $query, float $lat, float $lng, string $location): string
  - Builds Google search URL with geo parameters
  - Uses `gl` parameter for country
  - Uses `uule` parameter for location encoding
  - Uses `tbm=lcl` for local search mode
- [ ] Method: parseLocalResults(string $html): array
  - Parses SERP HTML for local pack results
  - Extracts business names, positions, GBP IDs
  - Handles various SERP layouts
- [ ] Method: getMonthlyCheckCount(BusinessLocation $location): int
  - Returns current month's check count
- [ ] Quota enforcement:
  - Free tier: 50 checks per month per location
  - Throws QuotaExceededException when exceeded
- [ ] Caching: 24-hour TTL for ranking results
- [ ] Rate limiting: 1 request per second between Google requests
- [ ] Browser headers to avoid blocking
- [ ] Respect robots.txt
- [ ] Error handling for blocked requests
- [ ] Unit tests with mocked HTTP responses
- [ ] Integration tests (careful with live Google requests)
