## Description
Implement smart keyword suggestions based on parsing the user's website URL. This helps users who don't know what keyword to track by suggesting relevant terms extracted from their site.

## Acceptance Criteria
- [ ] Parse website URL to extract:
  - [ ] Domain name (e.g., "example" from "example.com")
  - [ ] Page title from homepage
  - [ ] Meta keywords (if present)
  - [ ] H1/H2 headings from homepage
- [ ] Generate keyword suggestions from extracted data:
  - [ ] Brand name + "review"
  - [ ] Brand name + "alternative"
  - [ ] Main product/service terms
  - [ ] Industry terms from page content
- [ ] Display suggestions below keyword input field
- [ ] User can click suggestion to auto-fill input
- [ ] Maximum 5 suggestions displayed
- [ ] Loading state during URL fetch
- [ ] Graceful fallback if URL fetch fails
- [ ] Cache suggestions for session

## Technical Details

### URL Parsing Service
```php
class WebsiteKeywordSuggester
{
    public function suggest(string $url): array
    {
        $html = $this->fetchHtml($url);
        $title = $this->extractTitle($html);
        $headings = $this->extractHeadings($html);
        
        return $this->generateSuggestions($title, $headings);
    }
}
```

### Suggestion Generation
```typescript
// Example: https://seotools.com
// Extract: "SEO Tools" from title
// Suggestions:
// - "seo tools"
// - "seo tools free"
// - "best seo tools"
// - "seo software"
```

### API Endpoint
```
GET /api/v1/suggestions/from-url?url=https://example.com

Response:

    "best seo tools",
    "seo software"
  ]
}
```
