## Technical Details

### Rate Limit Configuration
```typescript
const RATE_LIMITS = {
  perMinute: 10,
  perHour: 50,
  perDay: 100,
  captchaThreshold: 3
};
```

### Response Headers
```
X-RateLimit-Limit: 10
X-RateLimit-Remaining: 7
X-RateLimit-Reset: 1709049600
Retry-After: 60
```

### 429 Response
```json
{
  "success": false,
  "error": {
    "code": "RATE_LIMITED",
    "message": "Too many requests. Please wait before trying again.",
    "retryAfter": 60
  }
}
```

### URL Blocklist
```typescript
const BLOCKED_PATTERNS = [

  /^192\.168\./,
  /^file:/i,
  /internal\./i
];
```
