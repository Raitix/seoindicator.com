## Description
Create LocalSEOAlertService for detecting and generating alerts for local SEO events: ranking changes, new reviews, rating drops, competitor movements.

## Acceptance Criteria
- [ ] LocalSEOAlertService created with interface
- [ ] Alert types supported:
  - ranking_improved: Local pack position improved
  - ranking_dropped: Local pack position dropped
  - new_review: New review received
  - negative_review: Review with rating ≤ 2
  - rating_dropped: Average rating dropped by 0.5+
  - competitor_overtake: Competitor moved ahead in pack
  - gbp_disconnected: GBP connection lost
- [ ] Method: checkForAlerts(BusinessLocation $location): void
  - Runs all alert checks for a location
  - Creates alert records for detected issues
- [ ] Method: createAlert(int $userId, int $locationId, string $type, string $severity, string $title, string $message, array $data = []): LocalSEOAlert
  - Creates alert with deduplication (no duplicates within 24h)
- [ ] Method: getUnreadAlerts(int $userId): Collection
  - Returns unread alerts for user
- [ ] Method: markAsRead(int $alertId): void
- [ ] Method: markAllAsRead(int $userId): void
- [ ] Severity levels: info, warning, critical
- [ ] Integration with existing notification system (if available)
- [ ] Queue job for periodic alert checks
- [ ] Unit tests for each alert type
- [ ] Feature tests for alert operations
