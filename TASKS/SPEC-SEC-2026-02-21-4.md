# TASK: Validate OAuth Production Configuration and Token Encryption

## STATUS
`To Prioritize`

## PRIORITY
`High`

## RISK
`High`

## Specification
SPEC-SPEC-SEC-2026-02-21 (Task 4 of 5)

## Description
Verify OAuth production configuration is secure: redirect URIs are correct, secrets are loaded from environment, and stored tokens are encrypted at rest. This ensures OAuth integrations are safe for production use.

## Acceptance Criteria
- [ ] Verify Google OAuth redirect URI is correctly configured in Google Cloud Console
- [ ] Confirm OAuth client ID and secret are loaded from environment variables
- [ ] Verify no OAuth secrets are hardcoded in any config file
- [ ] Check that stored OAuth tokens are encrypted (check model casts/mutators)
- [ ] Verify `OAUTH_GOOGLE_CLIENT_ID` and `OAUTH_GOOGLE_CLIENT_SECRET` are in `.env.example`
- [ ] Test OAuth flow in staging/development environment
- [ ] Document OAuth environment variables required for production
- [ ] Write test verifying tokens are encrypted before storage

## Dependencies
- SPEC-SEC-2026-02-21-1 (secrets must be removed from files first)
- TASK-12-4 (OAuth implementation task - mentioned in spec dependencies)

## Effort Estimate
`Medium` — Verification and documentation task

## Files Affected
- `backend/config/services.php` (OAuth config)
- `backend/app/Services/OAuthService.php`
- `backend/.env.example`
- Any models storing OAuth tokens

## Risks
- **OAuth misconfiguration can block all user logins**
- **Redirect URI mismatch will cause OAuth failures**
- **Unencrypted tokens are a security vulnerability**

## Notes
This task requires access to Google Cloud Console to verify redirect URI configuration. Coordinate with owner if access is needed.
