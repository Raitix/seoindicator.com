   - `AIModel` interface with all required properties
   - `AIModelsResponse` for API response structure
   - `UseAIModelsReturn` for hook return type
   - `ModelPickerProps` for component props
   - Helper functions: `formatContextWindow`, `formatLatency`, `contentFitsModel`

2. **Hook (`useAIModels.ts`):**
   - Uses SWR for data fetching with caching
   - Fetches from `/api/v1/ai/models` endpoint
   - Returns models, defaultModel, userPreference, loading/error states, refetch
   - 1-minute deduplication interval for performance

3. **Component (`ModelPicker.tsx`):**
   - Grid layout with responsive design (1-4 columns)
   - Model cards with selection, disabled states, recommended badge
   - Context window and latency display with icons
   - Content fit warning when estimated tokens exceed context window
   - Loading skeleton with aria-busy
   - Error state with retry button
   - Empty state for no models
   - Full keyboard navigation support
   - Proper ARIA attributes for accessibility
