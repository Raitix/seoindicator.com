# TASK-17-10: Progress Bar Component

## STATUS
`To Develop`

## PRIORITY

## RISK

## Specification
- **SPEC-017**: User Onboarding & Activation Flow

## Dependencies
- TASK-17-3 (Frontend - OnboardingProvider, Modal, and Wizard Shell)

## Description
Create a visual progress bar component that shows the user's progress through the onboarding wizard. This provides clear feedback on how many steps remain, reducing abandonment.

## Acceptance Criteria
- [ ] Horizontal progress bar at top of wizard
- [ ] 5 step indicators (circles or dots)
- [ ] Current step highlighted
- [ ] Completed steps marked with checkmark or filled color
- [ ] Upcoming steps shown as empty/outlined
- [ ] Step labels visible (optional, on hover or below)
- [ ] Progress percentage displayed (e.g., "40% complete")
- [ ] Smooth animation on step transitions
- [ ] Accessible with ARIA labels
- [ ] Responsive design (works on mobile)

## Effort Estimate
`XS` (2-4 hours)

## Technical Details

### Component Props
```typescript
interface ProgressBarProps {
  currentStep: number;
  completedSteps: number[];
  totalSteps: number;
}
```

### Visual Design
```
[●]──[●]──[○]──[○]──[○]
Step 1  2    3    4    5

● = Completed
○ = Upcoming
◉ = Current
```

### Accessibility
```typescript
// ARIA attributes
<div
  role="progressbar"
  aria-valuenow={percentage}
  aria-valuemin={0}
  aria-valuemax={100}
  aria-label={`Onboarding progress: ${percentage}%`}
>
```
