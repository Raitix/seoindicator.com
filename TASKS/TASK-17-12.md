## Description
Create the dashboard banner that prompts users to resume their incomplete onboarding. This is the primary mechanism for bringing users back to complete the wizard after they've skipped or abandoned it.

## Acceptance Criteria
- [ ] Banner displayed on dashboard when onboarding incomplete
- [ ] Banner shows progress: "Complete your setup (X/5 steps)"
- [ ] Visual progress indicator (mini progress bar or step count)
- [ ] "Continue Setup" button opens wizard at correct step
- [ ] "Remind me later" button dismisses for session
- [ ] "Don't show again" option (sets preference)
- [ ] Banner styled as info/warning (not error)
- [ ] Banner appears below header, above main content
- [ ] Banner is dismissible with X button
- [ ] Banner doesn't show if onboarding completed
- [ ] Banner shows different message for skipped vs. in-progress:
  - [ ] In-progress: "Complete your setup to start tracking"
  - [ ] Skipped: "Finish setting up your first keyword"
- [ ] Responsive design (works on mobile)
