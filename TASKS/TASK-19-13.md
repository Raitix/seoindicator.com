## Acceptance Criteria
- [ ] Network timeout handling:
  - Mark indicator as failed after timeout
  - Continue processing other indicators
  - Log timeout with URL and duration
- [ ] Invalid URL handling:
  - Validate URL format before processing
  - Return clear error message
  - Mark as failed, continue with others
- [ ] Rate limiting detection:
  - Detect 429 responses from target sites
  - Implement exponential backoff
  - Single retry after backoff
- [ ] Memory exhaustion handling:
  - Monitor worker memory usage
  - Kill worker if approaching limit
  - Mark indicator as failed, restart worker
- [ ] Partial job completion:
  - Job can complete with some failed indicators
  - Final status reflects partial success
  - User can see which indicators failed and why
- [ ] Error messages are user-friendly (not technical)
- [ ] All errors logged with context for debugging
- [ ] Unit tests for error scenarios
