## Description
Create BusinessLocationController with REST API endpoints for managing business locations, including GBP connection flow.

## Acceptance Criteria
- [ ] Controller created at app/Http/Controllers/Api/V1/LocalSEO/BusinessLocationController.php
- [ ] Routes defined in routes/api.php under /api/v1/
- [ ] GET /api/v1/sites/{siteId}/locations
  - Lists all locations for a site
  - Authorization: user owns the site
  - Returns paginated list with basic info
- [ ] POST /api/v1/sites/{siteId}/locations
  - Creates new business location
  - Validates: name (required), address (required), phone, website, category
  - Returns created location with coordinates
- [ ] GET /api/v1/locations/{id}
  - Returns detailed location info
  - Includes latest insights summary, review stats
  - Authorization: user owns the location
- [ ] PUT /api/v1/locations/{id}
  - Updates location details
  - Authorization: user owns the location
- [ ] DELETE /api/v1/locations/{id}
  - Soft deletes location
  - Clears GBP connection
  - Authorization: user owns the location
- [ ] POST /api/v1/locations/{id}/connect-gbp
  - Initiates GBP OAuth flow
  - Returns authorization URL
- [ ] GET /api/v1/locations/{id}/gbp-callback
  - Handles OAuth callback
  - Stores tokens, fetches initial data
- [ ] DELETE /api/v1/locations/{id}/disconnect-gbp
  - Removes GBP connection
  - Revokes tokens
- [ ] Form Request validation for all inputs
- [ ] API Resource for response formatting
- [ ] Feature tests for all endpoints
- [ ] Authorization tests (user isolation)
