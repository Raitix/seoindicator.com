# TASKS Template

This folder contains implementation tasks.

## Naming Convention
`SPEC-X-Y.md` where:
- X = Specification/Feature number
- Y = Task number within that specification

## Task File Structure

```markdown
# SPEC-X-Y: [Task Name]

## Related
- Feature: FEAT-X
- Specification: SPEC-X
- Test: TESTS/SPEC-X-Y.md

## Description
_What this task accomplishes_

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Implementation Notes
_Technical details, approach_

## Dependencies
_Other tasks or external factors_

## Status
- [ ] Not Started
- [ ] In Progress
- [ ] Code Review
- [ ] Testing
- [ ] Complete
```
