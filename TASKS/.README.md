# TASKS Template

This folder contains implementation tasks.

## Naming Convention
`SPEC-X-Y.md` where:
- X = Specification/Feature number
- Y = Task number within that specification

## Task File Structure

```markdown
# SPEC-X-Y: [Task Name]

## STATUS
`To Prioritize` | `Prioritization In Progress` | `To Write Tests` | `Tests Coverage In Progress` |
`To Develop` | `In Development` | `To Test Locally` | `Testing Locally` |
`To Deploy` | `In Deployment` | `To Test Prod` | `Testing Prod` |
`Done` | `Cancelled`

## Related
- Feature: FEAT-X
- Specification: SPEC-X
- Test: TESTS/SPEC-X-Y.md

## Description
_What this task accomplishes_

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Implementation Notes
_Technical details, approach_

## Dependencies
_Other tasks or external factors_

## Notes
_Additional context_
```

---

## Valid Status Values

| Status | Meaning | Next Agent |
|--------|---------|------------|
| `To Prioritize` | Ready for prioritization | ProjectManager |
| `Prioritization In Progress` | Being prioritized | ProjectManager |
| `To Write Tests` | Ready for test design | PreTester |
| `Tests Coverage In Progress` | Tests being written | PreTester |
| `To Develop` | Ready for implementation | Developer |
| `In Development` | Being implemented | Developer |
| `To Test Locally` | Ready for local testing | LocalTester |
| `Testing Locally` | Local testing in progress | LocalTester |
| `To Deploy` | Ready for deployment | DevOps |
| `In Deployment` | Being deployed | DevOps |
| `To Test Prod` | Ready for production testing | ProdTester |
| `Testing Prod` | Production testing in progress | ProdTester |
| `Done` | Successfully completed | DocSystemAnalyst |
| `Cancelled` | Not viable or unnecessary | — |
