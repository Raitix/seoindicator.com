## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the BadgePreview component that shows live badge previews with size/theme selectors and generates embed code snippets for users to copy.

## Acceptance Criteria
- [ ] Live preview of badge in selected size
- [ ] Size selector: small, medium, large
- [ ] Theme selector: light, dark
- [ ] Three embed code types:
  - SVG image link (HTML)
  - JavaScript embed (script tag)
  - iframe embed
- [ ] Copy button for each embed type
- [ ] Copied confirmation feedback
- [ ] Responsive preview container
- [ ] Accessible: preview described, selectors labeled
- [ ] Unit tests for all options and interactions

## Dependencies
- TASK-33-6 (BadgeService for badge data)
- TASK-33-15 (SVG badge route)

## Effort Estimate
**3 hours** - Preview component with code generation

## Technical Notes
- Fetch badge preview from API
- Embed code templates stored as constants
- Use navigator.clipboard for copy
- Fallback to textarea select for older browsers

## Embed Code Templates
```html
<!-- SVG -->
<a href="https://seoindicator.com/audit/{hash}/">
  <img src="https://seoindicator.com/badge/{hash}/{size}.svg" alt="SEO Score: {score}/100" />
</a>

<!-- JS -->
<div data-seoindicator-badge="{hash}" data-size="{size}" data-theme="{theme}"></div>
<script src="https://seoindicator.com/badge.js" async></script>

<!-- iframe -->
<iframe src="https://seoindicator.com/badge/{hash}/large?theme={theme}" 
        width="300" height="150" frameborder="0"></iframe>
```
