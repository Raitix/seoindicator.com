# TASK-22-12: Request Validation and Authorization

## STATUS
`To Deploy`

## PRIORITY
`High`

## RISK
`Medium`

## Related Specification
SPEC-022: Headless Crawler Service (JS-Rendered HTML)

## Related Feature
FEAT-022: Headless Crawler Service (JS-Rendered HTML)

---

## Description
Create comprehensive form request validation and authorization policies for the crawler API.

## Acceptance Criteria

### Form Requests

#### CrawlRequest (POST /api/v1/crawler/crawl)
- [ ] Created at `app/Http/Requests/Api/V1/CrawlRequest.php`
- [ ] Authorization: authenticated users only
- [ ] URL validation:
  - [ ] Required
  - [ ] Valid URL format
  - [ ] Max 2083 characters
  - [ ] Must use http or https protocol
  - [ ] Must not resolve to blocked IPs (call UrlValidatorService)
- [ ] Depth validation:
  - [ ] Integer, 0-2
  - [ ] Default 0 if not provided
- [ ] Options validation:
  - [ ] waitForSelector: string, nullable, max 200 chars
  - [ ] waitTime: integer, 0-30000 ms, default 2000
  - [ ] userAgent: string, max 500 chars, regex validation
  - [ ] includeImages: boolean
  - [ ] followRedirects: boolean
  - [ ] maxRedirects: integer, 0-10, default 5

#### ContentRequest (GET /api/v1/crawler/jobs/{jobId}/content)
- [ ] Created at `app/Http/Requests/Api/V1/ContentRequest.php`
- [ ] Authorization: user owns the job
- [ ] Optional pagination parameters:
  - [ ] page: integer, min 1
  - [ ] perPage: integer, 1-100, default 50

### Custom Validation Rules

#### ValidCrawlUrl Rule
- [ ] Created at `app/Rules/ValidCrawlUrl.php`
- [ ] Check URL format
- [ ] Check protocol (http/https only)
- [ ] Check against blocked IPs (SSRF)
- [ ] Check against blocked domains
- [ ] Custom error messages for each failure type

#### MaxContentSize Rule
- [ ] Created at `app/Rules/MaxContentSize.php`
- [ ] Validate total content size won't exceed limit
- [ ] Consider user's existing active jobs

### Authorization Policies

#### CrawlJobPolicy
- [ ] Created at `app/Policies/CrawlJobPolicy.php`
- [ ] `view(User $user, CrawlJob $job)` - User owns job or is admin
- [ ] `update(User $user, CrawlJob $job)` - User owns job
- [ ] `delete(User $user, CrawlJob $job)` - User owns job
- [ ] `cancel(User $user, CrawlJob $job)` - User owns job, job is queued/running

### Rate Limiting

#### Per-User Limits
- [ ] Max 10 crawl jobs per 24 hours (configurable)
- [ ] Max 3 concurrent running jobs
- [ ] Track in cache or database
- [ ] Return X-RateLimit headers

#### Per-IP Limits (for anonymous/future)
- [ ] Max 5 crawl jobs per 24 hours
- [ ] Max 1 concurrent running job

#### Custom Rate Limiter
- [ ] Create in `AppServiceProvider.php`
- [ ] Named limiter: 'crawler'
- [ ] Use user ID as key
- [ ] Return 429 with Retry-After header

### Validation Error Messages
- [ ] Custom messages for all validation rules
- [ ] Field-specific messages
- [ ] Localized messages (optional)

### Error Response Format
```json
{
  "message": "The given data was invalid.",
  "errors": {
    "url": [
      "The URL format is invalid.",
      "The URL resolves to a blocked IP address."
    ],
    "depth": [
      "The depth must be between 0 and 2."
    ]
  }
}
```

### Tests
- [ ] Test CrawlRequest validation
- [ ] Test ValidCrawlUrl rule with blocked IPs
- [ ] Test authorization policies
- [ ] Test rate limiting
- [ ] Test error response format
