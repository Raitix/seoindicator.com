## Description
Create REST API endpoints for users to view and manage their saved payment methods (cards, bank accounts).

## Acceptance Criteria

### Endpoints

#### List Payment Methods
- [ ] `GET /api/v1/payments/methods`
- [ ] Returns list of saved payment methods for authenticated user

#### Delete Payment Method
- [ ] `DELETE /api/v1/payments/methods/{id}`
- [ ] Removes payment method from user's account

### Response Format (List)
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "provider": "stripe",
      "brand": "visa",
      "last_four": "4242",
      "is_default": true,
      "created_at": "2026-03-01T12:00:00Z"
    }
  ]
}
```

### PaymentMethod Model
- [ ] `app/Models/PaymentMethod.php` created
- [ ] BelongsTo relationship to User
- [ ] Scope for user's methods
- [ ] Accessor for formatted display

### Controller Implementation
- [ ] `listMethods()` method in PaymentController
- [ ] `deleteMethod()` method in PaymentController
- [ ] User can only access their own methods

### Stripe Integration
- [ ] Fetch payment methods from Stripe customer
- [ ] Detach payment method from Stripe on delete
- [ ] Sync with local `payment_methods` table

### Validation Rules
- [ ] User must own the payment method being deleted
- [ ] Cannot delete default if it's the only method

### Security Measures
- [ ] User can only see their own payment methods
- [ ] Delete requires user ownership verification
- [ ] Soft delete vs hard delete consideration

### Feature Tests
- [ ] Test list returns user's methods only
- [ ] Test delete removes method
- [ ] Test cannot delete another user's method
- [ ] Test unauthenticated returns 401
