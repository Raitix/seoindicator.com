## Description

## Acceptance Criteria

- [ ] `CompetitorComparisonService` created at `app/Services/AIVisibility/`

- [ ] `getHeadToHead()` method implemented
  - [ ] Accepts: `projectId`, `competitorName`
  - [ ] Returns direct comparison between brand and specific competitor
  - [ ] Includes:
    - Mention counts
    - Mention rates
    - Sentiment scores
    - Common query categories
    - Co-mention frequency (both mentioned in same response)
  - [ ] Response structure:
    ```json
    {
      "brand": { "mentions": 15, "rate": 23.5, "sentiment": 0.45 },
      "competitor": { "mentions": 25, "rate": 38.5, "sentiment": 0.30 },
      "co_mentions": 5,
      "brand_advantage": ["comparison", "use_case"],
      "competitor_advantage": ["recommendation"]
    }
    ```

- [ ] `getCompetitorRanking()` method implemented
  - [ ] Accepts: `projectId`
  - [ ] Ranks brand and all competitors by mention rate
  - [ ] Returns position, mention rate, trend direction
  - [ ] Response structure:
    ```json
    {
      "rankings": [
        { "position": 1, "name": "Ahrefs", "rate": 38.5, "trend": "up" },
        { "position": 2, "name": "SEMrush", "rate": 30.8, "trend": "stable" },
        { "position": 3, "name": "SEOIndicator", "rate": 23.5, "trend": "up" }
      ],
      "brand_position": 3
    }
    ```

- [ ] `getCompetitorMentionDetails()` method implemented
  - [ ] Accepts: `projectId`, `competitorName`
  - [ ] Returns detailed breakdown of competitor mentions
  - [ ] Includes:
    - Query categories where competitor appears
    - Context snippets
    - Sentiment breakdown
    - Platforms where competitor is mentioned

- [ ] `trackCompetitorTrend()` method implemented
  - [ ] Accepts: `projectId`, `competitorName`, `period`
  - [ ] Tracks competitor mention trend over time
  - [ ] Returns weekly/monthly data points

- [ ] Performance optimization
  - [ ] Single database query for comparison data
  - [ ] Caches results for 1 hour
  - [ ] Batch processing for multiple competitors

- [ ] Unit tests created
  - [ ] Test head-to-head comparison
  - [ ] Test ranking calculation
  - [ ] Test co-mention detection
  - [ ] Test trend tracking
