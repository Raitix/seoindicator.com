## Description
Implement polling endpoint as fallback for environments without SSE support.

## Acceptance Criteria
- [x] `GET /api/v1/analysis/jobs/{jobId}/progress` endpoint
- [x] Response: { status, totalIndicators, completedIndicators, progressPercent, results: [] }
- [x] Polling interval recommendation: 2 seconds (documented)
- [x] Authorization: user must own the job
- [ ] Rate limiting: 30 requests per minute per job **NOT IMPLEMENTED**
- [x] Cache-Control: no-store (always fresh data)
- [x] Returns 404 if job not found
- [x] Returns 403 if user doesn't own job (returns 404 for security)
- [x] Feature tests for endpoint
