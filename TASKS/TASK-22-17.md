## Description
Implement robust timeout and cancellation handling for crawl jobs to prevent runaway processes and resource exhaustion.

## Acceptance Criteria

### Timeout Configuration
- [ ] Job timeout: 5 minutes (configurable)
- [ ] Page timeout: 30 seconds (configurable)
- [ ] Browser timeout: 60 seconds (configurable)
- [ ] Connection timeout: 10 seconds

### Timeout Detection
- [ ] Use Laravel's `setTimeout()` on queue job
- [ ] Implement custom timeout tracking
- [ ] Monitor elapsed time between pages
- [ ] Log timeout events with context

### Timeout Handling Flow
1. [ ] Job starts, record start time
2. [ ] Before each page, check elapsed time
3. [ ] If elapsed > timeout - 30s, start graceful shutdown
4. [ ] If elapsed > timeout, force termination
5. [ ] Store partial results
6. [ ] Update job status to 'completed' with timeout note

### Cancellation Support

#### Cancellation Request
- [ ] API endpoint: DELETE /api/v1/crawler/jobs/{jobId}
- [ ] Check job status (only queued/running can cancel)
- [ ] Set cancellation flag in cache/database
- [ ] Return 202 Accepted

#### Cancellation Detection
- [ ] Check cancellation flag before each page
- [ ] Use atomic cache operation
- [ ] Support immediate cancellation for queued jobs

#### Cancellation Flow
1. [ ] User requests cancellation
2. [ ] Set cancellation flag
3. [ ] Worker detects flag before next page
4. [ ] Worker stops gracefully
5. [ ] Browser instance closed
6. [ ] Partial results stored
7. [ ] Job status set to 'cancelled'
8. [ ] Cancellation timestamp recorded

### Resource Cleanup on Timeout/Cancel
- [ ] Close browser instance
- [ ] Release queue slot
- [ ] Clear rate limit tokens
- [ ] Remove temporary files
- [ ] Unlock queued URLs

### Partial Results Handling
- [ ] Store all successfully crawled pages
- [ ] Include timeout/cancellation reason in response
- [ ] Mark which pages were not crawled
- [ ] Return partial results in job status

### Job Status Response (Cancelled)
```json
{
  "jobId": "crawl-abc123",
  "status": "cancelled",
  "pagesCrawled": 3,
  "totalSize": 600000,
  "cancelledAt": "2026-03-01T10:00:30Z",
  "reason": "User requested cancellation",
  "partialContentUrl": "/api/v1/crawler/jobs/crawl-abc123/content"
}
```

### Job Status Response (Timeout)
```json
{
  "jobId": "crawl-abc123",
  "status": "completed",
  "pagesCrawled": 8,
  "totalSize": 1500000,
  "completedAt": "2026-03-01T10:05:00Z",
  "reason": "Job completed with partial results (timeout reached)",
  "partialContentUrl": "/api/v1/crawler/jobs/crawl-abc123/content"
}
```

### Worker Process Monitoring
- [ ] Monitor for zombie processes
- [ ] Kill browser processes if worker dies
- [ ] Use process supervisors (supervisor/systemd)
- [ ] Log process start/stop

### Configuration
```php
// config/crawler.php
'timeouts' => [
    'job' => 300,        // 5 minutes
    'page' => 30,        // 30 seconds
    'browser' => 60,     // 60 seconds
    'connection' => 10,  // 10 seconds
    'grace_period' => 30, // Grace time before hard kill
]
```
