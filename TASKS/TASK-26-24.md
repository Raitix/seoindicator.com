## Description
Implement the frontend PayPal payment flow using PayPal JS SDK for Smart Buttons integration.

## Acceptance Criteria

### Payment Flow Options

#### Option A: Smart Buttons (Popup)
1. User selects credit package
2. PayPal button renders on page
3. User clicks, PayPal popup opens
4. User logs in and approves
5. Payment captured, balance updated

#### Option B: Redirect Flow
1. User selects credit package
2. Redirect to PayPal
3. User approves payment
4. Redirect back to success/cancel page
5. Payment captured, balance updated
