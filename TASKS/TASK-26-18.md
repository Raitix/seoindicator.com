## Description
Create REST API endpoint for getting detailed pricing information for a specific model, including cost estimation for different analysis types.

## Acceptance Criteria

### Endpoint
- [ ] `GET /api/v1/models/{id}/pricing`
- [ ] Authentication optional (public data)
- [ ] Returns detailed pricing breakdown

### Path Parameter
- [ ] `id` - AI model ID (required)

### Query Parameters
- [ ] `analysis_type` - Type of analysis ('quick', 'standard', 'deep')
- [ ] `estimated_tokens` - Custom token estimate

### Response Format
```json
{
  "success": true,
  "data": {
    "model": {
      "id": 1,
      "display_name": "GPT-4 Turbo",
      "provider": "openrouter",
      "model_id": "openai/gpt-4-turbo"
    },
    "pricing": {
      "cost_per_1m_input": 10.00,
      "cost_per_1m_output": 30.00,
      "cost_per_1k_input": 0.01,
      "cost_per_1k_output": 0.03
    },
    "estimates": {
      "quick_analysis": {
        "tokens": 500,
        "cost": 0.01
      },
      "standard_analysis": {
        "tokens": 2000,
        "cost": 0.05
      },
      "deep_analysis": {
        "tokens": 5000,
        "cost": 0.12
      }
    },
    "free_tier": {
      "available": false,
      "limit": null
    }
  }
}
```

### Controller Implementation
- [ ] `pricing()` method in ModelController
- [ ] Uses ModelPricingService for calculations
- [ ] Returns 404 if model not found

### Token Estimates by Analysis Type
- [ ] Quick: ~500 tokens
- [ ] Standard: ~2000 tokens
- [ ] Deep: ~5000 tokens

### Validation Rules
- [ ] `id` must exist in ai_models table
- [ ] `analysis_type` must be valid enum if provided
- [ ] `estimated_tokens` must be positive integer if provided

### Error Responses
- [ ] 404 Not Found if model doesn't exist
- [ ] 422 Unprocessable Entity for invalid parameters

### Feature Tests
- [ ] Test pricing for existing model
- [ ] Test 404 for non-existent model
- [ ] Test analysis type parameter
- [ ] Test custom token estimate
- [ ] Test free tier model pricing
