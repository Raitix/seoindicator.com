# TASK-35-10: GBP Reviews Service with Sentiment

## Description
Create GBPReviewsService for syncing reviews from GBP API and performing sentiment analysis using a free keyword-based approach.

## Acceptance Criteria
- [ ] GBPReviewsService created with interface
- [ ] Method: syncReviews(BusinessLocation $location): void
  - Fetches all reviews from GBP API (paginated)
  - Stores in gbp_reviews table
  - Updates existing reviews if changed
  - Triggers sentiment analysis for new/updated reviews
- [ ] Method: getReviews(BusinessLocation $location, array $filters = []): LengthAwarePaginator
  - Returns paginated reviews
  - Supports filtering by rating, sentiment, date range
  - Supports sorting by date, rating
- [ ] Method: getReviewStats(BusinessLocation $location): array
  - Returns average rating, total count
  - Returns rating distribution (1-5 stars)
  - Returns sentiment breakdown
- [ ] Method: respondToReview(BusinessLocation $location, string $reviewId, string $reply): bool
  - Posts response to Google
  - Stores response locally
- [ ] Sentiment Analyzer implementation:
  - analyzeSentiment(string $text): string
  - Returns 'positive', 'negative', or 'neutral'
  - Uses keyword matching (no paid API)
  - Extensive keyword lists for accuracy
- [ ] Method: detectNewNegativeReviews(BusinessLocation $location): Collection
  - Returns reviews with rating <= 2 and no prior alert
- [ ] Queue job for background sync
- [ ] Unit tests for sentiment analysis
- [ ] Feature tests for review operations

## Dependencies
- TASK-35-3 (GBP-Related Models)
- TASK-35-8 (GBP API Client Service)

## Effort Estimate
4 hours

## Technical Notes
- Sentiment analysis uses simple keyword counting
- Keyword lists should be comprehensive (50+ words each category)
- Consider adding negation detection (e.g., "not good" = negative)
- Store sentiment to avoid re-analysis
