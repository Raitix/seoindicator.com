## Acceptance Criteria

- [ ] `AlertNotification` component created at `frontend/components/ai-visibility/`
  - [ ] Displays single alert with:
    - Alert type icon (spike, drop, competitor, sentiment)
    - Project name
    - Message summarizing the alert
    - Time ago (relative time)
    - Read/unread indicator
  - [ ] Color coding by alert type:
    - `mention_spike`: green (positive)
    - `mention_drop`: red (negative)
    - `competitor_gain`: orange (warning)
    - `sentiment_change`: yellow (caution)
  - [ ] Click to view details
  - [ ] Actions: Mark as Read, Resolve

- [ ] `AlertList` component created
  - [ ] Displays list of alerts
  - [ ] Filter controls:
    - By project (dropdown)
    - By type (multi-select)
    - Read/unread toggle
  - [ ] "Mark All as Read" button
  - [ ] Infinite scroll or pagination
  - [ ] Empty state with illustration

- [ ] `AlertDetailModal` component created
  - [ ] Shows full alert details:
    - Alert type and message
    - Previous vs current values
    - Percentage change
    - Related project link
    - Recommendations for action
  - [ ] Actions: Resolve, Dismiss, View Project

- [ ] `AlertBell` component created (header integration)
  - [ ] Bell icon with unread count badge
  - [ ] Dropdown showing recent alerts (last 5)
  - [ ] "View All" link to alerts page
  - [ ] Real-time updates (polling or WebSocket)

- [ ] Alert toast notifications
  - [ ] Shows toast when new alert received
  - [ ] Auto-dismiss after 10 seconds
  - [ ] Click to view details
  - [ ] Dismiss button

- [ ] `AlertPreferencesForm` component created
  - [ ] Toggle for email notifications
  - [ ] Webhook URL input (optional)
  - [ ] Alert type checkboxes (select which to receive)
  - [ ] Save button with success feedback

- [ ] Alert page created at `frontend/app/ai-visibility/alerts/page.tsx`
  - [ ] Full alert list with all filters
  - [ ] Sidebar with preferences form
  - [ ] Summary stats (total, unread, by type)

- [ ] Loading states
  - [ ] Skeleton for alert list
  - [ ] Loading spinner for modal

- [ ] Error handling
  - [ ] Error message if API fails
  - [ ] Retry button

- [ ] Responsive design
  - [ ] Mobile: stacked alerts, modal becomes bottom sheet
  - [ ] Desktop: side-by-side layout

- [ ] Accessibility
  - [ ] Proper ARIA labels
  - [ ] Keyboard navigation
  - [ ] Screen reader announcements

- [ ] Component tests created
  - [ ] Test alert rendering by type
  - [ ] Test filter functionality
