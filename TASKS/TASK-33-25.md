## Meta Tag Examples
```html

<meta name="description" content="SEO audit for example.com - Score: 85/100. View technical SEO analysis and recommendations.">
<meta name="robots" content="index, follow">
<link rel="canonical" href="https://seoindicator.com/audit/abc123/">
<meta property="og:title" content="example.com SEO Score: 85/100">
<meta property="og:description" content="SEO audit results for example.com">
<meta property="og:image" content="https://seoindicator.com/badge/abc123/og.png">
<meta property="og:url" content="https://seoindicator.com/audit/abc123/">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">
```
