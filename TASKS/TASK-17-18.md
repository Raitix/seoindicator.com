## Technical Details

### Suggestion Algorithm
```php
class CompetitorSuggester
{
    public function suggest(string $url): array
    {
        $industry = $this->classifyIndustry($url);
        $keywords = $this->extractKeywords($url);
        
        return Competitor::where('industry', $industry)
            ->orWhereHas('keywords', fn($q) => $q->whereIn('keyword', $keywords))
            ->limit(3)
            ->get();
    }
}
```

### Industry Classification
- Use meta keywords, title, and content
- Match against known industry categories
- Fallback to "General" if unclassified
