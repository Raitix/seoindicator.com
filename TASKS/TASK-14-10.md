### Features

#### 1. Link Extraction
```php
class BrokenLinkChecker implements CheckerInterface
{
    public function check(CrawlResult $result): ?IssueFinding
    {
        $links = $this->extractLinks($result->html, $result->url);
        $brokenLinks = $this->validateLinks($links);
        
        if (count($brokenLinks) > 0) {
            return $this->createFinding(
                issueType: 'broken_links',
                severity: 'critical',
                description: "Found {$count} broken links on this page",
                recommendation: 'Fix or remove broken links to improve user experience and SEO.',
                context: ['broken_links' => $brokenLinks]
            );
        }
        
        return null;
    }
    
    protected function extractLinks(string $html, string $baseUrl): array;
    protected function validateLinks(array $links): array;
}
```

#### 2. Link Validation Strategy

**Internal Links (same domain):**
- Validate during crawl (reuse CrawlResult data)
- Track in cache to avoid re-checking same URL
- Cache key: `audit:links:{audit_id}:{url_hash}`

**External Links:**
- HEAD request first (faster)
- Fallback to GET if HEAD not supported
- Timeout: 10 seconds per link
- Max external links to check: 50 per page
- Skip if daily quota exceeded

#### 3. Status Code Handling
| Status Code | Severity | Action |
|-------------|----------|--------|
| 200-299 | — | OK, no issue |
| 301, 302 | Notice | Redirect detected |
| 404 | Critical | Broken link |
| 410 | Critical | Gone permanently |
| 500-599 | Critical | Server error |
| Timeout | Warning | Could not verify |
| DNS Error | Critical | Domain not found |

#### 4. Link Types to Check
```php
// Links to validate
<a href="...">
<link rel="canonical" href="...">
<img src="...">
<script src="...">
<link rel="stylesheet" href="...">
```
