## Description
Create comprehensive automated tests for all authentication flows including token validation, expiry handling, and login/logout behavior.

## Test Scenarios

### Token Validation Tests
- Valid token → User authenticated
- Expired token → User redirected to login
- Invalid token → User redirected to login
- No token → User sees login page

### Login Flow Tests
- Successful login → Redirect to dashboard/destination
- Failed login → Show error message
- Login with redirect param → Redirect to stored destination

### Session Expiry Tests
- API returns 401 → Clear storage, redirect to login
- Session expired message shown to user

### Logout Tests
- Logout clears tokens
- Logout redirects to login page
- Protected routes inaccessible after logout
