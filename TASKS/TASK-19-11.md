## Description

## Acceptance Criteria
- [ ] AnalysisProgress component with props:
  - jobId: number
  - onComplete: (results) => void
  - onCancel: () => void
- [ ] SSE connection management:
  - Connects to /api/v1/analysis/jobs/{jobId}/stream
  - Auto-reconnects on disconnect with exponential backoff
  - Falls back to polling if SSE fails after 3 attempts
- [ ] UI elements:
  - Progress bar with percentage
  - Status indicator (pending/running/completed/cancelled/failed)
  - Cancel button (disabled when not running)
  - Elapsed time display
- [ ] State management:
  - Tracks completedIndicators, totalIndicators
  - Updates progressPercent in real-time
- [ ] Accessibility: ARIA labels, keyboard navigation
- [ ] Unit tests with mocked SSE
- [ ] Storybook component documentation
