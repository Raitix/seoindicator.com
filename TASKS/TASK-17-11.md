## Description
Implement the skip functionality that allows users to skip the entire onboarding or individual steps. This ensures users aren't forced through the wizard and can explore the platform independently.

## Acceptance Criteria
- [ ] "Skip for now" link on each step (steps 1-4)
- [ ] Skip link styled as subtle text link (not primary button)
- [ ] Confirmation dialog on skip:
  - [ ] "Skip onboarding? You can always complete it later from the dashboard."
  - [ ] "Skip" and "Continue Setup" buttons
- [ ] POST `/api/v1/onboarding/skip` API call on confirm
- [ ] `skipped_at` timestamp set in database
- [ ] Modal closes on skip
- [ ] Resume banner appears on dashboard for skipped onboarding
- [ ] Per-step skip option (skip individual step, not entire wizard):
  - [ ] Skipped step marked as completed in progress
  - [ ] User advances to next step
- [ ] Analytics event fired: `onboarding_skipped`
- [ ] Event includes which step was skipped from

## Effort Estimate

## Technical Details

### Skip Flow
```typescript
const handleSkip = async () => {
  const confirmed = await showConfirmDialog({
    title: "Skip onboarding?",
    message: "You can always complete it later from the dashboard.",
    confirmText: "Skip",
    cancelText: "Continue Setup"
  });
  
  if (confirmed) {
    await onboardingContext.skipOnboarding();
    trackEvent('onboarding_skipped', { step: currentStep });
    closeModal();
  }
};
```

### API Endpoint
```http
POST /api/v1/onboarding/skip
Authorization: Bearer {token}

Response (200):
{
  "success": true,
  "data": {
    "skipped_at": "2026-02-28T10:00:00Z"
  }
}
```
