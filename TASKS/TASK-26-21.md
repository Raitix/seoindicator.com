## Description
Create a reusable component to display the user's credit balance with quick actions for adding credits.

## Acceptance Criteria

### Component Features
- [ ] Display current balance in USD format (e.g., "$25.50")
- [ ] Show total purchased and total spent (optional, expandable)
- [ ] Low balance warning when balance < $2.00
- [ ] "Add Credits" button that navigates to pricing
- [ ] Link to transaction history
- [ ] Real-time balance updates after purchases

### Component States
- [ ] **Loading**: Skeleton while fetching balance
- [ ] **Loaded**: Show balance with actions
- [ ] **Error**: Error message with retry button
- [ ] **Unauthenticated**: "Sign in to view balance" with login link

### Placement Locations
- [ ] Header/navbar (compact version)
- [ ] Dashboard sidebar (full version)
- [ ] Analysis page (before running)
- [ ] Settings page (balance management)

### Components to Create
- [ ] `components/credits/CreditBalance.tsx` (main component)
- [ ] `components/credits/CreditBalanceCompact.tsx` (header version)
- [ ] `components/credits/LowBalanceWarning.tsx`

### API Integration
- [ ] Fetch balance from `GET /api/v1/credits/balance`
- [ ] React Query for caching and refetching
- [ ] Invalidate cache after purchases

### User Experience
- [ ] Smooth animations on balance changes
- [ ] Toast notification on low balance
- [ ] Quick add credits modal option
- [ ] Responsive design

### Accessibility
- [ ] Live region for balance updates (screen readers)
- [ ] Keyboard accessible
- [ ] High contrast support

## Dependencies
- TASK-26-6 (balance API endpoint)

## Effort Estimate
`Small` (2-3 hours)

## Notes
- Consider using context/provider for balance state
- Cache balance to reduce API calls
- Optimistic updates for better UX

## Security Considerations
- Only fetch balance for authenticated users
- Mask balance in logs for privacy
- Rate limit balance API calls
