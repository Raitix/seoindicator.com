## Description
Implement comprehensive rate limiting for the crawler service to prevent abuse and protect target servers.

## Acceptance Criteria

### Service Structure
- [ ] Service created at `app/Services/Crawler/RateLimiterService.php`
- [ ] Use Laravel's cache for rate limit tracking

### Rate Limit Types

#### User Daily Limit
- [ ] Track crawl requests per user per 24 hours
- [ ] Default: 10 jobs per day
- [ ] Reset at midnight UTC or rolling 24-hour window
- [ ] Return remaining count in response headers

#### User Concurrent Jobs
- [ ] Track active (queued/running) jobs per user
- [ ] Default: 3 concurrent jobs
- [ ] Block new jobs when limit reached
- [ ] Release slot when job completes/fails

#### Per-Domain Rate Limit
- [ ] Track requests to each target domain
- [ ] Default: 1 request per second per domain
- [ ] Implement crawl delay between requests
- [ ] Use domain as key (normalized)

#### Global Rate Limit
- [ ] Total concurrent browser instances
- [ ] Default: 10 global concurrent jobs
- [ ] Prevent resource exhaustion
- [ ] Queue jobs when limit reached

### Rate Limit Headers
- [ ] `X-RateLimit-Limit` - Maximum allowed
- [ ] `X-RateLimit-Remaining` - Remaining in current window
- [ ] `X-RateLimit-Reset` - Unix timestamp when window resets
- [ ] `Retry-After` - Seconds until retry (on 429)

### Rate Limit Response (429)
```json
{
  "message": "Rate limit exceeded.",
  "limit": 10,
  "remaining": 0,
  "resetAt": "2026-03-01T00:00:00Z",
  "retryAfter": 3600
}
```

### Core Methods
- [ ] `checkUserLimit(int $userId): RateLimitResult`
- [ ] `checkConcurrentLimit(int $userId): RateLimitResult`
- [ ] `checkDomainLimit(string $domain): RateLimitResult`
- [ ] `checkGlobalLimit(): RateLimitResult`
- [ ] `incrementUserCount(int $userId): void`
- [ ] `incrementDomainCount(string $domain): void`
- [ ] `decrementConcurrentCount(int $userId): void`

### RateLimitResult Structure
```php
[
    'allowed' => bool,
    'limit' => int,
    'remaining' => int,
    'resetAt' => Carbon,
    'retryAfter' => int|null,
]
```

### Configuration
```php
// config/crawler.php
'rate_limits' => [
    'user_daily' => 10,
    'user_concurrent' => 3,
    'domain_per_second' => 1,
    'global_concurrent' => 10,
    'window_hours' => 24,
]
```

### Middleware
- [ ] Create `CrawlerRateLimit` middleware
- [ ] Apply to all crawler endpoints
- [ ] Check all rate limits before processing
- [ ] Return 429 with headers if any limit exceeded

### Cache Keys
- [ ] User daily: `crawler:rate:user:{userId}:daily`
- [ ] User concurrent: `crawler:rate:user:{userId}:concurrent`
- [ ] Domain: `crawler:rate:domain:{domain}`
- [ ] Global: `crawler:rate:global`

### Cleanup
- [ ] Expire cache keys automatically
- [ ] Clean up stale concurrent counts on job completion
- [ ] Handle crashed jobs (cleanup on next check)

### Tests

- [ ] Test concurrent job limit
- [ ] Test domain rate limit
- [ ] Test global limit
- [ ] Test rate limit headers
- [ ] Test 429 response
