## Technical Details

### Suggestion Rules

| Trigger | Suggestion | Priority |
|---------|------------|----------|
| Low referring domain count | "Build more referring domains. Guest posting and content marketing can help." | High |
| High exact-match anchor % | "Diversify anchor text. Too many exact-match anchors can appear manipulative." | High |
| Low domain trust average | "Focus on earning links from higher-authority sites in your niche." | Medium |
| Declining backlink count | "Check for lost backlinks. Some may be recoverable with outreach." | Medium |
| Homepage-only links | "Create link-worthy content beyond your homepage to diversify link targets." | Low |
| High nofollow ratio | "More dofollow links would improve your link equity." | Low |

### Service Implementation
```php
class BacklinkSuggestionService
{
    /**
     * Generate suggestions for a project
     */
    public function generate(Project $project): array
    {
        $metrics = $this->getMetrics($project);
        $suggestions = [];
        
        if ($this->needsMoreDomains($metrics)) {
            $suggestions[] = $this->createSuggestion(
                'low_domains',
                'Build more referring domains. Guest posting and content marketing can help.',
                'high',
                $metrics
            );
        }
        
        if ($this->hasHighExactMatchAnchors($metrics)) {
            $suggestions[] = $this->createSuggestion(
                'high_exact_match',
                'Diversify anchor text. Too many exact-match anchors can appear manipulative.',
                'high',
                $metrics
            );
        }
        
        // ... more rules
        
        return $this->prioritize($suggestions);
    }
}
```
