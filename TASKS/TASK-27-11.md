# TASK-27-11: Health Check Service

## STATUS
`To Write Tests`

## Parent Specification
SPEC-027: Admin Dashboard (Ops + Usage)

## Description
Create service for checking system health status. Monitors database, cache, storage, and external service availability.

## Acceptance Criteria
- [ ] Service class created at `app/Services/Admin/HealthCheckService.php`
- [ ] Health checks for:
  - Database connectivity and latency
  - Cache (Redis) connectivity and hit rate
  - Storage availability and disk usage
  - Queue worker status
- [ ] Each check returns: status (healthy/degraded/unhealthy), message, metrics
- [ ] Overall health status computed from individual checks
- [ ] Results cached briefly (30 seconds) to prevent overwhelming checks
- [ ] Configurable thresholds for degraded/unhealthy states
- [ ] Unit tests for all health check methods

## Dependencies
- None (standalone infrastructure)

## Effort Estimate
`Medium` (2-4 hours)

## Technical Notes
- Use try-catch for each check to prevent cascade failures
- Database: simple SELECT 1 query
- Cache: SET/GET test key
- Storage: disk_free_space() and disk_total_space()
- Consider adding external API health checks (OpenRouter, etc.)

## Response Format
```json
{

  "uptime": 99.98,

      "status": "healthy",

    }
  }
}
```
