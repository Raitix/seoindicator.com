## Description
Add rate limiting middleware to deploy endpoints (`/deploy/migrate`, `/deploy/rollback`) and implement logging for failed authentication attempts. This protects against brute force attacks on sensitive deployment endpoints.

## Acceptance Criteria
- [ ] Define a custom rate limiter for deploy endpoints in `AppServiceProvider` or `RouteServiceProvider`
- [ ] Apply `throttle:deploy` middleware (or `throttle:5,15`) to deploy routes
- [ ] Configure rate limit: max 5 requests per 15 minutes per IP
- [ ] Add logging in `DeployController` for failed authentication attempts
- [ ] Log format includes: IP address, user-agent, timestamp, endpoint
- [ ] Write unit tests for rate limiting behavior
- [ ] Write unit tests for logging behavior
- [ ] Verify legitimate deploys still work after implementation

## Technical Notes
```php
// In AppServiceProvider::boot()
RateLimiter::for('deploy', function (Request $request) {
    return Limit::perMinutes(15, 5)->by($request->ip());
});
```

```php
// In DeployController, log failed auth
Log::warning('Deploy auth failed', [
    'ip' => $request->ip(),
    'user_agent' => $request->userAgent(),
    'endpoint' => $request->path(),
    'timestamp' => now()->toIso8601String(),
]);
```
