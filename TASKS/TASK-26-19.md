## Description
Create database migration and API endpoints for users to set their preferred/default AI model for analyses.

## Acceptance Criteria

### user_model_preferences Table
- [ ] `id` - BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
- [ ] `user_id` - BIGINT UNSIGNED NOT NULL with FK to users (ON DELETE CASCADE)
- [ ] `model_id` - BIGINT UNSIGNED NOT NULL with FK to ai_models (ON DELETE CASCADE)
- [ ] `is_default` - TINYINT(1) DEFAULT 0
- [ ] `created_at` and `updated_at` timestamps
- [ ] UNIQUE constraint on `(user_id, model_id)`

### UserModelPreference Model
- [ ] `app/Models/UserModelPreference.php` created
- [ ] BelongsTo relationships to User and AIModel
- [ ] Scope for default preferences

### Endpoints

#### Set Default Model
- [ ] `POST /api/v1/models/preferences`
- [ ] Authentication required
- [ ] Sets user's default model

#### Get User Preferences
- [ ] `GET /api/v1/models/preferences`
- [ ] Authentication required
- [ ] Returns user's saved preferences

### Request Body (Set Default)
```json
{
  "model_id": 5,
  "is_default": true
}
```

### Response Format
```json
{
  "success": true,
  "data": {
    "default_model": {
      "id": 5,
      "display_name": "GPT-4 Turbo",
      "provider": "openrouter"
    }
  }
}
```

### Controller Implementation
- [ ] `preferences()` method in ModelController (GET)
- [ ] `setPreference()` method in ModelController (POST)
- [ ] Only one model can be default per user
- [ ] Setting new default unsets previous default

### Business Logic
- [ ] User can have multiple saved preferences
- [ ] Only one can be `is_default`
- [ ] Validate model is active before setting
- [ ] Create or update preference record

### Validation Rules
- [ ] `model_id` must exist in ai_models table
- [ ] `model_id` must reference active model
- [ ] `is_default` must be boolean

### Feature Tests
- [ ] Test set default model
- [ ] Test get preferences
- [ ] Test only one default allowed
- [ ] Test cannot set inactive model
- [ ] Test unauthenticated returns 401

## Dependencies
- TASK-26-4 (ai_models table)
- TASK-26-16 (ModelPricingService)

## Effort Estimate
`Small` (2-3 hours)

## Notes
- Preferences are per-user, not global
- Default model used automatically in analysis
- User can override default per-analysis

## Security Considerations

- Validate model exists and is active
- Log preference changes for audit
