## Description
Create end-to-end integration tests that validate the complete authentication and navigation flow from user perspective.

## Test Scenarios

### Complete Auth Flow
1. Guest visits protected route → Redirected to login
2. Guest logs in → Redirected to intended destination
3. User navigates to other protected routes → Works
4. User logs out → Redirected to login, protected routes blocked

### Token Expiry Flow
1. User authenticated, token expires
2. User makes API call → Gets 401
3. Application clears session → Redirects to login
4. User logs in again → Works normally

### Navigation Flow
1. Guest sees only public nav items
2. Guest clicks Sign In → Login page
3. After login, protected nav items appear
4. User can navigate to all protected areas

### Error Recovery Flow
1. Network error during auth
2. Application shows retry option
3. User retries → Success
