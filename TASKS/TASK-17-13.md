## Description
Implement comprehensive analytics event tracking for the onboarding flow. This provides data for measuring completion rates, identifying drop-off points, and optimizing the user experience.

## Acceptance Criteria
- [ ] Track event: `onboarding_started`
  - [ ] Properties: user_id, timestamp
- [ ] Track event: `onboarding_step_completed`
  - [ ] Properties: user_id, step_number, timestamp, duration_on_step
- [ ] Track event: `onboarding_step_skipped`
  - [ ] Properties: user_id, step_number, timestamp
- [ ] Track event: `onboarding_skipped`
  - [ ] Properties: user_id, step_number, timestamp
- [ ] Track event: `onboarding_completed`
  - [ ] Properties: user_id, duration_seconds, timestamp, steps_completed
- [ ] Track event: `onboarding_resumed`
  - [ ] Properties: user_id, current_step, timestamp
- [ ] Events stored in database (analytics_events table or similar)
- [ ] Events can be queried for reporting
- [ ] No performance impact on onboarding flow
- [ ] Events respect user privacy settings (if applicable)

## Effort Estimate
`S` (4-6 hours)

## Technical Details

### Event Structure
```typescript
interface AnalyticsEvent {
  event_name: string;
  user_id: number;
  properties: Record<string, any>;
  timestamp: Date;
  session_id: string;
}
```

### Tracking Implementation
```typescript
// Frontend tracking utility
const trackOnboardingEvent = (eventName: string, properties: Record<string, any>) => {
  // Option 1: Send to backend
  fetch('/api/v1/analytics/events', {
    method: 'POST',
    body: JSON.stringify({
      event_name: eventName,
      properties,
      timestamp: new Date().toISOString()
    })
  });
  
  // Option 2: Use existing analytics service (e.g., Plausible, PostHog)
};
```

### Events to Track
| Event | When | Properties |
|-------|------|------------|
| `onboarding_started` | Modal opens | user_id |
| `onboarding_step_completed` | User clicks Continue | step_number, duration_ms |
| `onboarding_step_skipped` | User skips a step | step_number |
| `onboarding_skipped` | User skips entire flow | step_number |
| `onboarding_completed` | User finishes step 5 | duration_seconds, steps_completed |
| `onboarding_resumed` | User reopens from banner | current_step |
