### Sync Endpoint
```
POST /api/v1/projects/{projectId}/backlinks/sync
```

**Response:**
```json
{
  "success": true,
  "data": {
    "job_id": "backlink-sync-abc123",
    "status": "queued",
    "estimated_duration": "2-5 minutes"
  }
}
```

### Rate Limiting
- Max 1 sync request per project per hour
- Returns 429 if rate limit exceeded

### Controller Implementation
```php
public function history(Request $request, Project $project): JsonResponse
{
    $this->authorize('view', $project);
    
    $from = $request->get('from', now()->subDays(30)->toDateString());
    $to = $request->get('to', now()->toDateString());
    
    $snapshots = $this->snapshotService->getHistory(
        $project->id,
        $from,
        $to
    );
    
    return response()->json([
        'data' => $snapshots,
    ]);
}

public function sync(Project $project): JsonResponse
{
    $this->authorize('update', $project);
    
    $job = SyncBacklinksJob::dispatch($project->id);
    
    return response()->json([
        'success' => true,
        'data' => [
            'job_id' => $job->id,
            'status' => 'queued',
        ],
    ]);
}
```
