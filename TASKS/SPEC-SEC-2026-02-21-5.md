# TASK: Purge Secrets from Git History and Verify Repository Clean

## STATUS
`To Prioritize`

## PRIORITY
`High`

## RISK

## Specification
SPEC-SPEC-SEC-2026-02-21 (Task 5 of 5)

## Description
Remove all traces of secrets from git history using `git filter-repo` or BFG Repo-Cleaner. Force-push the cleaned history. Verify no secrets remain in any commit.

## Acceptance Criteria
- [ ] Identify all commits containing secrets using `git log -p` or `git secrets --scan-history`
- [ ] Install `git filter-repo` (preferred) or BFG Repo-Cleaner
- [ ] Create a backup of the repository before rewriting history
- [ ] Run `git filter-repo` to remove secret-containing files or patterns
- [ ] Force-push to remote repository (requires coordination with owner)
- [ ] Verify secrets are no longer in git history: `git log -p | grep -i "secret_pattern"`
- [ ] Notify all collaborators to re-clone the repository
- [ ] Document the history rewrite and provide reset instructions
- [ ] Add `git-secrets` or similar tool to prevent future commits of secrets

## Dependencies
- SPEC-SEC-2026-02-21-1 (secrets must be removed from current files first)
- SPEC-SEC-2026-02-21-2 (GitHub Secrets must be configured before force-push)

## Effort Estimate
`High` — Requires careful execution and coordination

## Files Affected

- `.git/config` (potential git-secrets hooks)
- Repository backup

## Risks
- **Git history rewrite disrupts all collaborators** — must coordinate
- **Force-push can cause merge conflicts** — provide reset instructions
- **Incomplete purge leaves secrets exposed** — thorough verification required

## Technical Notes
```bash
# Using git filter-repo to remove secrets
pip install git-filter-repo

# Remove specific file from history
git filter-repo --path backend/.env --invert-paths

# Or use BFG to remove sensitive data
bfg --delete-files .env
git reflog expire --expire=now --all && git gc --prune=now --aggressive
```
