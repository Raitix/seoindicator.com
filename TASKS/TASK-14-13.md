### API Endpoints

#### 1. Trigger New Audit
```
POST /api/v1/sites/{siteId}/audits
```

**Request:**
```json
{
    "max_pages": 100,      // Optional, default from config
    "max_depth": 3,        // Optional, default from config
    "user_agent": "custom" // Optional, default from config
}
```

**Response (201):**
```json
{
    "id": 123,
    "site_id": 1,
    "status": "pending",
    "max_pages": 100,
    "max_depth": 3,
    "created_at": "2026-03-06T15:00:00Z"
}
```

#### 2. Get Audit Status
```
GET /api/v1/audits/{auditId}
```

**Response (200):**
```json
{
    "id": 123,
    "site_id": 1,
    "status": "running",
    "pages_crawled": 45,
    "issues_found": 12,
    "progress": {
        "current_url": "https://example.com/about",
        "elapsed_seconds": 120
    },
    "started_at": "2026-03-06T15:00:00Z",
    "estimated_completion": "2026-03-06T15:10:00Z"
}
```

#### 3. List Audits for Site
```
GET /api/v1/sites/{siteId}/audits
```

**Query Parameters:**
- `status` - Filter by status (pending, running, completed, failed)
- `per_page` - Items per page (default: 15)
- `page` - Page number

**Response (200):**
```json
{
    "data": [
        {
            "id": 123,
            "status": "completed",
            "pages_crawled": 100,
            "issues_found": 25,
            "completed_at": "2026-03-06T15:10:00Z"
        }
    ],
    "meta": {
        "current_page": 1,
        "per_page": 15,
        "total": 5
    }
}
```

#### 4. Cancel Running Audit
```
DELETE /api/v1/audits/{auditId}
```

**Response (200):**
```json
{
    "id": 123,
    "status": "cancelled"
}
```

### Request Validation

```php
class StoreAuditRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'max_pages' => ['nullable', 'integer', 'min:1', 'max:10000'],
            'max_depth' => ['nullable', 'integer', 'min:1', 'max:10'],
            'user_agent' => ['nullable', 'string', 'max:255'],
        ];
    }
}
```

### Authorization
- User must own the site (via SiteUser pivot)
- Only one running audit per site at a time

### Rate Limiting
```php
// Limit audit triggers
RateLimiter::for('audit-trigger', function (Request $request) {
    return Limit::perHour(5)->by($request->user()->id);
});
```
