### API Endpoints

#### 1. List Issues for Audit
```
GET /api/v1/audits/{auditId}/issues
```

**Query Parameters:**
- `severity` - Filter by severity (critical, warning, notice)
- `status` - Filter by status (open, fixed, ignored)
- `category` - Filter by issue category
- `search` - Search in URL or description
- `sort_by` - Sort field (created_at, severity, url)
- `sort_order` - Sort direction (asc, desc)
- `per_page` - Items per page (default: 25)
- `page` - Page number

**Response (200):**
```json
{
    "data": [
        {
            "id": 1,
            "url": "https://example.com/page",
            "issue_type": {
                "id": 1,
                "name": "Missing title tag",
                "category": "meta"
            },
            "severity": "critical",
            "description": "This page is missing a title tag",
            "recommendation": "Add a unique, descriptive title tag to this page.",
            "status": "open",
            "created_at": "2026-03-06T15:05:00Z"
        }
    ],
    "meta": {
        "current_page": 1,
        "per_page": 25,
        "total": 50,
        "severity_counts": {
            "critical": 10,
            "warning": 25,
            "notice": 15
        },
        "status_counts": {
            "open": 45,
            "fixed": 3,
            "ignored": 2
        }
    }
}
```

#### 2. Get Single Issue
```
GET /api/v1/issues/{issueId}
```

**Response (200):**
```json
{
    "id": 1,
    "url": "https://example.com/page",
    "issue_type": {
        "id": 1,
        "name": "Missing title tag",
        "category": "meta",
        "category_label": "Meta Tags"
    },
    "severity": "critical",
    "description": "This page is missing a title tag",
    "recommendation": "Add a unique, descriptive title tag to this page.",
    "status": "open",
    "created_at": "2026-03-06T15:05:00Z",
    "audit": {
        "id": 123,
        "status": "completed",
        "pages_crawled": 100
    }
}
```

#### 3. Update Issue Status
```
PATCH /api/v1/issues/{issueId}
```

**Request:**
```json
{
    "status": "fixed"
}
```

**Response (200):**
```json
{
    "id": 1,
    "status": "fixed",
    "updated_at": "2026-03-06T16:00:00Z"
}
```

#### 4. Bulk Update Issues
```
PATCH /api/v1/audits/{auditId}/issues/bulk
```

**Request:**
```json
{
    "issue_ids": [1, 2, 3, 4, 5],
    "status": "ignored"
}
```

**Response (200):**
```json
{
    "updated_count": 5,
    "message": "5 issues marked as ignored"
}
```

### Request Validation
```php
class UpdateIssueStatusRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'status' => ['required', 'in:open,fixed,ignored'],
        ];
    }
}

class BulkUpdateIssuesRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'issue_ids' => ['required', 'array', 'max:100'],
            'issue_ids.*' => ['integer', 'exists:audit_issues,id'],
            'status' => ['required', 'in:open,fixed,ignored'],
        ];
    }
}
```

### Authorization
- User must own the site associated with the audit
- Issues can only be updated for completed audits
