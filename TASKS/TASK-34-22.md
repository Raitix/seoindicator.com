## Acceptance Criteria

- [ ] `AIVisibilityExportService` created at `app/Services/AIVisibility/`

- [ ] `exportToCsv()` method implemented
  - [ ] Accepts: `projectId`, `options` (date range, platforms, etc.)
  - [ ] Exports query results with columns:
    - Date
    - Platform
    - Query Text
    - Brand Mentioned
    - Sentiment
    - Competitor Mentions
  - [ ] Returns file path or stream
  - [ ] Handles large datasets (chunked processing)

- [ ] `exportToJson()` method implemented
  - [ ] Same parameters as CSV
  - [ ] Returns structured JSON with:
    - Project metadata
    - Analytics summary
    - Query results array
    - Competitor comparison data

- [ ] `exportAnalyticsReport()` method implemented
  - [ ] Generates comprehensive PDF/HTML report

    - Executive summary

    - Top queries and categories
    - Recommendations
  - [ ] Uses existing PDF infrastructure from FEAT-029

- [ ] API endpoint `GET /api/v1/ai-visibility/projects/{id}/export`
  - [ ] Query parameters:
    - `format`: csv, json (default: csv)
    - `start_date`: filter start (optional)
    - `end_date`: filter end (optional)

  - [ ] Returns file download with proper headers
  - [ ] Rate limited: 5 per hour
  - [ ] Authorization: user must own project

- [ ] Frontend export components

  - [ ] Export modal with options:

  - [ ] Download progress indicator

- [ ] File handling

  - [ ] Temp file cleanup after download

- [ ] Performance
  - [ ] Chunked processing for large exports
  - [ ] Background job for large files (>10k records)
  - [ ] Email notification when large export ready

- [ ] Security
  - [ ] Validate date ranges (max 1 year)
  - [ ] Rate limit enforcement
  - [ ] Audit log for exports

- [ ] Unit tests created
  - [ ] Test CSV generation
  - [ ] Test JSON generation
  - [ ] Test large dataset handling
  - [ ] Test API endpoint
