#### BUG 2: XlsxExporter DateTime/Object Casting Error (CRITICAL)

**File:** `app/Services/AIVisibility/XlsxExporter.php` (line 228)
**Severity:** Critical - Runtime error

**Issue:** The `setCellValue()` method casts values to string BEFORE checking for DateTime/array types:

```php
// CURRENT (BUGGY):
$stringValue = (string) $value;  // <-- Fails for DateTime and Array!
if (in_array(substr($stringValue, 0, 1), ['=', '+', '-', '@', "\t", "\r"])) {
    // Formula injection check
}
if (is_bool($value)) { ... }
elseif ($value instanceof \DateTimeInterface) { ... }  // <-- Never reached!
```

**Error:**
```
Object of class DateTime could not be converted to string
Array to string conversion
```

**Fix Required:** Reorder the type checks to handle DateTime/array BEFORE casting to string:

```php
// CORRECT ORDER:
protected function setCellValue($sheet, int $col, int $row, mixed $value): void
{
    $cellCoordinate = [$col, $row];

    if ($value === null) {
        $sheet->setCellValue($cellCoordinate, '');
        return;
    }

    // Handle DateTime BEFORE string cast
    if ($value instanceof \DateTimeInterface) {
        $sheet->setCellValue($cellCoordinate, $value->format('Y-m-d H:i:s'));
        return;
    }

    // Handle array/object BEFORE string cast
    if (is_array($value) || (is_object($value) && !method_exists($value, '__toString'))) {
        $sheet->setCellValue($cellCoordinate, json_encode($value, JSON_UNESCAPED_UNICODE));
        return;
    }

    if (is_bool($value)) {
        $sheet->setCellValue($cellCoordinate, $value ? 'Yes' : 'No');
        return;
    }

    if (is_int($value) || is_float($value)) {
        $sheet->setCellValue($cellCoordinate, $value);
        return;
    }

    // Now safe to cast to string
    $stringValue = (string) $value;
    
    // Check for formula injection
    if (in_array(substr($stringValue, 0, 1), ['=', '+', '-', '@', "\t", "\r"])) {
        $sheet->setCellValueExplicit($cellCoordinate, "'" . $stringValue, DataType::TYPE_STRING);
        return;
    }

    $sheet->setCellValue($cellCoordinate, $stringValue);
}
```
