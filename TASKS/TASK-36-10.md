## Technical Notes
### API Response Examples

**GET /summary:**
```json
{
    "success": true,
    "data": {
        "total_candidates": 23,
        "critical_count": 5,
        "high_count": 8,
        "medium_count": 10,
        "estimated_lost_clicks": 3420,
        "recovery_upside": 2750,
        "recovered_count": 12,
        "last_scanned_at": "2026-03-10T08:00:00Z"
    }
}
```

**GET /candidates:**
```json
{
    "success": true,
    "data": [...],
    "meta": {
        "current_page": 1,
        "total": 23,
        "per_page": 15
    },
    "filters": {
        "status": null,
        "severity": null,
        "min_score": null
    }
}
```

### Queue Filters
- `status` - Filter by candidate status
- `severity` - Filter by severity level
- `page_type` - Filter by page type
- `reason_code` - Filter by reason code
- `min_lost_clicks` - Minimum lost clicks threshold
- `search` - Search in page URL/title
- `sort` - Sort by decay_score, recovery_upside, lost_clicks, last_detected
- `order` - asc/desc
