# TASK-33-19: Implement Badge Auto-Refresh Mechanism

## STATUS
`To Write Tests`

## PRIORITY
`Low`

## RISK
`Low`

## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Implement the auto-refresh mechanism in badge.js that updates badges when audit scores change. This ensures embedded badges stay current.

## Acceptance Criteria
- [ ] Badge checks for score update on load
- [ ] Background refresh every 24 hours (configurable)
- [ ] Uses localStorage to track last check time
- [ ] Graceful degradation if localStorage unavailable
- [ ] Only refreshes if score has changed
- [ ] Smooth transition when score updates
- [ ] Respects reduced motion preferences
- [ ] Unit tests for refresh logic

## Dependencies
- TASK-33-16 (badge.js script)
- TASK-33-5 (badge config endpoint with last_updated timestamp)

## Effort Estimate
**2 hours** - JavaScript refresh logic

## Technical Notes
- Store in localStorage: `seoindicator_{hash}_lastCheck`
- Compare last_updated timestamp from API
- Use requestIdleCallback for non-blocking refresh
- Animate score change with CSS transitions

## Storage Schema
```javascript
localStorage.setItem(`seoindicator_${hash}_lastCheck`, Date.now());
localStorage.setItem(`seoindicator_${hash}_lastScore`, 85);
```

## Files to Modify
- `frontend/src/scripts/badge.ts` (add refresh logic)
- `frontend/__tests__/scripts/badge.test.ts`
