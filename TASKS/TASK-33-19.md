- [x] Only refreshes if score has changed
- [x] Smooth transition when score updates
- [x] Respects reduced motion preferences
- [x] Unit tests for refresh logic ✅ (44 tests written)

- Use requestIdleCallback for non-blocking refresh

**Implementation Summary:**

Modified `frontend/lib/scripts/badge.ts` with the following additions:

1. **localStorage Utilities** (new functions):
   - `isLocalStorageAvailable()` - Checks if localStorage is available
   - `storeLastCheckTime(auditId)` - Stores last check timestamp
   - `storeLastScore(auditId, score)` - Stores last known score
   - `getLastCheckTime(auditId)` - Retrieves last check timestamp
   - `getLastScore(auditId)` - Retrieves last known score
   - `shouldRefresh(auditId, interval)` - Checks if enough time has passed
   - `hasScoreChanged(auditId, newScore)` - Compares scores
   - `prefersReducedMotion()` - Checks user motion preference

2. **Enhanced `setupAutoRefresh()`**:
   - Stores check time in localStorage on setup
   - Re-validates refresh timing on timer fire
   - Handles page visibility/sleep scenarios

3. **Enhanced `loadBadge()`**:
   - Tracks previous score for animation
   - Stores score and check time after successful load
   - Only animates if score changed and motion not reduced

4. **Enhanced `renderBadge()`**:
   - Accepts optional `previousScore` parameter
   - Applies CSS transitions for smooth score updates
   - Respects `prefers-reduced-motion` media query
   - Uses `requestAnimationFrame` for smooth animation

**Storage Schema Implemented:**
