- [ ] Uses localStorage to track last check time
- [ ] Graceful degradation if localStorage unavailable
- [ ] Only refreshes if score has changed
- [ ] Smooth transition when score updates
- [ ] Respects reduced motion preferences
- [ ] Unit tests for refresh logic

- Compare last_updated timestamp from API
- Use requestIdleCallback for non-blocking refresh
