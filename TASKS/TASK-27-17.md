# TASK-27-17: System Health Monitoring Panel

## STATUS
`To Test Locally`

## PRIORITY
`Medium`

## RISK
`Low`

## Parent Specification
SPEC-027: Admin Dashboard (Ops + Usage)

## Description
Create the system health monitoring panel for the admin dashboard. Displays service status, queue metrics, and active alerts.

## Acceptance Criteria
- [ ] Health page at `/admin/health`
- [ ] Service status indicators (database, cache, storage, queue):
  - Green checkmark = healthy
  - Yellow warning = degraded
  - Red X = unhealthy
- [ ] Queue status panel:
  - Pending jobs count
  - Failed jobs count
  - Active workers count
- [ ] Database metrics panel:
  - Connection count
  - Query latency
  - Table sizes (optional)
- [ ] Active alerts panel:
  - Alert message
  - Time since alert
  - Severity indicator
- [ ] Auto-refresh every 30 seconds
- [ ] Manual refresh button
- [ ] Unit tests for all components

## Dependencies
- TASK-27-14 (Admin Dashboard Layout)
- TASK-27-13 (Health API endpoints)

## Effort Estimate
`Medium` (2-4 hours)

## Technical Notes
- Use polling for updates (consider WebSocket in future)
- Add sound/notification for new alerts (optional)
- Color coding should match overall design system
- Consider adding alert acknowledgment functionality
