## Description

## Acceptance Criteria
- [ ] Rankings page at /locations/{id}/rankings
- [ ] Quota indicator:
  - Shows checks used / checks available
  - Visual progress bar
  - Resets monthly
- [ ] Keywords table:
  - Columns: keyword, local pack position, organic position, change, last checked
  - Color-coded positions (green = in pack, yellow = close, red = not found)
  - Position change indicators (up/down arrows)
  - Sortable columns
- [ ] Ranking history chart:
  - Line chart for selected keyword
  - Shows position over time
  - Toggle for pack vs organic
- [ ] Check ranking button:
  - Triggers ranking check
  - Shows loading state
  - Respects quota limits
  - Error message if quota exceeded
- [ ] Competitor comparison:
  - Side-by-side comparison cards
  - Shows competitor position, rating, review count
  - "Add competitor" button
- [ ] Position change alerts:
  - Highlights keywords with significant changes
  - Links to alert details
- [ ] Local pack visualization:
  - Shows current pack positions (1-3)
  - Indicates if location is in pack
  - Shows competitors in pack
- [ ] Export functionality:
  - Export to CSV/Excel
- [ ] Loading states
- [ ] Component tests
