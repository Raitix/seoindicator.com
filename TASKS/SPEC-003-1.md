## Description
Create database migrations for `competitors` and `competitor_rankings` tables. This is the foundation for the competitor rank comparison feature.

## Acceptance Criteria
- [ ] Migration creates `competitors` table with: id, user_id, domain, display_name, notes, created_at, updated_at
- [ ] Migration creates `competitor_rankings` table with: id, competitor_id, keyword_id, position, url, checked_at
- [ ] Foreign key constraints: competitors.user_id → users.id, competitor_rankings.competitor_id → competitors.id, competitor_rankings.keyword_id → keywords.id
- [ ] Unique constraint on (user_id, domain) in competitors table
- [ ] Unique constraint on (competitor_id, keyword_id, checked_at) in competitor_rankings table
- [ ] Indexes on: competitors.user_id, competitors.domain, competitor_rankings.competitor_id, competitor_rankings.keyword_id, competitor_rankings.checked_at
- [ ] Migration is reversible (down method drops tables)
- [ ] Migration runs successfully on local MySQL
