## Description

## Acceptance Criteria

- [ ] `app/Services/Gateway/PayPalGatewayService.php` created
- [ ] Implements `PaymentGatewayInterface`

- [ ] `createPaymentIntent(User $user, float $amount, string $currency = 'USD'): array`
- [ ] `capturePayment(string $orderId): bool`
- [ ] `refundPayment(string $captureId, float $amount = null): array`
