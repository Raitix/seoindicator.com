## Description
Implement the PayPal payment gateway service as an alternative to Stripe for credit purchases.

## Acceptance Criteria

### PayPalGatewayService Implementation
- [ ] `app/Services/Gateway/PayPalGatewayService.php` created
- [ ] Implements `PaymentGatewayInterface`
- [ ] Uses PayPal PHP SDK (`paypal/rest-api-sdk-php`)

### PaymentGatewayInterface Methods
- [ ] `createPaymentIntent(User $user, float $amount, string $currency = 'USD'): array`
- [ ] `capturePayment(string $orderId): bool`
- [ ] `refundPayment(string $captureId, float $amount = null): array`
- [ ] `handleWebhook(Request $request): PaymentResult`
- [ ] `getCustomer(User $user): ?string`
- [ ] `createCustomer(User $user): string`

### Order Creation (PayPal uses Orders API)
- [ ] Create PayPal order with correct amount
- [ ] Set return and cancel URLs
- [ ] Include custom_id for tracking (user_id, package_id)
- [ ] Return order ID for frontend

### Order Capture
- [ ] Capture approved order
- [ ] Verify amount matches original
- [ ] Return success/failure status

### Webhook Handler
- [ ] Verify webhook signature using PayPal headers
- [ ] Handle `CHECKOUT.ORDER.APPROVED` event
- [ ] Handle `PAYMENT.CAPTURE.COMPLETED` event
- [ ] Handle `PAYMENT.CAPTURE.DENIED` event
- [ ] Handle `PAYMENT.CAPTURE.REFUNDED` event

### Customer Management
- [ ] PayPal doesn't require customer creation
- [ ] Use payer_id from approved order

### Error Handling
- [ ] Custom exception: `PayPalPaymentException`
- [ ] Log all PayPal API errors
- [ ] Graceful handling of network timeouts

### Unit Tests
- [ ] Mock PayPal SDK for unit testing
- [ ] Test order creation
- [ ] Test order capture
- [ ] Test webhook signature verification
- [ ] Test refund flow
- [ ] Test error scenarios

## Dependencies

## Effort Estimate
`Large` (5-6 hours)

## Notes
- PayPal uses Orders API v2 (not classic Payments API)
- Sandbox mode for development
- PayPal has longer webhook processing times
- Consider PayPal's fees in pricing

## Security Considerations
- Verify webhook signatures
- Validate order amounts server-side
- Use idempotency for captures
- Log all payment events
