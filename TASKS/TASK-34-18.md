**Design Issue Identified:**

The tests expect `AIMentionAnalytics` to be a **per-mention tracking table**:

```php
// Tests create records like this:
AIMentionAnalytics::create([
    'project_id' => $this->project->id,
    'entity_type' => 'brand',        // ← Does NOT exist
    'entity_name' => 'SEOIndicator', // ← Does NOT exist
    'mention_type' => 'neutral',     // ← Does NOT exist
    'sentiment' => 'positive',       // ← Does NOT exist
    'context' => '...',              // ← Does NOT exist
    'mentioned_at' => now(),         // ← Does NOT exist
]);
```

But the current model is an **aggregation table**:

```php
// Current model has these fields:
'platform' => 'chatgpt',
'period' => 'week',
'total_queries' => 100,
'brand_mentions' => 50,
'mention_rate' => 50.00,
// ... etc
```

**Resolution Options:**

| Option | Effort | Recommendation |
|--------|--------|----------------|
| Create `AIMention` model for per-mention tracking | Medium | ✅ **Recommended** |
| Rewrite tests to use aggregation model | Medium | ⚠️ Loses per-mention test coverage |
| Add per-mention fields to `AIMentionAnalytics` | Low | ❌ Violates single responsibility |

**Recommended Next Steps:**

1. PreTester: Create migration for `ai_mentions` table
2. PreTester: Update tests to use new model
3. Developer: Create `AIMention` model
4. Developer: Update `RunQueryJob` to create per-mention records
