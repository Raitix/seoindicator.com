# TASK-27-12: Queue Monitoring Integration

## STATUS
`To Prioritize`

## PRIORITY
`Medium`

## RISK
`Low`

## Parent Specification
SPEC-027: Admin Dashboard (Ops + Usage)

## Description
Integrate with existing job queue system (FEAT-019) to provide queue monitoring. Reports pending jobs, failed jobs, and worker status.

## Acceptance Criteria
- [ ] Service methods for:
  - Pending jobs count by queue
  - Failed jobs count (last 24 hours)
  - Active workers count
  - Average job processing time
- [ ] Integrates with existing queues table from FEAT-019
- [ ] Integrates with Laravel Horizon if available (optional)
- [ ] Results exposed via HealthCheckService
- [ ] Alert thresholds configurable (pending > X, failed > Y)
- [ ] Unit tests verify queue status retrieval
- [ ] Graceful handling if queue system unavailable

## Dependencies
- FEAT-019 (Job Queue system)
- TASK-27-11 (HealthCheckService)

## Effort Estimate
`Small` (1-2 hours)

## Technical Notes
- Query queues table for pending/failed counts
- Consider using Laravel Queue::size() for real-time counts
- Worker status may require process monitoring
- Add to health check response under "services.queue"

## Response Format
```json
{
  "queue": {
    "status": "healthy",
    "pending": 23,
    "failed": 2,
    "workers": 5,
    "avgProcessingTimeMs": 150
  }
}
```
