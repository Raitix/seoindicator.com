## Description
Implement analytics aggregation for public audits, including views, leads, and geographic breakdown. This powers the analytics dashboard.

## Acceptance Criteria
- [ ] Service aggregates views per audit per day
- [ ] Service aggregates leads captured per audit
- [ ] Service aggregates badge impressions/clicks
- [ ] Geographic breakdown by country code
- [ ] Referrer domain breakdown
- [ ] API endpoint: GET `/api/v1/audits/{id}/analytics`
- [ ] Response includes: views, leads, impressions, clicks
- [ ] Date range filter supported
- [ ] Unit tests for aggregation logic
- [ ] Feature tests for API endpoint

## Dependencies
- TASK-33-2 (public_audit_views table)
- TASK-33-3 (badge_impressions table)

## Effort Estimate
**4 hours** - Aggregation service with API

## Technical Notes
- Use database aggregation queries (SUM, COUNT, GROUP BY)
- Consider caching aggregated results
- Index viewed_at, impression_at for date queries
- Prune old analytics data (90+ days) to save space
