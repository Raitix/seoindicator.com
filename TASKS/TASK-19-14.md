## Acceptance Criteria
- [ ] Job creation rate limits:
  - 10 jobs per user per hour
  - 5 jobs per site per hour
  - 2 concurrent jobs per user
- [ ] API rate limiting:
  - 60 requests per minute per user (authenticated)
  - Polling endpoint: 30 requests per minute per job
- [ ] Rate limit headers in responses:
  - X-RateLimit-Limit
  - X-RateLimit-Remaining
  - X-RateLimit-Reset (timestamp)
- [ ] Rate limit exceeded response:
  - 429 status code
  - JSON body with error message and retry-after

- [ ] Rate limit bypass for admin users (optional)
- [ ] Redis-based rate limiting for distributed systems
- [ ] Feature tests for rate limit behavior
