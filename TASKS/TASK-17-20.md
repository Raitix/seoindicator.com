## Description
Provide AI-powered personalized keyword and feature recommendations during onboarding. This uses machine learning to suggest the most valuable setup based on the user's website and industry.

## Technical Details

### Recommendation Engine
```php
class PersonalizationEngine
{
    public function getRecommendations(string $url, string $industry): array
    {
        $topics = $this->extractTopics($url);
        $opportunities = $this->findOpportunities($topics, $industry);
        
        return [
            'keywords' => $this->rankKeywords($opportunities),
            'features' => $this->recommendFeatures($industry)
        ];
    }
}
```

### Recommendation Structure
```json
{
  "keywords": [
    {
      "keyword": "best seo tools 2026",
      "opportunity_score": 85,
      "reason": "High search volume in your industry with low competition"
    }
  ],
  "features": [
    {
      "feature": "competitor_tracking",
      "priority": "high",
      "reason": "E-commerce sites benefit from price and ranking comparison"
    }
  ]
}
```
