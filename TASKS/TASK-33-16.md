# TASK-33-16: Implement badge.js Embed Script

## STATUS
`To Test Locally`

## PRIORITY
`High`

## RISK
`Low`

## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the JavaScript embed script that third-party sites can include to display interactive badges. This enables the JS embed option for users.

## Acceptance Criteria
- [ ] Script at `/badge.js` served statically
- [ ] Auto-initializes on DOMContentLoaded
- [ ] Finds elements with `data-seoindicator-badge` attribute
- [ ] Fetches badge configuration from API
- [ ] Renders badge in container element
- [ ] Supports size attribute: data-size="small|medium|large"
- [ ] Supports theme attribute: data-theme="light|dark"
- [ ] Auto-refresh every 24 hours (configurable)
- [ ] Click tracking (calls impression/click APIs)
- [ ] UMD build for AMD/CommonJS/browser compatibility
- [ ] Minified < 10KB gzip
- [ ] Unit tests for initialization and rendering

## Dependencies
- TASK-33-5 (badge config endpoint)
- TASK-33-17, TASK-33-18 (tracking APIs)

## Effort Estimate
**6 hours** - JavaScript SDK with tracking

## Technical Notes
- Use TypeScript, compile to UMD
- No external dependencies (vanilla JS)
- Use IntersectionObserver for lazy loading
- Handle CORS properly
- No cookies (privacy-friendly)

## API
```javascript
// Auto-init via data attributes
<div data-seoindicator-badge="abc123" data-size="medium" data-theme="light"></div>
<script src="https://seoindicator.com/badge.js" async></script>

// Manual init (optional)
window.SEOIndicatorBadge.init({
  auditId: 'abc123',
  size: 'medium',
  theme: 'light',
  container: '#badge-container'
});

// Methods
SEOIndicatorBadge.refresh();
SEOIndicatorBadge.setTheme('dark');
```

## Files to Create
- `frontend/public/badge.js` (or built from src)
- `frontend/src/scripts/badge.ts`
- `frontend/__tests__/scripts/badge.test.ts`
