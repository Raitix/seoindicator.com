## Technical Details

### Error Codes
| Code | HTTP Status | Message | User Action |
|------|-------------|---------|-------------|
| INVALID_URL | 400 | Invalid URL format | Fix URL format |
| URL_BLOCKED | 403 | URL not allowed | Try different URL |
| FETCH_FAILED | 502 | Could not fetch page | Check URL or try later |
| TIMEOUT | 504 | Analysis timed out | Try again |
| RATE_LIMITED | 429 | Too many requests | Wait and retry |
| PARSE_ERROR | 500 | Could not parse page | Try different URL |
| TOOL_ERROR | 500 | Analysis failed | Try again later |

### Error Response Format
```json
{
  "success": false,
  "error": {
    "code": "FETCH_FAILED",
    "message": "Could not access the page",
    "details": "The server returned a 403 Forbidden response",
    "suggestion": "The page may be blocking automated access. Try a different URL."
  }
}
```

### Frontend Error Display
```tsx
<ToolError
  code="FETCH_FAILED"
  message="Could not access the page"
  suggestion="Try a different URL or check if the page exists"
  onRetry={() => retryAnalysis()}
/>
```

### Retry Logic
- Automatic retry: 1 time after 1 second for transient failures
- Manual retry: User can click "Try Again" button
- Max retries: 2 automatic retries
