## Description
Create REST API endpoint for listing available AI models with pricing information.

## Acceptance Criteria

### Endpoint
- [x] `GET /api/v1/models`
- [x] Authentication optional (public data)
- [x] Returns paginated list of models

### Query Parameters
- [x] `provider` - Filter by provider (e.g., 'openrouter')
- [x] `free_only` - Filter to free tier models only
- [x] `capability` - Filter by capability (e.g., 'vision')
- [x] `sort` - Sort by 'price', 'name', 'context' (default: 'name')

### Response Format
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "provider": "openrouter",
      "model_id": "openai/gpt-4-turbo",
      "display_name": "GPT-4 Turbo",
      "cost_per_1k_input": 0.00001,
      "cost_per_1k_output": 0.00003,
      "estimated_cost_per_analysis": 0.05,
      "context_window": 128000,
      "is_free_tier": false,
      "capabilities": ["tools", "vision"],
      "is_user_default": true
    }
  ],
  "meta": {
    "total": 25,
    "free_tier_count": 5
  }
}
```

### Controller Implementation
- [x] `app/Http/Controllers/Api/V1/ModelController.php` created
- [x] `index()` method for listing
- [x] Uses ModelPricingService
- [x] Applies filters from query params

### Validation Rules
- [x] `provider` must be valid string if provided
- [x] `free_only` must be boolean if provided
- [x] `capability` must be valid string if provided
- [x] `sort` must be one of: 'price', 'name', 'context'

### Response Includes
- [x] All active models
- [x] Pricing per 1K tokens
- [x] Estimated cost per analysis
- [x] Context window size
- [x] Free tier indicator
- [x] User's default model flag (if authenticated)
