## Description
Create REST API endpoint for listing available AI models with pricing information.

## Acceptance Criteria

### Endpoint
- [ ] `GET /api/v1/models`
- [ ] Authentication optional (public data)
- [ ] Returns paginated list of models

### Query Parameters
- [ ] `provider` - Filter by provider (e.g., 'openrouter')
- [ ] `free_only` - Filter to free tier models only
- [ ] `capability` - Filter by capability (e.g., 'vision')
- [ ] `sort` - Sort by 'price', 'name', 'context' (default: 'name')

### Response Format
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "provider": "openrouter",
      "model_id": "openai/gpt-4-turbo",
      "display_name": "GPT-4 Turbo",
      "cost_per_1k_input": 0.00001,
      "cost_per_1k_output": 0.00003,
      "estimated_cost_per_analysis": 0.05,
      "context_window": 128000,
      "is_free_tier": false,
      "capabilities": ["tools", "vision"],
      "is_user_default": true
    }
  ],
  "meta": {
    "total": 25,
    "free_tier_count": 5
  }
}
```

### Controller Implementation
- [ ] `app/Http/Controllers/Api/V1/ModelController.php` created
- [ ] `index()` method for listing
- [ ] Uses ModelPricingService
- [ ] Applies filters from query params

### Validation Rules
- [ ] `provider` must be valid string if provided
- [ ] `free_only` must be boolean if provided
- [ ] `capability` must be valid string if provided
- [ ] `sort` must be one of: 'price', 'name', 'context'

### Response Includes
- [ ] All active models
- [ ] Pricing per 1K tokens
- [ ] Estimated cost per analysis
- [ ] Context window size
- [ ] Free tier indicator
- [ ] User's default model flag (if authenticated)
