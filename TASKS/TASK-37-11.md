# TASK-37-11: Post-Login Redirect Handling

## STATUS
`To Develop`

## PRIORITY

## RISK

## Specification
SPEC-037

## Description
Implement post-login redirect to return users to their intended destination after successful authentication.

## Problem
1. Users trying to access protected page get redirected to login
2. After login, users always go to dashboard
3. Users lose their place - have to navigate again

## Solution
1. Store redirect target in localStorage or URL param
2. After successful login, redirect to stored destination
3. Fall back to dashboard if no stored destination

## Acceptance Criteria
- [ ] Redirect target stored before login redirect
- [ ] After login, user redirected to stored destination
- [ ] Falls back to /dashboard if no stored destination
- [ ] Stored destination cleared after use
- [ ] Works with both URL param and localStorage storage
- [ ] Unit tests for redirect handling

## Technical Details

### File to Modify
`frontend/lib/contexts/AuthContext.tsx`
`frontend/app/login/page.tsx`

### Code Changes
```typescript
// In login handler
const redirectTarget = localStorage.getItem('seoindicator_redirect');
const urlRedirect = searchParams.get('redirect');
const destination = urlRedirect || redirectTarget || '/dashboard';

// Clear stored redirect
localStorage.removeItem('seoindicator_redirect');

// Redirect to destination
router.push(destination);
```
