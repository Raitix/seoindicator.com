**Implementation Notes for Developer:**

1. **Number Formatting:**
   - Use `Intl.NumberFormat` for localization
   - K/M suffix for large numbers (1.23K, 1.23M)
   - Currency: `$` prefix, 2 decimal places
   - Percent: `%` suffix

2. **Trend Indicators:**
   - Positive: Green arrow up (↑), "+X%"
   - Negative: Red arrow down (↓), "-X%"
   - Zero/Null: Neutral dash (−), no indicator

3. **Health Status Colors:**
   - Healthy: Green (`bg-green-100 text-green-800`)
   - Degraded: Yellow (`bg-yellow-100 text-yellow-800`)
   - Unhealthy: Red (`bg-red-100 text-red-800`)

4. **Auto-Refresh:**
   - Default: 30 seconds (configurable)
   - Show countdown timer
   - Cancel on unmount

5. **Loading State:**
   - Skeleton with pulse animation
   - `role="status"` and `aria-live="polite"`
   - No layout shift

6. **Error State:**
   - Error message with retry button
   - `role="alert"`
   - Preserve partial data if available

7. **Navigation:**
   - Cards link to detail pages via Next.js `Link`
   - Keyboard accessible (Enter/Space)
