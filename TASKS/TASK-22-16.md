## Description
Integrate the CrawlWorker with the existing JobQueue system (from TASK-1-10) for unified job management and monitoring.

## Acceptance Criteria

### Queue Configuration
- [x] Add 'crawler' queue to queue connections
- [x] Configure in `config/queue.php`
- [x] Use same driver as existing JobQueue (database/redis)
- [x] Set queue priority (default: normal)

### Queue Connection
```php
// config/queue.php
'connections' => [
    'crawler' => [
        'driver' => 'database',
        'table' => 'jobs',
        'queue' => 'crawler',
        'retry_after' => 300,
        'after_commit' => true,
    ],
],
```

### Job Dispatching
- [x] Dispatch CrawlWorker to 'crawler' queue
- [x] Set job priority based on user tier (optional)
- [x] Support delay parameter (schedule for later)
- [x] Include job metadata in payload

### Job Status Integration
- [x] Update existing job status tracking (if applicable)
- [x] Map CrawlJob status to JobQueue status
- [x] Support job progress updates

### Worker Management
- [x] Document how to start crawler worker:
  ```bash
  php artisan queue:work --queue=crawler
  ```
- [ ] Support multiple crawler workers (Supervisor config) - **Requires DevOps**
- [ ] Configure max jobs per worker (restart periodically) - **Requires DevOps**

### Failed Job Handling
- [x] Store failed jobs in failed_jobs table
- [x] Retry mechanism for transient failures - **Configurable via `crawler.queue.retry_attempts` and `crawler.queue.retry_delay`**
- [x] Alert on consecutive failures - **Implemented via `CrawlFailureAlertService`**

### Job Priority System
| Priority | Use Case |
|----------|----------|
| `high` | Manual user-initiated crawls |
| `default` | Scheduled/system crawls |
| `low` | Background re-crawls |

### Queue Monitoring
- [ ] Integrate with Laravel Horizon (if installed)
- [x] Queue size metrics
- [x] Job wait time metrics
- [x] Worker health metrics

### Supervisor Configuration
- [ ] Create supervisor config for crawler workers:
```ini
[program:crawler-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /path/to/artisan queue:work --queue=crawler --sleep=3 --tries=1
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/log/crawler-worker.log
```

### Queue Commands
- [x] `php artisan crawler:restart` - Restart all crawler workers
- [x] `php artisan crawler:status` - Show queue statistics
- [x] `php artisan crawler:clear` - Clear crawler queue

### Testing Queue Integration
- [x] Test job dispatch
- [x] Test job processing
- [x] Test failed job handling
- [x] Test queue priority
- [x] Test with multiple workers
