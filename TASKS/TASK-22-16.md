## Description
Integrate the CrawlWorker with the existing JobQueue system (from TASK-1-10) for unified job management and monitoring.

## Acceptance Criteria

### Queue Configuration
- [ ] Add 'crawler' queue to queue connections
- [ ] Configure in `config/queue.php`
- [ ] Use same driver as existing JobQueue (database/redis)
- [ ] Set queue priority (default: normal)

### Queue Connection
```php
// config/queue.php
'connections' => [
    'crawler' => [
        'driver' => 'database',
        'table' => 'jobs',
        'queue' => 'crawler',
        'retry_after' => 300,
        'after_commit' => true,
    ],
],
```

### Job Dispatching
- [ ] Dispatch CrawlWorker to 'crawler' queue
- [ ] Set job priority based on user tier (optional)
- [ ] Support delay parameter (schedule for later)
- [ ] Include job metadata in payload

### Job Status Integration
- [ ] Update existing job status tracking (if applicable)
- [ ] Map CrawlJob status to JobQueue status
- [ ] Support job progress updates

### Worker Management
- [ ] Document how to start crawler worker:
  ```bash
  php artisan queue:work --queue=crawler
  ```
- [ ] Support multiple crawler workers
- [ ] Configure max jobs per worker (restart periodically)

### Failed Job Handling
- [ ] Store failed jobs in failed_jobs table
- [ ] Retry mechanism for transient failures
- [ ] Alert on consecutive failures

### Job Priority System
| Priority | Use Case |
|----------|----------|
| `high` | Manual user-initiated crawls |
| `default` | Scheduled/system crawls |
| `low` | Background re-crawls |

### Queue Monitoring
- [ ] Integrate with Laravel Horizon (if installed)
- [ ] Queue size metrics
- [ ] Job wait time metrics
- [ ] Worker health metrics

### Supervisor Configuration
- [ ] Create supervisor config for crawler workers:
```ini
[program:crawler-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /path/to/artisan queue:work --queue=crawler --sleep=3 --tries=1
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/log/crawler-worker.log
```

### Queue Commands
- [ ] `php artisan crawler:restart` - Restart all crawler workers
- [ ] `php artisan crawler:status` - Show queue statistics
- [ ] `php artisan crawler:clear` - Clear crawler queue

### Testing Queue Integration
- [ ] Test job dispatch
- [ ] Test job processing
- [ ] Test failed job handling
- [ ] Test queue priority
- [ ] Test with multiple workers
