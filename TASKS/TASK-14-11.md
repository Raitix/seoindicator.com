### Features

#### 1. Response Time Analysis
```php
class PerformanceChecker implements CheckerInterface
{
    public function check(CrawlResult $result): ?IssueFinding
    {
        $responseTime = $result->responseTimeMs;
        
        if ($responseTime > $this->slowThreshold) {
            return $this->createFinding(
                issueType: 'slow_page',
                severity: $this->getSeverity($responseTime),
                description: "Page loaded in {$responseTime}ms (threshold: {$this->slowThreshold}ms)",
                recommendation: 'Optimize page performance. Consider image compression, caching, or code optimization.',
                context: ['response_time_ms' => $responseTime]
            );
        }
        
        return null;
    }
}
```

#### 2. Performance Thresholds
| Response Time | Severity | Issue |
|---------------|----------|-------|
| < 1000ms | — | Good |
| 1000-2000ms | Notice | Acceptable |
| 2000-3000ms | Warning | Needs improvement |
| > 3000ms | Warning | Slow page |
| > 5000ms | Critical | Very slow page |

#### 4. Page Size Analysis
```php
protected function checkPageSize(string $html): ?IssueFinding
{
    $sizeInBytes = strlen($html);
    $sizeInKB = $sizeInBytes / 1024;
    
    if ($sizeInKB > $this->maxPageSizeKB) {
        return $this->createFinding(
            issueType: 'large_page',
            severity: 'notice',
            description: "Page size is {$sizeInKB}KB",
            recommendation: 'Consider reducing page size for faster loading.'
        );
    }
    
    return null;
}
```
