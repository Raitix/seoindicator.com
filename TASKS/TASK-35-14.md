## Description

## Acceptance Criteria
- [ ] GBPInsightsController created
- [ ] GET /api/v1/locations/{id}/insights
  - Returns insights for date range (default: last 30 days)
  - Query params: start_date, end_date
  - Returns daily breakdown and totals
- [ ] GET /api/v1/locations/{id}/insights/trend
  - Returns trend analysis
  - Includes week-over-week, month-over-month changes
- [ ] POST /api/v1/locations/{id}/insights/sync
  - Triggers background sync from GBP API
  - Returns job ID for status tracking
- [ ] GBPReviewsController created
- [ ] GET /api/v1/locations/{id}/reviews
  - Returns paginated reviews
  - Filters: rating, sentiment, has_response, date_range
  - Sort: date, rating
- [ ] GET /api/v1/locations/{id}/reviews/stats
  - Returns review statistics
  - Average rating, total count, distribution, sentiment breakdown
- [ ] POST /api/v1/locations/{id}/reviews/sync
  - Triggers background review sync
- [ ] POST /api/v1/locations/{id}/reviews/{reviewId}/respond
  - Posts owner response to review
  - Validates response length (max 4096 chars)
- [ ] All endpoints require authentication
- [ ] User authorization verified (owns location)
- [ ] API Resources for responses
- [ ] Feature tests for all endpoints
