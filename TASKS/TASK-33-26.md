## JSON-LD Example
```json
{
  "@context": "https://schema.org",
  "@type": "WebPage",
  "name": "example.com SEO Audit Report",
  "description": "SEO audit results for example.com",
  "publisher": {
    "@type": "Organization",
    "name": "SEOIndicator",
    "url": "https://seoindicator.com"
  },
  "mainEntity": {
    "@type": "Analysis",
    "result": {
      "@type": "Rating",
      "ratingValue": "85",
      "bestRating": "100",
      "worstRating": "0"
    }
  }
}
```
