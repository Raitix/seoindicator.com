## Description
Create a dashboard and reporting system for tracking onboarding completion rates. This provides visibility into the effectiveness of the onboarding flow and helps identify areas for improvement.

## Acceptance Criteria
- [ ] Admin dashboard shows onboarding metrics:
  - [ ] Total users who started onboarding
  - [ ] Completion rate percentage
  - [ ] Average time to completion
  - [ ] Skip rate percentage
- [ ] Funnel visualization:
  - [ ] Step 1 → Step 2 conversion rate
  - [ ] Step 2 → Step 3 conversion rate
  - [ ] Step 3 → Step 4 conversion rate
  - [ ] Step 4 → Step 5 conversion rate
  - [ ] Step 5 → Completion conversion rate
- [ ] Time-based filtering (last 7 days, 30 days, 90 days)
- [ ] Export to CSV functionality
- [ ] Daily/weekly summary email (optional)
- [ ] Alert on significant drop-off (>20% at any step)

## Technical Details

### Metrics Calculation
```sql
-- Completion rate
SELECT 
    COUNT(CASE WHEN completed_at IS NOT NULL THEN 1 END) * 100.0 / COUNT(*) as completion_rate
FROM user_onboarding
WHERE created_at >= :start_date;

-- Average time to completion
SELECT AVG(TIMESTAMPDIFF(SECOND, created_at, completed_at)) as avg_duration_seconds
FROM user_onboarding
WHERE completed_at IS NOT NULL
AND created_at >= :start_date;

-- Step conversion funnel
SELECT 
    COUNT(*) as started,
    COUNT(CASE WHEN JSON_CONTAINS(completed_steps, '1') THEN 1 END) as step1,
    COUNT(CASE WHEN JSON_CONTAINS(completed_steps, '2') THEN 1 END) as step2,
    ...
FROM user_onboarding
WHERE created_at >= :start_date;
```
