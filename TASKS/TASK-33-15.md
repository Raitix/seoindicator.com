## STATUS
`Done`

## PRIORITY

## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Create the Next.js API route that serves SVG badges dynamically. This enables direct embedding of badges via image tags.

## Acceptance Criteria
- [x] Route at `/badge/[hash]/[size]/route.ts`
- [x] Returns SVG with correct Content-Type header
- [x] Supports sizes: small, medium, large
- [x] Supports theme query param: ?theme=light|dark
- [x] Returns 404 for invalid hash
- [x] Returns 404 for non-public audit
- [x] Returns 400 for invalid size
- [x] SVG cached for 1 hour
- [x] ETag header for browser caching
- [x] Unit tests for all scenarios

## Dependencies
- TASK-33-6 (BadgeService)
- TASK-33-4 (PublicAudit model)

## Effort Estimate
**3 hours** - API route with caching

## Technical Notes
- Use Next.js Route Handlers
- Set Cache-Control header: public, max-age=3600
- Generate ETag from score + hash + size
- Validate hash format (32 alphanumeric chars)

## Route Parameters
- `hash`: 32-char public audit hash
- `size`: 'small' | 'medium' | 'large'
- Query: `theme`: 'light' | 'dark' (default: 'light')

## Response Headers
```
Content-Type: image/svg+xml
Cache-Control: public, max-age=3600
ETag: "{score}-{size}-{theme}"
```

## Files to Create
- `frontend/app/badge/[hash]/[size]/route.ts`
- `frontend/__tests__/app/badge/[hash]/[size]/route.test.ts`
