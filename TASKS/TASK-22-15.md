# TASK-22-15: CrawlWorker Implementation

## STATUS
`To Prioritize`

## PRIORITY
`High`

## RISK
`High`

## Related Specification
SPEC-022: Headless Crawler Service (JS-Rendered HTML)

## Related Feature
FEAT-022: Headless Crawler Service (JS-Rendered HTML)

## Description
Implement the CrawlWorker that processes crawl jobs from the queue, orchestrating the full crawl pipeline.

## Acceptance Criteria

### Worker Structure
- [ ] Job created at `app/Jobs/CrawlWorker.php`
- [ ] Implements `ShouldQueue` interface
- [ ] Uses `Queueable`, `InteractsWithQueue` traits
- [ ] Sets timeout and tries properties

### Job Configuration
- [ ] `$timeout = 300` (5 minutes max)
- [ ] `$tries = 1` (no auto-retry)
- [ ] `$maxExceptions = 1`
- [ ] `$backoff = [60]` (wait before retry after failure)

### Main Handler Method
- [ ] `handle(CrawlerService $crawler, ...)` - Main execution
- [ ] Retrieve job by ID from database
- [ ] Set status to 'running'
- [ ] Record started_at timestamp
- [ ] Execute crawl pipeline
- [ ] Handle success/failure states
- [ ] Set completed_at timestamp

### Crawl Pipeline Steps
1. [ ] Validate URL (SSRF check)
2. [ ] Launch browser instance
3. [ ] Render main page (depth 0)
4. [ ] Extract content and links
5. [ ] Store page results
6. [ ] Process depth 1 links (if configured)
7. [ ] Process depth 2 links (if configured)
8. [ ] Update job statistics
9. [ ] Close browser instance
10. [ ] Set job to completed

### Progress Tracking
- [ ] Update pages_crawled after each page
- [ ] Update total_size after each page
- [ ] Log progress percentage
- [ ] Check for cancellation between pages

### Error Handling
- [ ] Catch Playwright exceptions
- [ ] Catch network exceptions
- [ ] Catch timeout exceptions
- [ ] Catch memory limit exceptions
- [ ] Store error message in job
- [ ] Set job status to 'failed'
- [ ] Log full exception stack trace

### Cancellation Support
- [ ] Check cancellation flag between pages
- [ ] Clean up resources on cancellation
- [ ] Store partial results before exiting

### Memory Management
- [ ] Set memory limit (256MB)
- [ ] Force garbage collection between pages
- [ ] Monitor memory usage
- [ ] Fail gracefully if memory exceeded

### Browser Instance Lifecycle
- [ ] Launch browser at start
- [ ] Reuse browser for all pages in job
- [ ] Close browser on completion/failure
- [ ] Force close on timeout

### Logging
- [ ] Log job start with URL and options
- [ ] Log each page crawl
- [ ] Log errors with context
- [ ] Log job completion with stats

### Failed Job Handling
- [ ] `failed(Throwable $exception)` method
- [ ] Update job status to 'failed'
- [ ] Store error message
- [ ] Close browser instances
- [ ] Alert monitoring (optional)

### Tests
- [ ] Test successful crawl (single page)
- [ ] Test successful crawl (multi-depth)
- [ ] Test failure handling
- [ ] Test timeout handling
- [ ] Test cancellation handling
- [ ] Test memory management
