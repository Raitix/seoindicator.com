**Key Lesson for Dashboard Tasks:**
Dashboard pages that aggregate multiple API endpoints should follow the same TDD pattern:
1. Tests designed with MSW mocking all required endpoints
2. Component logic tested independently of real backend
3. Progressive loading pattern: critical data first, secondary data deferred
4. Error boundaries per section (one section failure doesn't crash entire dashboard)
