## Acceptance Criteria
- [ ] LocalRankingController created
- [ ] GET /api/v1/locations/{id}/rankings
  - Returns current rankings for location's keywords
  - Shows local pack and organic positions
  - Returns competitor comparison data
- [ ] GET /api/v1/locations/{id}/rankings/history
  - Returns historical ranking data
  - Query params: keyword_id, start_date, end_date
  - Returns daily snapshots with position changes
- [ ] POST /api/v1/locations/{id}/rankings/check
  - Triggers ranking check for all keywords
  - Returns job ID for status tracking
  - Enforces monthly quota (50 checks/month free tier)
- [ ] POST /api/v1/locations/{id}/rankings/check/{keywordId}
  - Triggers ranking check for single keyword
  - Enforces monthly quota
- [ ] GET /api/v1/locations/{id}/rankings/quota
  - Returns current month's quota usage
  - Returns remaining checks
- [ ] GET /api/v1/locations/{id}/competitors
  - Lists detected competitors from local pack
  - Shows competitor rankings, ratings, review counts
- [ ] POST /api/v1/locations/{id}/competitors
  - Manually add competitor for tracking
  - Validates competitor data
- [ ] DELETE /api/v1/locations/{id}/competitors/{competitorId}
  - Removes competitor from tracking
- [ ] QuotaExceededException returns 429 response
- [ ] All endpoints require authentication
- [ ] Feature tests for all endpoints
