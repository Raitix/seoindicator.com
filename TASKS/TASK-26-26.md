```json
  }
}
```

**Required Action:** Update test assertions to match actual API response structure OR update controllers to match test expectations.

---

### Bug #3: Missing Required Request Fields
**Severity: High** - PayPal tests fail with 422 validation error

**Problem:** `CreatePayPalOrderRequest` requires:
- `package_id` (required, exists in credit_packages table)
- `return_url` (required, must be HTTPS URL)
- `cancel_url` (required, must be HTTPS URL)

**Tests Only Send:**
```php
['amount' => 10.00, 'package_id' => 1]  // Missing return_url, cancel_url
```

**Required Actions:**
1. Add `return_url` and `cancel_url` to all PayPal test requests
2. Create `CreditPackage` records in test setup (no package with id=1 exists)

---

### Bug #4: SQLite Transaction Cascade Failure
**Severity: Medium** - Causes cascade failures after first test failure

**Problem:** First test fails with 404/422, leaving transaction open. Subsequent tests fail with:
```
PDOException: There is already an active transaction
```

**Root Cause:** Tests use `RefreshDatabase` which wraps each test in a transaction. When a test fails before transaction completes, SQLite can't handle nested transactions.

**Workaround:** This is a test environment limitation, not a test code bug. Will work fine once Bug #1 and #3 are fixed.
