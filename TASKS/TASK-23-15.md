## Technical Details

### Visibility Score Components
| Component | Weight | Source |
|-----------|--------|--------|
| Position | 40% | Average keyword positions |
| SERP Features | 30% | SERP feature presence |
| Backlinks | 20% | Profile health score |
| Search Volume | 10% | Keyword volume distribution |

### Service Implementation
```php
class VisibilityScoreService
{
    public function calculate(Project $project): int
    {
        $positionScore = $this->calculatePositionComponent($project);
        $serpScore = $this->calculateSerpComponent($project);
        $backlinkScore = $this->calculateBacklinkComponent($project);
        $volumeScore = $this->calculateVolumeComponent($project);
        
        return (int) round(
            $positionScore * 0.40 +
            $serpScore * 0.30 +
            $backlinkScore * 0.20 +
            $volumeScore * 0.10
        );
    }
    
    protected function calculateBacklinkComponent(Project $project): float
    {
        // Return 0 if no backlink data
        if (!$project->hasBacklinks()) {
            return 0;
        }
        
        $profileScore = app(BacklinkProfileScorer::class)->score($project);
        
        // Weight is already 20%, return full score
        return $profileScore;
    }
}
```

### Graceful Degradation
```php
// If no backlink data, redistribute weight
if (!$project->hasBacklinks()) {
    return $positionScore * 0.50 +  // +10%
           $serpScore * 0.375 +     // +7.5%
           $volumeScore * 0.125;    // +2.5%
}
```
