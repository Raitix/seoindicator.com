## Description
Create optimized content retrieval endpoints with filtering, pagination, and multiple output formats.

## Acceptance Criteria

### Enhanced Content Endpoint

#### GET /api/v1/crawler/jobs/{jobId}/content
- [ ] Return all pages with rendered HTML
- [ ] Support filtering parameters:
  - [ ] `depth` - Filter by depth level (0, 1, 2)
  - [ ] `search` - Search in title/text
  - [ ] `include` - Fields to include (html, text, meta, links)
  - [ ] `exclude` - Fields to exclude
- [ ] Support pagination:
  - [ ] `page` - Page number (default 1)
  - [ ] `perPage` - Items per page (default 50, max 100)
- [ ] Support sorting:
  - [ ] `sortBy` - Field to sort by (depth, size, crawledAt)
  - [ ] `sortOrder` - asc or desc

#### Response with Pagination
```json
{
  "jobId": "crawl-abc123",
  "pages": [...],
  "pagination": {
    "currentPage": 1,
    "perPage": 50,
    "totalPages": 3,
    "totalItems": 5
  },
  "summary": {...}
}
```

### Field Selection
- [ ] `?include=text,meta` - Only structured text and metadata
- [ ] `?exclude=renderedHtml` - Exclude large HTML content
- [ ] Default: include all fields
- [ ] Validate field names against whitelist

### Individual Page Endpoint

#### GET /api/v1/crawler/jobs/{jobId}/pages/{pageId}
- [ ] Get single page content
- [ ] Return 404 if page not found
- [ ] Support same field selection options

### Export Endpoints

#### GET /api/v1/crawler/jobs/{jobId}/export/json
- [ ] Export as JSON file
- [ ] Include all pages
- [ ] Set Content-Disposition header for download

#### GET /api/v1/crawler/jobs/{jobId}/export/csv
- [ ] Export as CSV file
- [ ] Columns: url, depth, title, meta_description, text_preview, size
- [ ] Exclude full HTML from CSV

#### GET /api/v1/crawler/jobs/{jobId}/export/html
- [ ] Export as combined HTML file
- [ ] Include table of contents
- [ ] Separate pages with dividers

### Streaming Response (Large Jobs)
- [ ] Stream response for jobs with > 1MB content
- [ ] Use Laravel's stream response
- [ ] Include progress indicator in headers

### Content Transformation
- [ ] HTML minification (optional)
- [ ] Text encoding normalization (UTF-8)
- [ ] Link URL resolution (relative to absolute)

### Caching
- [ ] Cache content responses for completed jobs
- [ ] Cache TTL: 1 hour
- [ ] Invalidate on job deletion

### Tests
- [ ] Test pagination
- [ ] Test field selection
- [ ] Test filtering
- [ ] Test export endpoints
- [ ] Test large response streaming
