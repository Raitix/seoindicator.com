## Description

## Acceptance Criteria

- [ ] `AIVisibilityAnalyticsController` created at `app/Http/Controllers/Api/V1/AIVisibility/`

- [ ] `GET /api/v1/ai-visibility/projects/{id}/analytics` endpoint
  - [ ] Returns aggregated analytics for project
  - [ ] Query parameters:
    - `period`: day, week, month (default: week)
    - `platform`: filter by platform (optional)
  - [ ] Response structure:
    ```json
    {
      "mention_rate": 23.5,
      "share_of_voice": 31.2,
      "sentiment": {
        "score": 0.45,
        "breakdown": { "positive": 10, "neutral": 5, "negative": 2, "mixed": 1 }
      },
      "trend": { "direction": "up", "change_percent": 5.2 },
      "by_platform": [
        { "platform": "chatgpt", "mention_rate": 25.0, "queries": 10 },
        { "platform": "perplexity", "mention_rate": 22.0, "queries": 10 }
      ]
    }
    ```
  - [ ] Authorization: user must own project
  - [ ] Cache response for 5 minutes

- [ ] `GET /api/v1/ai-visibility/projects/{id}/comparison` endpoint
  - [ ] Returns brand vs competitors comparison
  - [ ] Response structure:
    ```json
    {
      "brand": { "name": "SEOIndicator", "mentions": 15, "rate": 23.5 },
      "competitors": [
        { "name": "Ahrefs", "mentions": 25, "rate": 38.5 },
        { "name": "SEMrush", "mentions": 20, "rate": 30.8 }
      ]
    }
    ```
  - [ ] Authorization: user must own project

- [ ] `GET /api/v1/ai-visibility/projects/{id}/trend` endpoint
  - [ ] Returns trend analysis over time
  - [ ] Query parameters:
    - `days`: number of days (default: 90)
  - [ ] Response structure:
    ```json
    {
      "data": [
        { "date": "2026-03-01", "mention_rate": 20.5, "share_of_voice": 28.0 },
        { "date": "2026-03-02", "mention_rate": 22.0, "share_of_voice": 30.0 }
      ],
      "direction": "up",
      "change_percent": 12.5
    }
    ```
  - [ ] Authorization: user must own project

- [ ] `GET /api/v1/ai-visibility/projects/{id}/queries` endpoint
  - [ ] Returns paginated query history
  - [ ] Query parameters:
    - `page`: page number
    - `platform`: filter by platform (optional)
    - `mentioned_only`: boolean (default: false)
  - [ ] Response structure:
    ```json
    {
      "data": [
        {
          "id": 1,
          "platform": "chatgpt",
          "query_text": "What are the best SEO tools?",
          "brand_mentioned": true,
          "brand_sentiment": "positive",
          "queried_at": "2026-03-07T10:00:00Z"
        }
      ],
      "meta": { "current_page": 1, "total": 50 }
    }
    ```
  - [ ] Authorization: user must own project

- [ ] Error handling
  - [ ] 404 for non-existent project
  - [ ] 403 for unauthorized access
  - [ ] 400 for invalid parameters

- [ ] Routes registered in `routes/api.php`
