## Description
Create CrawlController with REST API endpoints for initiating crawl jobs, checking status, and retrieving content.

## Acceptance Criteria

### Controller Structure
- [ ] Controller created at `app/Http/Controllers/Api/V1/CrawlController.php`
- [ ] Extends base API controller
- [ ] Uses API versioning (v1)

### Endpoints

#### POST /api/v1/crawler/crawl
- [ ] Initiate crawl job
- [ ] Request body validation
- [ ] Returns 202 Accepted with jobId
- [ ] Queue job for background processing

#### GET /api/v1/crawler/jobs/{jobId}
- [ ] Get crawl job status
- [ ] Returns job details and progress
- [ ] Returns 404 if job not found

#### GET /api/v1/crawler/jobs/{jobId}/content
- [ ] Get crawled content
- [ ] Returns pages array with rendered HTML
- [ ] Support pagination (optional)
- [ ] Returns 404 if job not found
- [ ] Returns 409 if job not complete

#### DELETE /api/v1/crawler/jobs/{jobId}
- [ ] Cancel crawl job
- [ ] Only allowed for queued/running jobs
- [ ] Returns 200 on success

#### GET /api/v1/crawler/jobs
- [ ] List user's crawl jobs
- [ ] Support pagination
- [ ] Support filtering by status
- [ ] Support sorting by date

### Request Validation (POST /crawl)
- [ ] `url` - required, URL format, max 2083 chars
- [ ] `depth` - integer, 0-2, default 0
- [ ] `options.waitForSelector` - string, nullable
- [ ] `options.waitTime` - integer, 0-30000, default 2000
- [ ] `options.userAgent` - string, max 500, default SEOIndicator/1.0
- [ ] `options.includeImages` - boolean, default false
- [ ] `options.followRedirects` - boolean, default true
- [ ] `options.maxRedirects` - integer, 0-10, default 5

### Error Responses
- [ ] 400 Bad Request - Invalid parameters
- [ ] 401 Unauthorized - Missing/invalid auth token
- [ ] 403 Forbidden - Not authorized to access job
- [ ] 404 Not Found - Job not found
- [ ] 409 Conflict - Job not in correct state
- [ ] 422 Unprocessable Entity - Validation errors
- [ ] 429 Too Many Requests - Rate limit exceeded
- [ ] 500 Internal Server Error - Unexpected error

### Authorization
- [ ] All endpoints require authentication (Bearer token)
- [ ] Users can only access their own jobs
- [ ] Admin users can access all jobs (optional)

### Routes Registration
- [ ] Routes added to routes/api.php
- [ ] Routes under 'api/v1/crawler' prefix
- [ ] Middleware: auth:sanctum, throttle
