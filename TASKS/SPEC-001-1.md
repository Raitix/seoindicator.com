## Description
Create database migrations for keywords and ranking_history tables. This is the foundation for the keyword rank tracking feature.

## Acceptance Criteria
- [ ] Migration creates `keywords` table with: id, user_id, site_id, keyword, target_url, search_engine, location, device, status, last_checked_at, created_at, updated_at
- [ ] Migration creates `ranking_history` table with: id, keyword_id, position, url_found, serp_features, checked_at, check_duration_ms, error
- [ ] Foreign key constraints: keywords.site_id → sites.id, ranking_history.keyword_id → keywords.id
- [ ] Unique constraint on (site_id, keyword, search_engine, location, device) in keywords table
- [ ] Indexes on: keywords.site_id, keywords.status, keywords.last_checked_at, ranking_history.keyword_id, ranking_history.checked_at, ranking_history(keyword_id, checked_at)
- [ ] Migration is reversible (down method drops tables)
- [ ] Migration runs successfully on local MySQL/SQLite

## Dependencies
