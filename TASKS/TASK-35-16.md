## Acceptance Criteria
- [x] LocalSEOAlertController created
- [x] GET /api/v1/local-seo/alerts
  - Returns all alerts for current user
  - Filters: location_id, severity, alert_type, is_read
  - Sort: created_at (desc)
  - Pagination support
- [x] GET /api/v1/local-seo/alerts/unread-count
  - Returns count of unread alerts
  - Grouped by severity
- [x] POST /api/v1/local-seo/alerts/{id}/read
  - Marks single alert as read
- [x] POST /api/v1/local-seo/alerts/mark-all-read
  - Marks all alerts as read for user
  - Optional filters: location_id, severity
- [x] DELETE /api/v1/local-seo/alerts/{id}
  - Deletes alert (soft delete or permanent)
- [x] GET /api/v1/locations/{id}/alerts
  - Returns alerts for specific location
  - Same filters and sorting as main endpoint
- [x] All endpoints require authentication
- [x] User can only access their own alerts
- [x] API Resource for alert formatting
- [x] Feature tests for all endpoints
