## Description

## Acceptance Criteria
- [ ] LocalSEOAlertController created
- [ ] GET /api/v1/local-seo/alerts
  - Returns all alerts for current user
  - Filters: location_id, severity, alert_type, is_read
  - Sort: created_at (desc)
  - Pagination support
- [ ] GET /api/v1/local-seo/alerts/unread-count
  - Returns count of unread alerts
  - Grouped by severity
- [ ] POST /api/v1/local-seo/alerts/{id}/read
  - Marks single alert as read
- [ ] POST /api/v1/local-seo/alerts/mark-all-read
  - Marks all alerts as read for user
  - Optional filters: location_id, severity
- [ ] DELETE /api/v1/local-seo/alerts/{id}
  - Deletes alert (soft delete or permanent)
- [ ] GET /api/v1/locations/{id}/alerts
  - Returns alerts for specific location
  - Same filters and sorting as main endpoint
- [ ] All endpoints require authentication
- [ ] User can only access their own alerts
- [ ] API Resource for alert formatting
- [ ] Feature tests for all endpoints
