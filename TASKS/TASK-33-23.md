# TASK-33-23: Implement Lead Capture Flow

## STATUS
`To Develop`

## PRIORITY
`High`

## RISK
`Low`

## Specification
**SPEC-33**: Public SEO Audit Reports & Embeddable Score Widget

## Description
Implement the complete lead capture flow: anonymous user views public audit → enters email → gets access to full report → receives follow-up.

## Acceptance Criteria
- [ ] Email form in PublicAuditCTA component
- [ ] Form validates email format
- [ ] Submission stores email in public_audit_views table
- [ ] Success: user sees full issue list (isPartial = false)
- [ ] Success: optional redirect to signup page
- [ ] Option to skip and view limited report
- [ ] Email not stored if already exists (deduplication)
- [ ] Unit tests for form and flow

## Dependencies
- TASK-33-12 (PublicAuditCTA component)
- TASK-33-5 (lead capture API endpoint)

## Effort Estimate
**3 hours** - Form with flow logic

## Technical Notes
- Store email hashed for privacy
- Set cookie/session for "unlocked" access
- Consider reCAPTCHA for spam prevention (optional)
- Rate limit email submissions per IP

## Flow States
1. Anonymous user arrives → sees top 5 issues
2. User enters email → stored in public_audit_views
3. User gets full access → sees all issues
4. Optional: redirect to signup with pre-filled email

## Files to Modify
- `frontend/components/audit/PublicAuditCTA.tsx`
- `frontend/lib/audit/public-audit.ts` (unlock logic)
- `frontend/__tests__/components/audit/PublicAuditCTA.test.tsx`
