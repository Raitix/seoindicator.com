### Domains Endpoint
```
GET /api/v1/projects/{projectId}/backlinks/domains?page=1&perPage=20&sort=backlinks_count
```

**Response:**
```json
{
  "data": [
    {
      "domain": "example.com",
      "backlinks_count": 45,
      "domain_trust_score": 72,
      "first_seen_at": "2026-01-15T10:00:00Z",
      "last_seen_at": "2026-02-27T10:00:00Z"
    }
  ],
  "meta": {
    "total": 89,
    "page": 1,
    "perPage": 20,
    "lastPage": 5
  }
}
```

### Anchors Endpoint
```
GET /api/v1/projects/{projectId}/backlinks/anchors
```

**Response:**
```json
{
  "data": [
    {
      "anchor_text": "seo tools",
      "backlinks_count": 150,
      "percentage": 12.0,
      "is_branded": false,
      "is_exact_match": true
    },
    {
      "anchor_text": "Brand Name",
      "backlinks_count": 280,
      "percentage": 22.4,
      "is_branded": true,
      "is_exact_match": false
    }
  ]

```

### Controller Implementation
```php
public function domains(Request $request, Project $project): JsonResponse
{
    $this->authorize('view', $project);
    
    $sort = $request->get('sort', 'backlinks_count');
    $perPage = min($request->get('perPage', 20), 100);
    
    $domains = $this->domains->paginate(
        $project->id,
        $perPage,
        $sort
    );
    
    return response()->json([
        'data' => $domains->items(),
        'meta' => [
            'total' => $domains->total(),
            'page' => $domains->currentPage(),
            'perPage' => $domains->perPage(),
            'lastPage' => $domains->lastPage(),
        ],
    ]);
}
```
