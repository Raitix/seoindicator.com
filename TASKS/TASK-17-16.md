## Description
Track the time from user registration to their first keyword being created. This metric measures how quickly users achieve value and is a key indicator of activation success.

## Acceptance Criteria
- [ ] Timestamp captured when user registers
- [ ] Timestamp captured when first keyword created
- [ ] Time-to-first-keyword calculated and stored
- [ ] Dashboard shows average time-to-first-keyword
- [ ] Breakdown by time period (same session, <1 hour, <1 day, >1 day)
- [ ] Correlation analysis: time-to-first-keyword vs. retention
- [ ] Alert if median time exceeds 10 minutes (onboarding too slow)
- [ ] Integration with user_onboarding.completed_at field

## Technical Details

### Data Sources
```php
// Registration timestamp
$user->created_at

// First keyword timestamp
$keyword = Keyword::where('user_id', $user->id)
    ->orderBy('created_at')
    ->first();
$keyword->created_at

// Time to first keyword
$timeToFirstKeyword = $keyword->created_at->diffInSeconds($user->created_at);
```

### Time Buckets
```php
enum TimeToFirstKeywordBucket: string
{
    case SAME_SESSION = 'same_session';     // < 30 min
    case WITHIN_HOUR = 'within_hour';        // 30 min - 1 hour
    case WITHIN_DAY = 'within_day';          // 1 hour - 24 hours
    case WITHIN_WEEK = 'within_week';        // 1 day - 7 days
    case NEVER = 'never';                    // No keyword created
}
```

### Metric Calculation
```sql
SELECT 
    AVG(TIMESTAMPDIFF(MINUTE, u.created_at, k.created_at)) as avg_minutes,
    MEDIAN(TIMESTAMPDIFF(MINUTE, u.created_at, k.created_at)) as median_minutes
FROM users u
JOIN keywords k ON k.user_id = u.id
WHERE k.id = (
    SELECT MIN(id) FROM keywords WHERE user_id = u.id
)
AND u.created_at >= :start_date;
```
