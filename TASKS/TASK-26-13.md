## Description
Create REST API endpoint for creating a PayPal order for credit purchase.

## Acceptance Criteria

### Endpoint
- [ ] `POST /api/v1/payments/paypal/order`
- [ ] Authentication required (Bearer token)
- [ ] Returns JSON with order ID for PayPal SDK

### Request Body
```json
{
  "package_id": 2,
  "return_url": "https://example.com/credits/success",
  "cancel_url": "https://example.com/credits/cancelled"
}
```

### Response Format (Success)
```json
{
  "success": true,
  "data": {
    "order_id": "5O190127TN364715T",
    "approval_url": "https://www.paypal.com/checkoutnow?token=5O190127TN364715T",
    "amount": 10.00,
    "credits": 10.50,
    "package_name": "Basic"
  }
}
```

### Controller Implementation
- [ ] `createPayPalOrder()` method in PaymentController
- [ ] Validates package exists and is active
- [ ] Calculates credits including bonus
- [ ] Calls PayPalGatewayService
- [ ] Creates pending transaction record

### Validation Rules
- [ ] `package_id` required, must exist in credit_packages table
- [ ] `return_url` required, must be valid URL
- [ ] `cancel_url` required, must be valid URL

### Business Logic
- [ ] Verify user is authenticated
- [ ] Calculate credits: base + bonus percentage
- [ ] Create PayPal order
- [ ] Store pending transaction with order_id
- [ ] Return order_id and approval_url

### Error Responses
- [ ] 401 Unauthorized if not authenticated
- [ ] 422 Unprocessable Entity for validation errors
- [ ] 400 Bad Request if package inactive
- [ ] 500 Internal Server Error for PayPal failures

### Feature Tests
- [ ] Test successful order creation
- [ ] Test invalid package returns 422
- [ ] Test inactive package returns 400
- [ ] Test unauthenticated returns 401
- [ ] Test PayPal error handling
