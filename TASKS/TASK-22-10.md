## Description
Implement comprehensive link extraction and queue management for multi-page crawling, including priority queuing and concurrent processing support.

## Acceptance Criteria

### Link Extraction Enhancement
- [x] Enhance DepthControllerService link extraction
- [x] Extract links from rendered HTML (after JS execution)
- [x] Handle JavaScript-generated links (onclick, etc.)
- [x] Extract image src attributes (optional)
- [x] Extract link href (stylesheet, icon)
- [x] Extract iframe src (optional, configurable)

### Link Data Structure
```php
[
    'url' => string,
    'text' => string|null,
    'title' => string|null,
    'rel' => string|null,
    'target' => string|null,
    'internal' => bool,
    'type' => 'link'|'image'|'script'|'stylesheet',
    'depth' => int,
    'parentUrl' => string,
    'discovered' => timestamp,
]
```

### Queue Management
- [x] Create `crawl_queue` table or use Redis
- [x] Track queue items with status: pending, processing, completed, failed, skipped
- [x] Implement priority levels (depth 0 = high, depth 1 = medium, depth 2 = low)
- [x] Support concurrent workers (lock items during processing)

### Queue Item Structure
```php
[
    'id' => string,
    'crawl_job_id' => int,
    'url' => string,
    'depth' => int,
    'priority' => int,
    'status' => 'pending'|'processing'|'completed'|'failed'|'skipped',
    'parent_url' => string|null,
    'attempts' => int,
    'error' => string|null,
    'created_at' => timestamp,
    'updated_at' => timestamp,
]
```

### Queue Operations
- [x] `addToQueue(string $jobId, array $links, int $depth): void` - Add links to queue
- [x] `getNextItem(string $jobId): ?QueueItem` - Get next pending item
- [x] `markProcessing(string $itemId): void` - Mark item as being processed
- [x] `markCompleted(string $itemId): void` - Mark item as completed
- [x] `markFailed(string $itemId, string $error): void` - Mark item as failed
- [x] `getQueueStats(string $jobId): QueueStats` - Get queue statistics

### Queue Statistics
```php
[
    'total' => int,
    'pending' => int,
    'processing' => int,
    'completed' => int,
    'failed' => int,
    'skipped' => int,
]
```

### Duplicate Prevention
- [x] Use Bloom filter or set for O(1) duplicate detection
- [x] Normalize URLs before duplicate check
- [x] Handle near-duplicates (trailing slash, www prefix)

### Retry Logic
- [x] Max retry attempts: 2
- [x] Exponential backoff between retries
- [x] Don't retry on certain errors (4xx client errors)
- [x] Log retry attempts

### Queue Cleanup
- [x] Remove completed items after job finishes
- [x] Remove failed items after job finishes (keep error logs)
- [x] Clear queue on job cancellation

### Concurrent Processing Support
- [x] Lock items when processing begins
- [x] Lock timeout: 5 minutes (auto-release)
- [x] Support multiple workers per job (configurable max)
- [x] Prevent duplicate processing of same URL

### Configuration
- [x] `max_concurrent_pages` (default: 3)
- [x] `queue_retry_attempts` (default: 2)
- [x] `queue_lock_timeout` (default: 300 seconds)
- [x] `dedup_method` ('set' or 'bloom')

### Tests

- [x] Test retry logic
- [x] Test concurrent processing
- [x] Test queue statistics
