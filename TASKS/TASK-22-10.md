## Description
Implement comprehensive link extraction and queue management for multi-page crawling, including priority queuing and concurrent processing support.

## Acceptance Criteria

### Link Extraction Enhancement
- [ ] Enhance DepthControllerService link extraction
- [ ] Extract links from rendered HTML (after JS execution)
- [ ] Handle JavaScript-generated links (onclick, etc.)
- [ ] Extract image src attributes (optional)
- [ ] Extract link href (stylesheet, icon)
- [ ] Extract iframe src (optional, configurable)

### Link Data Structure
```php
[
    'url' => string,
    'text' => string|null,
    'title' => string|null,
    'rel' => string|null,
    'target' => string|null,
    'internal' => bool,
    'type' => 'link'|'image'|'script'|'stylesheet',
    'depth' => int,
    'parentUrl' => string,
    'discovered' => timestamp,
]
```

### Queue Management
- [ ] Create `crawl_queue` table or use Redis
- [ ] Track queue items with status: pending, processing, completed, failed, skipped
- [ ] Implement priority levels (depth 0 = high, depth 1 = medium, depth 2 = low)
- [ ] Support concurrent workers (lock items during processing)

### Queue Item Structure
```php
[
    'id' => string,
    'crawl_job_id' => int,
    'url' => string,
    'depth' => int,
    'priority' => int,
    'status' => 'pending'|'processing'|'completed'|'failed'|'skipped',
    'parent_url' => string|null,
    'attempts' => int,
    'error' => string|null,
    'created_at' => timestamp,
    'updated_at' => timestamp,
]
```

### Queue Operations
- [ ] `addToQueue(string $jobId, array $links, int $depth): void` - Add links to queue
- [ ] `getNextItem(string $jobId): ?QueueItem` - Get next pending item
- [ ] `markProcessing(string $itemId): void` - Mark item as being processed
- [ ] `markCompleted(string $itemId): void` - Mark item as completed
- [ ] `markFailed(string $itemId, string $error): void` - Mark item as failed
- [ ] `getQueueStats(string $jobId): QueueStats` - Get queue statistics

### Queue Statistics
```php
[
    'total' => int,
    'pending' => int,
    'processing' => int,
    'completed' => int,
    'failed' => int,
    'skipped' => int,
]
```

### Duplicate Prevention
- [ ] Use Bloom filter or set for O(1) duplicate detection
- [ ] Normalize URLs before duplicate check
- [ ] Handle near-duplicates (trailing slash, www prefix)

### Retry Logic
- [ ] Max retry attempts: 2
- [ ] Exponential backoff between retries
- [ ] Don't retry on certain errors (4xx client errors)
- [ ] Log retry attempts

### Queue Cleanup
- [ ] Remove completed items after job finishes
- [ ] Remove failed items after job finishes (keep error logs)
- [ ] Clear queue on job cancellation

### Concurrent Processing Support
- [ ] Lock items when processing begins
- [ ] Lock timeout: 5 minutes (auto-release)
- [ ] Support multiple workers per job (configurable max)
- [ ] Prevent duplicate processing of same URL

### Configuration
- [ ] `max_concurrent_pages` (default: 3)
- [ ] `queue_retry_attempts` (default: 2)
- [ ] `queue_lock_timeout` (default: 300 seconds)
- [ ] `dedup_method` ('set' or 'bloom')

### Tests
- [ ] Test link extraction from HTML
- [ ] Test queue operations
- [ ] Test duplicate detection
- [ ] Test retry logic
- [ ] Test concurrent processing
- [ ] Test queue statistics
