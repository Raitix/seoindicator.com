## Test Scenarios

### Button Navigation Tests
- Sign In button navigates to /login

### Hover State Tests
- Nav items show pointer cursor
- Hover background is visible (not white-on-white)
- Focus states work correctly

### Protected Route Visibility Tests
- Dashboard hidden from guests
- Competitors hidden from guests
- Comparison hidden from guests
- All items visible to authenticated users

### Accessibility Tests
- Keyboard navigation works
- ARIA labels present
- Focus visible on all interactive elements
